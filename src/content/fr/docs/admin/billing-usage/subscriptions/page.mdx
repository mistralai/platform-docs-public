# Abonnement

Utilisez `Abonnement` pour consulter le plan Mistral, les sièges, l'utilisation mensuelle incluse et les paramètres de paiement à l'usage actifs sur votre Organisation. Les plans Mistral sont globaux : le même plan s'applique à Vibe, Studio et l'API.

Pour connaître les détails des plans, les budgets d'utilisation et les tarifs des modèles, consultez la [tarification Mistral](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="open-subscriptions">Ouvrir l'abonnement</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/subscription" path={["Admin Panel", "Subscription"]} />.

Dans `Abonnement`, vous pouvez consulter :

- votre plan Mistral et vos sièges ;
- l'utilisation mensuelle incluse ;
- l'utilisation estimée actuelle ;
- les paramètres de paiement à l'usage ;
- les sièges Mistral Code, lorsqu'ils s'appliquent.

<SectionTab as="h1" sectionId="mistral-plan">Plan Mistral</SectionTab>

Votre plan Mistral contrôle l'accès à Vibe, Studio et l'API. Les plans disponibles incluent le mode gratuit, Pro, Education, Team et Enterprise.

Le mode gratuit est l'état par défaut des nouveaux comptes. Les plans payants ajoutent des sièges, des fonctionnalités et une utilisation mensuelle incluse. Pour connaître les fonctionnalités et limites actuelles, consultez la [tarification Mistral](https://mistral.ai/pricing/).

:::tip
Les étudiants et les enseignants peuvent vérifier leur éligibilité à une réduction dans l'[article sur les réductions étudiantes et enseignantes](https://help.mistral.ai/en/articles/698530-i-m-a-student-or-a-teacher-am-i-eligible-for-a-discount).
:::

<SectionTab as="h1" sectionId="included-monthly-usage">Utilisation mensuelle incluse</SectionTab>

Chaque plan Mistral inclut une utilisation mensuelle partagée entre Studio, l'API et Vibe Code. Cette allocation mensuelle est consommée en premier.

Une fois l'utilisation mensuelle incluse épuisée, l'accès dépend des paramètres de votre plan. Si le paiement à l'usage est activé, l'utilisation supplémentaire est facturée par token. S'il n'est pas activé, l'utilisation peut s'arrêter jusqu'à la prochaine période de facturation ou jusqu'à ce qu'un admin modifie les paramètres.

<SectionTab as="h1" sectionId="pay-as-you-go">Paiement à l'usage</SectionTab>

Le paiement à l'usage vous permet d'étendre l'utilisation au-delà de l'utilisation mensuelle incluse. Ce n'est pas un plan séparé pour l'API ou Vibe.

Pour activer le paiement à l'usage, ouvrez <AppLink href="https://admin.mistral.ai/subscription" path={["Admin Panel", "Subscription"]} />.

Pour connaître le prix exact des modèles, l'utilisation incluse et la disponibilité des fonctionnalités, consultez la [tarification Mistral](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="mistral-code">Mistral Code et Vibe Code</SectionTab>

Certaines Organisations affichent encore des sièges Mistral Code. Les sièges Mistral Code sont des sièges Enterprise historiques pour l'assistant de code. Vibe Code couvre le CLI, les extensions d'éditeur et les workflows de code.

Si vous devez modifier le nombre de sièges Mistral Code Enterprise, contactez Mistral.

<SectionTab as="h1" sectionId="manage-subscription">Gérer votre plan</SectionTab>

Utilisez <AppLink href="https://admin.mistral.ai/subscription" path={["Admin Panel", "Subscription"]} /> pour gérer votre plan Mistral, vos sièges, l'utilisation mensuelle incluse et les paramètres de paiement à l'usage.
