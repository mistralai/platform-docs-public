# Quotas

Each organization has a cap on the number of managed deployments running at the same time:

| Plan | Concurrent managed deployments |
| --- | --- |
| Free | 0 — managed deployments require a paid plan |
| Pay-as-you-go | 3 |
| Enterprise | 10 |

Creating or starting a deployment beyond the cap fails with a `403` error. Stop or delete a deployment to free a slot. Caps can be raised per organization — contact Mistral support.

Mistral Cloud also picks the instance size for you. Every managed worker gets the same size, and per-deployment CPU and memory metrics are not exposed yet.
