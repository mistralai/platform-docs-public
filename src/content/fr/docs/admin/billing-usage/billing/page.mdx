# Facturation

Utilisez la page `Facturation` pour gérer la facturation de votre Organisation. Cela inclut les moyens de paiement, les informations de facturation, les crédits, les limites de dépenses mensuelles, l’utilisation du mois en cours et les factures.

Vous devez disposer du rôle Organisation `Admin` ou `Billing` pour gérer la facturation.

<SectionTab as="h1" sectionId="open-billing">Ouvrir la facturation</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/organization/billing" path={["Panneau d’administration", "Subscriptions", "Billing"]} />.

<SectionTab as="h1" sectionId="payment-methods">Moyens de paiement</SectionTab>

Utilisez `Moyens de paiement` pour ajouter ou mettre à jour le moyen de paiement de votre Organisation. Si aucun moyen de paiement n’est configuré, la page `Facturation` indique qu’aucun moyen de paiement n’a été ajouté.

<SectionTab as="h1" sectionId="billing-information">Informations de facturation</SectionTab>

Utilisez `Informations de facturation` pour mettre à jour le profil de facturation de votre Organisation. Ces informations apparaissent sur les prochaines factures.

<SectionTab as="h1" sectionId="credits">Crédits</SectionTab>

Utilisez `Crédits` pour consulter le solde de crédits disponible pour votre Organisation. La page `Billing` affiche :

- le solde de crédits actuel ;
- les frais d’utilisation en attente pour la facturation à l’usage ;
- l’historique des crédits, y compris les attributions, achats, soldes restants, expirations et statuts.

Vous pouvez aussi utiliser un code cadeau depuis cette section.

<SectionTab as="h1" sectionId="monthly-spending-limit">Limite de dépenses mensuelle</SectionTab>

Utilisez `Limite de dépenses mensuelle (API et Vibe)` pour configurer un plafond mensuel pour les dépenses liées à l’API et à Vibe au niveau de l’Organisation.

:::warning
Si la limite est atteinte, l’accès API peut être suspendu jusqu’au début du mois suivant ou jusqu’à ce qu’un administrateur augmente la limite. En cas d’échec du paiement d’une facture récente, l’accès peut aussi être affecté jusqu’au traitement du paiement.
:::

La limite de dépenses de l’Organisation s’applique à toute l’Organisation. Les limites de dépenses des espaces de travail ne peuvent pas la dépasser. Pour les plafonds propres aux espaces de travail, consultez [Utilisation et limites des espaces de travail](/admin/workspaces/usage-limits).

<SectionTab as="h1" sectionId="current-usage">Utilisation du mois en cours</SectionTab>

La section `Utilisation` affiche l’utilisation API du mois en cours. Elle peut inclure :

- l’utilisation actuelle ;
- la limite mensuelle ;
- l’utilisation API.

Pour les ventilations détaillées par jour, modèle, capacité et espace de travail, consultez [Utilisation et limites](/admin/billing-usage/usage-limits).

<SectionTab as="h1" sectionId="invoices">Factures</SectionTab>

La section `Factures` liste les factures précédentes avec leur ID de facture, leur date, leur montant, leur statut de paiement, leur type et une option pour télécharger la facture.

Pour savoir comment lire et télécharger les factures, consultez [Factures](/admin/billing-usage/invoices).
