# Gestion des utilisateurs

Utilisez la page `Members` pour gérer les personnes qui appartiennent à votre Organisation, leur rôle d'Organisation, les sièges produit qu'elles utilisent, ainsi que leurs Workspaces et groupes.

:::info
Pour inviter des membres, votre Organisation doit avoir un plan Team ou Enterprise, ou le paiement à l'usage activé. Vous devez avoir un rôle d'admin d'Organisation pour gérer les membres.
:::

<SectionTab as="h1" sectionId="open-members">Ouvrir la page Members</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Admin Panel", "Administration", "Members"]} />.

La page `Members` contient deux listes :

- **Active Users** : les membres qui appartiennent déjà à l'Organisation.
- **Invited Users** : les invitations en attente, y compris les invitations expirées.

Utilisez la recherche pour trouver des membres par nom ou par email. Dans `Active Users`, filtrez par rôle d'Organisation : `Admin`, `Member` ou `Billing`.

<SectionTab as="h1" sectionId="invite-members">Inviter des membres</SectionTab>

Invitez des membres manuellement lorsque votre Organisation **n'utilise pas le SSO**.

:::info
Si [SAML SSO](/admin/set-up-organization/sign-in-method/saml-sso) est activé, les utilisateurs rejoignent l'Organisation via votre fournisseur d'identité configuré.
:::

Pour inviter des membres :

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Admin Panel", "Administration", "Members"]} />.
2. Cliquez sur `Invite members`.
3. Saisissez une ou plusieurs adresses email.
4. Choisissez le rôle d'Organisation des personnes invitées.
5. Attribuez des sièges produit si nécessaire.
6. Envoyez les invitations.

Les personnes invitées reçoivent un email avec les instructions pour rejoindre l'Organisation. Utilisez `Invited Users` pour suivre les invitations en attente et expirées.

Pour chaque invitation, vous pouvez :

- renvoyer l'invitation si elle a expiré ;
- révoquer l'invitation pour empêcher la personne de rejoindre l'Organisation.

<SectionTab as="h1" sectionId="manage-members">Gérer les membres</SectionTab>

Utilisez `Active Users` pour les modifications rapides. Depuis la liste des membres, vous pouvez :

- modifier le rôle d'Organisation du membre ;
- activer ou désactiver les sièges Vibe ;
- activer ou désactiver les sièges Mistral Code.

Pour accéder à plus de paramètres, cliquez sur un membre dans `Active Users` pour ouvrir `User Details`. Le panneau de détails vous permet de consulter le profil du membre, ses abonnements, ses Workspaces, ses groupes et ses clés API.

<SectionTab as="h2" variant="secondary" sectionId="user-profile">Consulter le profil</SectionTab>

L'onglet `Profile` affiche :

- l'adresse email ;
- le prénom et le nom ;
- l'ID utilisateur ;
- si le profil est géré par SSO ou SCIM.

:::note
Si un profil est géré par un système externe, le nom et l'email sont synchronisés depuis votre fournisseur d'identité et ne peuvent pas être modifiés dans l'Admin Panel.
:::

<SectionTab as="h2" variant="secondary" sectionId="organization-roles">Gérer les rôles d'Organisation</SectionTab>

Les rôles d'Organisation contrôlent ce qu'un membre peut faire au niveau de l'Organisation.

| Rôle | Accès |
| --- | --- |
| **Admin** | Administration complète de l'Organisation. |
| **Billing** | Facturation, abonnements, factures, moyens de paiement et informations d'utilisation. |
| **Member** | Accès produit et paramètres du profil personnel. |

Pour le modèle de rôles complet, consultez [Rôles et permissions](/admin/identity-access/roles-permissions).

<SectionTab as="h2" variant="secondary" sectionId="seats-and-subscriptions">Gérer les sièges et abonnements</SectionTab>

Utilisez `Subscriptions` dans `User Details` pour consulter et gérer les sièges produit du membre.

Les sièges peuvent inclure :

- Vibe ;
- Mistral Code ;
- d'autres accès produit propres au plan.

Lorsque SAML SSO est activé, les admins d'Organisation peuvent activer l'attribution automatique des sièges depuis <AppLink href="https://admin.mistral.ai/organization/access" path={["Admin Panel", "Administration", "Access"]} />.

:::info
Avec l'attribution automatique des sièges, les utilisateurs qui se connectent pour la première fois via SSO reçoivent un siège lorsqu'ils ont accès à l'Organisation et que des sièges sont disponibles.
:::

<SectionTab as="h2" variant="secondary" sectionId="workspace-access">Gérer l'accès aux Workspaces</SectionTab>

L'onglet `Workspaces` dans `User Details` liste les Workspaces auxquels le membre appartient et son rôle de Workspace dans chacun d'eux.

Depuis cet onglet, vous pouvez :

- ajouter le membre à un Workspace existant ;
- modifier son rôle de Workspace ;
- le retirer d'un Workspace ;
- consulter son appartenance aux Workspaces.

:::note
Vous pouvez ajouter un membre uniquement à un Workspace qui existe déjà. Vous ne pouvez pas retirer un membre du Workspace par défaut.
:::

Les rôles de Workspace sont séparés des rôles d'Organisation. Par exemple, un membre `Billing` de l'Organisation peut aussi être `Workspace Contributor` dans un Workspace. Consultez [Rôles et permissions](/admin/identity-access/roles-permissions) pour les détails des rôles de Workspace.

<SectionTab as="h2" variant="secondary" sectionId="groups">Gérer les groupes</SectionTab>

L'onglet `Groups` dans `User Details` affiche les groupes auxquels le membre appartient.

Utilisez-le pour ajouter le membre à des groupes ou consulter son appartenance aux groupes. Les groupes vous aident à attribuer des accès et des rôles de Workspace à plusieurs utilisateurs à la fois. Consultez [Groupes](/admin/identity-access/groups).

<SectionTab as="h2" variant="secondary" sectionId="api-keys">Consulter les clés API d'un membre</SectionTab>

L'onglet `API Keys` dans `User Details` affiche les clés API du membre et le Workspace auquel chaque clé appartient.

Les clés API sont limitées au Workspace. Consultez [Clés API](/admin/identity-access/api-keys) pour les détails de gestion des clés.

<SectionTab as="h1" sectionId="remove-members">Retirer un membre</SectionTab>

Retirez un membre lorsqu'il n'a plus besoin d'accéder à l'Organisation.

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Admin Panel", "Administration", "Members"]} />.
2. Trouvez le membre dans `Active Users`.
3. Ouvrez la ligne du membre ou ses détails utilisateur.
4. Cliquez sur `Remove user` et confirmez.

Retirer un membre supprime son accès à l'Organisation et ses appartenances aux Workspaces. Les ressources qu'il a créées peuvent rester disponibles pour les autres membres de l'Organisation.

:::warning
Vous ne pouvez pas retirer le dernier admin d'Organisation. Au moins un admin d'Organisation doit rester.
:::
