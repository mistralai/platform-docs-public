# Voix

Cette page présente les voix prédéfinies que vous pouvez passer à une requête de synthèse vocale et explique comment lister, écouter, créer et gérer des voix via l'API.

:::

<SectionTab as="h2" sectionId="use-a-voice-id">Utiliser un identifiant de voix</SectionTab>

Passez l'identifiant de la voix sous forme de `voice_id` dans une requête de synthèse vocale. Une voix prédéfinie possède un slug, comme `gb_jane_neutral` ou `voice_478`. Une voix enregistrée dans votre espace de travail n'a pas de slug : utilisez l'identifiant que l'API renvoie lorsque vous la créez. Si l'identifiant ne correspond à aucune voix, la requête échoue avec une erreur `404`.

:::info
Pour voir une requête complète, consultez le [guide de démarrage](/studio/audio/text-to-speech/quickstarts/generate-speech) ou [Génération de parole](/studio/audio/text-to-speech/generate-speech).
:::

<SectionTab as="h2" sectionId="manage-voices">Gérer les voix</SectionTab>

L'API des voix couvre les voix prédéfinies et les voix enregistrées dans votre espace de travail. Le tableau suivant indique à quoi s'applique chaque opération.

{/* SDK METHOD COLUMN (Gregory, Oct 9): the method names are the Python SDK's (mistralai 3.x). The TypeScript SDK 2.7.0 has no voices.search: its voices.list uses the v1 endpoint and drops the type field, so the TypeScript tab calls GET /v2/audio/voices with fetch. Revisit the column and the voices.search note when the TypeScript SDK catches up. */}

| Opération | Méthode SDK | S'applique à |
| --- | --- | --- |
| Lister les voix | `voices.search` | Les voix prédéfinies et vos voix enregistrées. Le champ `type` les distingue : `preset` ou `custom`. |
| Écouter une voix | `voices.get_sample_audio` |  |
| Créer une voix | `voices.create` | Une nouvelle voix enregistrée, clonée à partir d'un enregistrement |
| Obtenir, renommer, supprimer | `voices.get`, `voices.update`, `voices.delete` | Vos voix enregistrées |

```python
import os

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

page = client.audio.voices.search(page_size=50)
while page is not None:
    for voice in page.result.data:
        languages = ", ".join(voice.languages or []) or "-"
        print(f"{voice.slug or voice.id:<38} {voice.name:<28} {voice.type:<7} {languages}")
    page = page.next()
```

      <TabItem value="typescript" label="typescript">

```typescript
const apiKey = process.env.MISTRAL_API_KEY;

let pageToken: string | undefined;
do {
  const url = new URL("https://api.mistral.ai/v2/audio/voices");
  url.searchParams.set("page_size", "50");
  if (pageToken) url.searchParams.set("page_token", pageToken);

  const response = await fetch(url, { headers: { Authorization: `Bearer ${apiKey}` } });
  if (!response.ok) throw new Error(`${response.status}: ${await response.text()}`);
  const page = await response.json();

  for (const voice of page.data) {
    const languages = (voice.languages ?? []).join(", ") || "-";
    console.log(`${(voice.slug ?? voice.id).padEnd(38)} ${voice.name.padEnd(28)} ${voice.type.padEnd(7)} ${languages}`);
  }
  pageToken = page.next_page_token || undefined;
} while (pageToken);
```

```python
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

response = client.audio.voices.get_sample_audio(voice_id="gb_jane_neutral")
try:
    output = Path("gb_jane_neutral_sample.wav")
    output.write_bytes(response.read())
finally:
    response.close()
print(f"Saved {output.resolve()} ({response.headers['content-type']})")
```

```python
import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

sample = Path("voice_sample.mp3")
voice = client.audio.voices.create(
    name="Support agent",
    sample_audio=base64.b64encode(sample.read_bytes()).decode(),
    sample_filename=sample.name,
    languages=["en"],
)
print(f"Created voice {voice.id} ({voice.name})")
```

```python
import os

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])
voice_id = os.environ["VOICE_ID"]

voice = client.audio.voices.get(voice_id=voice_id)
print(f"Found {voice.id}: {voice.name}, languages {voice.languages}")

voice = client.audio.voices.update(voice_id=voice_id, name="Support agent (EU)")
print(f"Renamed to {voice.name}")

client.audio.voices.delete(voice_id=voice_id)
print(f"Deleted {voice_id}")
```

:::
