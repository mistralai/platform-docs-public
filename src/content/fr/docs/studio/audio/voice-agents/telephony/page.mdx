# Téléphonie (SIP)

La téléphonie permet à votre agent audio de répondre aux appels téléphoniques : l'agent enregistré associé à votre numéro décroche, avec son propre modèle, sa voix, ses instructions et ses outils. Vous fournissez le numéro et le système qui transporte vos appels, et Mistral achemine chaque appel vers votre agent.

:::note
La téléphonie est disponible pour les clients entreprises, mais pas en libre-service. Pour l'activer, contactez votre équipe de compte ou [écrivez-nous](https://mistral.ai/contact).
:::

<SectionTab as="h2" sectionId="how-calls-reach-your-agent">Comment les appels entrants parviennent à votre agent</SectionTab>

Chaque appel suit le même chemin, de l'appelant à votre agent :

1. Un appelant compose votre numéro de téléphone.
2. Votre système SIP, par exemple votre opérateur, un IP PBX ou une plateforme de centre de contacts, achemine l'appel vers votre endpoint SIP Mistral.
3. Mistral démarre une session à partir de l'agent enregistré associé à ce numéro, et l'agent répond à l'appelant.

:::info
Avant de demander l'accès, créez l'agent qui répond à vos appels et enregistrez-le. Voir [Créer et gérer des agents](/studio/audio/voice-agents/agents). Vous configurez le numéro et votre système SIP avec l'équipe Mistral : aucune étape de configuration n'est nécessaire de votre côté, dans la console ou via l'API.
:::

<SectionTab as="h2" sectionId="design-for-the-phone">Concevoir votre agent pour le téléphone</SectionTab>

Lors d'un appel téléphonique, le téléphone de l'appelant remplace le micro et le haut-parleur, et votre code ne s'exécute pas pendant l'appel. Tenez compte de ces différences lorsque vous rédigez l'agent :

| Lors d'un appel téléphonique | Ce qu'il faut faire |
| --- | --- |
| Les outils côté client échouent, car il n'y a aucune application pour exécuter leurs handlers | Donnez à l'agent des [outils côté serveur](/studio/audio/voice-agents/tools#server-side-tools) pour tout ce dont il a besoin pendant un appel, par exemple une bibliothèque de documents ou un connecteur vers vos systèmes. |
| L'agent ne peut pas transférer l'appel à une personne | Indiquez à l'agent, dans ses instructions, quoi répondre lorsqu'une demande sort de son périmètre, par exemple qu'un collègue rappellera, et gérez le suivi dans vos propres systèmes. |
| Il n'y a pas d'écran : l'appelant n'entend que l'agent | Gardez des réponses courtes et associez des [fillers](/studio/audio/voice-agents/tools#fillers) aux outils lents pour éviter un silence sur la ligne. |

:::tip
Testez l'agent dans une session navigateur ou SDK avant de le mettre sur une ligne téléphonique, et retirez-en d'abord tout outil côté client. Un outil qui fonctionne dans votre application de test échoue pour les appelants.
:::

<SectionTab as="h2" sectionId="what-you-can-build">Ce que vous pouvez construire</SectionTab>

La téléphonie convient aux lignes téléphoniques où les questions se répètent et où les réponses se trouvent dans vos systèmes :

- **Assistance de premier niveau** : répondre aux questions courantes, vérifier une commande et ouvrir un ticket. Voir [Agents audio du service client](/studio/audio/use-cases/customer-support-voice-agents).
- **Prise de rendez-vous** : prendre, déplacer ou annuler un rendez-vous via un connecteur vers votre système de planification.
- **Permanence hors heures ouvrées** : répondre aux appels que votre équipe ne peut pas prendre et laisser un résumé pour le lendemain matin.
