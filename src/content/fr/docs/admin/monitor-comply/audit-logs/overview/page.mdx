# Journaux d’audit

Les journaux d’audit fournissent un **enregistrement chronologique des actions** effectuées dans votre Organisation, dans Studio et dans Vibe. Ils aident les administrateurs à suivre l’activité des utilisateurs, l’utilisation des API keys et les événements de sécurité.

Disponible avec les plans **Enterprise**. Les journaux d’audit sont activés par défaut pour tous les espaces de travail.

<SectionTab as="h1" sectionId="accessing">Accéder aux journaux d’audit</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/audit-logs" path={["Panneau d’administration", "Administration", "Audit logs"]} />.

:::info
Aucune configuration n’est nécessaire. Les journaux d’audit sont activés automatiquement avec les plans Enterprise.
:::

<SectionTab as="h1" sectionId="what-is-logged">Ce qui est enregistré</SectionTab>

Les journaux d’audit capturent les actions effectuées par les utilisateurs et les API keys. Chaque entrée de journal inclut :

- **Horodatage** (`CreatedAt`) : date et heure de l’événement.
- **Acteur** : entité qui a effectué l’action, par exemple un utilisateur humain, une API key ou le système.
- **Événement** : action spécifique, par exemple `batch_job.create` ou `le_chat.conversation.deleted`.
- **Cible** : ressource concernée, par exemple un job batch, une conversation ou une API key.
- **Métadonnées** : contexte supplémentaire sur l’acteur, l’événement et la cible.

**Activités enregistrées** :

- événements d’authentification, comme les connexions et les flux SSO ;
- utilisation et gestion des API et des clés, comme la création et la suppression ;
- modifications de l’Organisation et des espaces de travail ;
- actions de gestion des utilisateurs, comme les invitations, changements de rôle et suppressions ;
- modifications des paramètres ;
- interactions dans Vibe, comme la création ou la suppression de conversations.

<SectionTab as="h1" sectionId="search-and-filter">Rechercher et filtrer</SectionTab>

Utilisez les contrôles de filtrage au-dessus du tableau des journaux pour affiner les résultats :

1. Filtrez par **Actor**, **Event type** ou **Target resource**.
2. Combinez plusieurs filtres pour trouver des activités spécifiques, par exemple toutes les suppressions de conversations effectuées par un utilisateur précis.
3. Personnalisez les colonnes visibles en cliquant sur **Columns** et en activant ou désactivant les champs.

Le tableau se met à jour automatiquement lorsque vous appliquez des filtres.

<SectionTab as="h1" sectionId="use-cases">Cas d’usage</SectionTab>

- **Surveillance de la sécurité** : détectez les accès non autorisés ou les schémas d’activité inhabituels.
- **Enquête sur un incident** : retracez la séquence d’actions à l’origine d’un problème.
- **Conformité** : conservez des enregistrements pour les exigences réglementaires.

<SectionTab as="h1" sectionId="limitations">Limitations</SectionTab>

- L’export des journaux n’est pas pris en charge.
- Les journaux d’audit ne sont disponibles qu’avec les plans Enterprise.
