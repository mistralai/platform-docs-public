# Prononciation personnalisée

La prononciation personnalisée indique exactement à une voix comment prononcer un mot qu'elle devrait sinon deviner à partir de son orthographe, comme un nom de marque, un nom de famille ou un sigle prononcé comme un mot. Cette page explique comment écrire une prononciation, quels phonèmes l'API accepte et ce qui se produit lorsqu'un indice est incorrect.

:::info
Pour comprendre pourquoi les voix prononcent mal les mots rares et comment cela s'articule avec les biais contextuels en transcription, consultez [Vocabulaire personnalisé](/studio/audio/concepts/custom-vocabulary#custom-pronunciation).
:::

<SectionTab as="h2" sectionId="define-a-pronunciation">Définir une prononciation</SectionTab>

Dans `phoneme_hints`, associez un mot de `input` à la liste des phonèmes à utiliser pour le prononcer. Chaque phonème est une chaîne de caractères de la liste.

<Tabs groupId="code">
  <TabItem value="curl" label="curl" default>

```bash
curl -s https://api.mistral.ai/v1/audio/speech \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "voxtral-mini-tts-3-0",
    "input": "I like tomato soup.",
    "voice_id": "gb_jane_neutral",
    "phoneme_hints": {"tomato": ["t", "ə", "m", "ɑ", "t", "oʊ"]},
    "response_format": "wav"
  }' | jq -r '.audio_data' | base64 --decode > tomato.wav
```

  </TabItem>
  <TabItem value="python" label="python">

```python
import base64
import os
from pathlib import Path

import httpx

response = httpx.post(
    "https://api.mistral.ai/v1/audio/speech",
    headers={"Authorization": f"Bearer {os.environ['MISTRAL_API_KEY']}"},
    json={
        "model": "voxtral-mini-tts-3-0",
        "input": "I like tomato soup.",
        "voice_id": "gb_jane_neutral",
        "phoneme_hints": {"tomato": ["t", "ə", "m", "ɑ", "t", "oʊ"]},
        "response_format": "wav",
    },
    timeout=60,
)
response.raise_for_status()

output = Path("tomato.wav")
output.write_bytes(base64.b64decode(response.json()["audio_data"]))
print(f"Saved {output.resolve()}")
```

```typescript
import { writeFile } from "node:fs/promises";
import { resolve } from "node:path";

const response = await fetch("https://api.mistral.ai/v1/audio/speech", {
```

La voix prononce « tomato » avec les six phonèmes de l'indice et lit le reste de la phrase normalement. Quelques règles s'appliquent aux clés et aux valeurs :

- **Une clé par mot à corriger.** Ajoutez autant de mots que nécessaire au même objet.
- 
- **Les indices s'appliquent à une seule requête.** Envoyez-les avec chaque requête dont le texte contient ces mots.

<SectionTab as="h2" sectionId="phonemes">Phonèmes acceptés</SectionTab>

L'API valide chaque phonème par rapport à son inventaire IPA pris en charge. Les phonèmes invalides sont rejetés lors de l'envoi de la requête.

| Groupe | Phonèmes |
| --- | --- |
| Voyelles | `a` `e` `i` `o` `u` `æ` `ɑ` `ɔ` `ə` `ɚ` `ɛ` `ɜ` `ɪ` `ʊ` `ʌ` |
| Diphtongues | `aɪ` `aʊ` `eɪ` `oʊ` `ɔɪ` |
| Consonnes | `b` `d` `dʒ` `f` `g` `h` `j` `k` `l` `m` `n` `p` `s` `t` `tʃ` `v` `w` `z` `ð` `ŋ` `ɖ` `ɱ` `ɹ` `ɾ` `ʃ` `ʈ` `ʋ` `ʒ` `ʔ` `θ` |

:::caution
Quelques symboles diffèrent de ce que vous taperiez par habitude :

- Pour le r anglais, utilisez `ɹ`. La lettre simple `r` ne figure pas dans la liste.
- Tapez `g` avec la lettre classique du clavier, et non le caractère de l'alphabet phonétique international `ɡ`.
- Écrivez une diphtongue ou un son combiné comme `oʊ`, `tʃ` ou `dʒ` sous forme d'une seule entrée, pas en deux.
- Les marques d'accent et de longueur, comme `ˈ` ou `ː`, ne figurent pas dans la liste.
- Certains sons d'autres langues, comme le `ʁ` français ou les voyelles nasales, ne figurent pas non plus dans la liste.
:::

<SectionTab as="h2" sectionId="limits-and-errors">Limites et erreurs</SectionTab>

L'API vérifie chaque phonème de chaque indice et rejette l'intégralité de la requête si l'un d'eux est invalide :

| Situation | Ce que vous obtenez | Solution |
| --- | --- | --- |
| Un phonème ne figure pas dans la liste | Une erreur `422` dont le message liste les phonèmes acceptés | Remplacez le symbole par un phonème de [la liste](#phonemes) |
