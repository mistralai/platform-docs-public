# Quotas

Each organization has a cap on the number of managed deployments running at the same time:

| Plan | Concurrent managed deployments |
| --- | --- |
| Free | 0 |
| Pro or Team, pay-as-you-go off | 0 |
| Pay-as-you-go enabled | 3 |
| Enterprise | 10 |

Managed deployments require pay-as-you-go to be enabled on the organization, or an Enterprise plan. The Free plan, and paid Pro or Team plans without pay-as-you-go, have a cap of 0: creating a deployment fails with a `403` error. To activate pay-as-you-go, see [Subscriptions](/admin/billing-usage/subscriptions#pay-as-you-go).

If your organization is on pay-as-you-go or Enterprise and you reached the cap, creating or starting a deployment beyond it fails with a `403` error. Stop or delete a deployment to free a slot.

Mistral Cloud also picks the instance size for you. Every managed worker gets the same size, and per-deployment CPU and memory metrics are not exposed yet.
