# Référence de l’API

Consultez la référence générée de l’API Admin pour découvrir les endpoints, les corps de requête, les schémas de réponse et les exemples. La référence est générée à partir de la spécification OpenAPI.

:::info[Réservé aux plans Entreprise]
L'API administrateur n'est disponible que sur les plans Entreprise, et l'accès n'est pas en libre-service. Sur les autres plans, vous ne pouvez pas créer de clé API administrateur, et une clé API standard ne fonctionne pas avec les endpoints d'administration. Pour demander l'accès, contactez votre équipe de compte Mistral ou [notre équipe commerciale](https://mistral.ai/contact).
:::
