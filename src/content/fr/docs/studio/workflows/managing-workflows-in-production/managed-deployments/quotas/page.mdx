# Quotas

Chaque organisation dispose d'un plafond sur le nombre de déploiements gérés pouvant s'exécuter simultanément :

| Plan | Déploiements gérés simultanés |
| --- | --- |
| Gratuit | 0 |
| Pro ou Team, paiement à l'usage désactivé | 0 |
| Paiement à l'usage activé | 3 |
| Entreprise | 10 |

Les déploiements gérés nécessitent que le paiement à l'usage soit activé sur l'organisation, ou un plan Entreprise. Le plan gratuit, ainsi que les plans payants Pro ou Team sans paiement à l'usage, ont un plafond de 0 : la création d'un déploiement échoue avec une erreur `403`. Pour activer le paiement à l'usage, consultez [Abonnements](/admin/billing-usage/subscriptions#pay-as-you-go).

Si votre organisation a le paiement à l'usage ou un plan Entreprise et que vous avez atteint le plafond, la création ou le démarrage d'un déploiement au-delà de celui-ci échoue avec une erreur `403`. Arrêtez ou supprimez un déploiement pour libérer une place.

Mistral Cloud choisit également la taille d'instance pour vous. Tous les workers gérés ont la même taille, et les métriques CPU et mémoire par déploiement ne sont pas encore exposées.
