# Instructions de style

Une instruction de style décrit, dans vos propres mots, comment dire l'ensemble de l'entrée, par exemple un rendu calme et lent. Utilisez-la pour appliquer un rendu unique à l'ensemble de la sortie ; pour modifier l'émotion ou le rythme d'une partie du texte, utilisez les [balises d'émotion et de rythme](/studio/audio/text-to-speech/emotion-tags).

:::info
Pour savoir comment les instructions se comparent aux autres moyens de diriger une voix, voir [Voix](/studio/audio/concepts/voices#choose-and-direct).
:::

<SectionTab as="h2" sectionId="give-an-instruction">Donner une instruction de livraison</SectionTab>

Ajoutez `instruction` à la requête de génération de parole, à côté de `input` et de la voix. La valeur est une courte phrase en langage clair :

<Tabs groupId="code">
  <TabItem value="curl" label="curl" default>

```bash
curl -s https://api.mistral.ai/v1/audio/speech \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "voxtral-mini-tts-3-0",
    "input": "Your order shipped this morning and should arrive on Thursday.",
    "voice_id": "gb_jane_neutral",
    "instruction": "A calm, slow delivery.",
    "response_format": "wav"
  }' | jq -r '.audio_data' | base64 --decode > calm.wav
```

  </TabItem>
  <TabItem value="python" label="python">

```python
import base64
import os
from pathlib import Path

import httpx

response = httpx.post(
    "https://api.mistral.ai/v1/audio/speech",
    headers={"Authorization": f"Bearer {os.environ['MISTRAL_API_KEY']}"},
    json={
        "model": "voxtral-mini-tts-3-0",
        "input": "Your order shipped this morning and should arrive on Thursday.",
        "voice_id": "gb_jane_neutral",
        "instruction": "A calm, slow delivery.",
        "response_format": "wav",
    },
    timeout=60,
)
response.raise_for_status()

output = Path("calm.wav")
output.write_bytes(base64.b64decode(response.json()["audio_data"]))
print(f"Saved {output.resolve()}")
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { writeFileSync } from "node:fs";
import { resolve } from "node:path";

const response = await fetch("https://api.mistral.ai/v1/audio/speech", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.MISTRAL_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "voxtral-mini-tts-3-0",
    input: "Your order shipped this morning and should arrive on Thursday.",
    voice_id: "gb_jane_neutral",
    instruction: "A calm, slow delivery.",
    response_format: "wav",
  }),
});
if (!response.ok) {
  throw new Error(`${response.status} ${await response.text()}`);
}

const { audio_data } = await response.json();
const output = resolve("calm.wav");
writeFileSync(output, Buffer.from(audio_data, "base64"));
console.log(`Saved ${output}`);
```

<SectionTab as="h2" sectionId="instructions-and-tags">Instructions, balises et expressivité</SectionTab>

Trois paramètres de requête façonnent le rendu, chacun à un niveau différent :

| Paramètre | S'applique à | Détails |
| --- | --- | --- |
| `instruction` | L'ensemble de l'entrée | Cette page |
| Balises d'émotion et de rythme dans `input` | Une partie du texte | [Balises d'émotion et de rythme](/studio/audio/text-to-speech/emotion-tags) |
| `expressiveness` | Contrôle le niveau d'expressivité de la parole. Des valeurs plus élevées sacrifient la similarité et la stabilité de la voix au profit d'une interprétation plus marquée. | [Générer la parole](/studio/audio/text-to-speech/generate-speech) |

Les instructions de style ne sont pas disponibles au lancement.

<SectionTab as="h2" sectionId="limits-and-errors">Limites et erreurs</SectionTab>

Ces erreurs proviennent du champ `instruction` :

| Erreur | Cause | Solution |
| --- | --- | --- |
| 422 `Extra inputs are not permitted` | Un nom de champ mal orthographié, par exemple `instructions` | Utilisez `instruction`, au singulier. |
| 422 avec le type `string_type` | `instruction` n'est pas une chaîne de caractères | Envoyez l'instruction sous forme de texte. |
| Les instructions de style ne sont pas disponibles au lancement. | L'instruction dépasse la limite de longueur. Elle n'est pas raccourcie à votre place. | Raccourcissez l'instruction. |
| Les instructions de style ne sont pas disponibles au lancement. | Le modèle ne prend pas en charge les instructions de style. | Utilisez un modèle qui les prend en charge. |

Pour les autres erreurs de génération de parole, voir [Dépannage](/studio/audio/text-to-speech/troubleshooting).
