# Commandes et commandes slash

Utilisez les **commandes slash** et les **raccourcis clavier** pour contrôler Vibe Code directement depuis l'éditeur. Quelques commandes VS Code sont également disponibles depuis la palette de commandes pour la configuration et le débogage.

<SectionTab as="h2" sectionId="slash-commands">Commandes slash</SectionTab>

L'extension expose un sous-ensemble des commandes slash de Vibe. Tapez `/` dans le panneau Vibe pour voir les commandes disponibles. Les [Skills](/vibe/code/cli/skills) activées y apparaissent dans le même sélecteur.

| Commande | Indice de saisie | Description |
|---|---|---|
| `/help` | | Affiche les commandes et les raccourcis clavier disponibles. |
| `/compact` | Instructions optionnelles pour le résumé | Condense l'historique de la conversation en le résumant. |
| `/reload` | | Recharge la configuration, les instructions de l'agent et les compétences depuis le disque. |
| `/log` | | Affiche le chemin du répertoire contenant les journaux de la session en cours. |
| `/proxy-setup` | `CLÉ valeur`, `CLÉ` ou vide pour obtenir de l'aide | Configure les paramètres de proxy et de certificat SSL. |
| `/leanstall` | | Installe l'agent Lean 4, `leanstral`. |
| `/unleanstall` | | Désinstalle l'agent Lean 4. |
| `/data-retention` | | Affiche les informations sur la conservation des données. |
| `/mcp` | `status`, `login <alias>`, ou `logout <alias>` | Affiche l'état de connexion MCP, ou permet de se connecter à un serveur MCP OAuth ou de s'en déconnecter. |
| `/retry` | Instructions supplémentaires facultatives | Poursuit une réponse interrompue du modèle. |
| `/teleport` | | Envoie la session vers Vibe Code Web. Voir [Basculement de session de la CLI vers le Web](/vibe/code/cli/teleport-cli-web). |

Pour consulter la liste complète des commandes CLI, voir [Commandes et raccourcis](/vibe/code/cli/commands-shortcuts).

<SectionTab as="h2" sectionId="hotkeys">Raccourcis clavier</SectionTab>

Dans le panneau Vibe, `Mod` correspond à `Command` sur macOS et à `Ctrl` sur Windows ou Linux.

| Raccourci | Action |
|---|---|
| `Mod+Y` | Approuver une action d'outil. |
| `Mod+Alt+Y` | Approuver une action d'outil alternative. |
| `Mod+Shift+Y` | Approuver et appliquer un choix de permission plus large. |
| `Mod+Alt+N` | Refuser une action d'outil. |
| `Mod+N` | Démarrer une nouvelle conversation. |
| `Échap` | Annuler ou désactiver l'état de saisie en cours. |
| `Maj+Tab` | Passer en revue les modes de saisie actifs. |

<SectionTab as="h2" sectionId="cli-parity">Parité avec le CLI</SectionTab>

L'extension n'expose pas toutes les commandes slash du CLI, mais elle permet tout de même de contrôler la plupart des paramètres d'exécution via l'interface :

- **`/model` et `/thinking`** ne sont pas disponibles en tant que commandes slash. Changez le modèle actif ou le niveau de raisonnement depuis l'interface de l'extension.
- **`/resume`** n'est pas disponible en tant que commande slash, mais vous pouvez charger les sessions précédentes depuis l'interface du panneau.
- **`/rename`** a un équivalent dans l'interface du panneau. Utilisez-le pour renommer la session en cours.
- Pour les commandes restantes de session et d'exécution, utilisez la CLI : `/rewind`, `/loop`, `/voice` et l'ajout ou la consultation de serveurs MCP avec `/mcp`.

<SectionTab as="h2" sectionId="vscode-commands">Commandes VS Code</SectionTab>

Un ensemble réduit de commandes de la palette de commandes VS Code est disponible pour la configuration et le débogage.

| Commande | Fonctionnalité |
|---|---|
| **Mistral Vibe : Ouvrir Mistral Vibe** | Met l'accent sur le panneau Mistral Vibe. |
| **Mistral Vibe : Afficher les journaux** | Ouvre la sortie des journaux de l'extension. |

:::note
L'extension ne déclare pas de raccourcis clavier par défaut pour VS Code. Ajoutez des raccourcis personnalisés dans `keybindings.json` si vous souhaitez y accéder directement via le clavier.
:::
