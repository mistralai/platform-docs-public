# Commandes et raccourcis clavier

Utilisez les **commandes slash** et les **raccourcis clavier** pour contrôler une session Vibe sans quitter le terminal.

<SectionTab as="h2" sectionId="slash-commands">Commandes slash</SectionTab>

Tapez `/` dans l’invite de ligne de commande pour ouvrir le sélecteur de commandes slash. La saisie semi-automatique propose des commandes correspondantes au fur et à mesure de votre saisie. Le tableau ci-dessous répertorie les commandes intégrées.

:::tip
Les [compétences](/vibe/code/cli/skills) peuvent aussi s'exposer comme commandes slash. Si une commande `/` ne figure pas dans cette liste, elle provient probablement d'une compétence locale (vérifiez `~/.vibe/skills/` ou le répertoire `.vibe/skills/` de votre projet), ou d'un [plugin](/vibe/code/cli/plugins) lorsque son nom comporte un préfixe `namespace:`.
:::

| Commande | Alias | Description |
|---|---|---|
| `/branch` |  | Dupliquer la conversation actuelle dans une nouvelle session que vous pouvez reprendre, sans modifier cette session. Reprenez la copie avec `vibe --resume <id>`. |
| `/clear` | `/new` | Démarrer une nouvelle conversation. Vous pouvez fournir un prompt initial. |
| `/compact` |  | Réduire l'historique de conversation en le résumant. Vous pouvez fournir des instructions pour orienter le résumé |
| `/config` |  | Modifier les paramètres de configuration |
| `/copy` |  | Copier le dernier message de l'agent dans le presse-papiers |
| `/data-retention` |  | Afficher les informations sur la conservation des données |
| `/debug` |  | Afficher ou masquer la console de débogage |
| `/exit` | `:q`, `:quit`, `exit`, `quit` | Quitter l'application |
| `/help` |  | Afficher le message d'aide |
| `/leanstall` |  | Installer l'agent Lean 4 (leanstral) |
| `/log` |  | Afficher le chemin du fichier log de l'interaction actuelle |
| `/log-level` |  | Modifier le niveau de log pour cette session ou l'enregistrer dans config.toml. |
| `/loop` |  | Planifier un prompt récurrent en langage naturel, par exemple `/loop every two minutes check the build`. Demandez à l'agent de lister ou d'annuler les planifications |
| `/mcp` | `/connectors` | Parcourir les serveurs MCP et les connecteurs. Fournissez un nom pour lister ses outils. Sous-commandes : `add`, `status`, `login`, `logout`. Voir [serveurs MCP](/vibe/code/cli/mcp-servers#browse) |
| `/model` |  | Sélectionner le modèle actif. Appuyez sur `Enter` pour l'enregistrer dans votre configuration, ou sur `s` pour l'utiliser uniquement pour cette session |
| `/paste-image` |  | Coller une image du presse-papiers du système dans le prompt. Uniquement sur macOS |
| `/plugins` |  | Afficher les plugins exécutés dans cette session. Voir [Plugins](/vibe/code/cli/plugins#manage) |
| `/proxy-setup` |  | Configurer les paramètres du proxy et des certificats SSL |
| `/reload` |  | Recharger la configuration, les instructions de l'agent et les skills depuis le disque |
| `/reload-plugins` |  | Réépingler les plugins de cette session et indiquer les modifications. Voir [Plugins épinglés](/vibe/code/cli/plugins#snapshot) |
| `/remote-project` |  | Sélectionner le projet Vibe Code Web pour ce dépôt |
| `/rename` |  | Renommer la session actuelle |
| `/resume` | `/continue` | Parcourir, reprendre ou supprimer les sessions enregistrées |
| `/retry` |  | Reprendre une réponse interrompue du modèle ; vous pouvez fournir des instructions supplémentaires |
| `/rewind` |  | Revenir à un message précédent (ou appuyer deux fois sur Échap) |
| `/status` |  | Afficher les statistiques de l'agent, les détails du modèle et du fournisseur, ainsi que la source d'identifiants utilisée |
| `/teleport` |  | Basculer la session vers Vibe Code Web |
| `/theme` |  | Sélectionner le thème |
| `/thinking` |  | Sélectionner le niveau de réflexion. Appuyez sur `Enter` pour l'enregistrer dans votre configuration, ou sur `s` pour l'utiliser uniquement pour cette session |
| `/unleanstall` |  | Désinstaller l'agent Lean 4 |
| `/voice` |  | Activer ou désactiver le mode vocal (dictée avec `Ctrl+R`) et le narrateur expérimental |
| `/whoami` |  | Afficher le compte utilisateur connecté à Mistral, l'espace de travail et le plan |

<SectionTab as="h2" sectionId="keyboard-shortcuts">Raccourcis clavier</SectionTab>

:::warning
Certains raccourcis peuvent ne pas fonctionner selon la combinaison d'émulateur de terminal, de session SSH ou de multiplexeur de terminal (comme tmux). Consultez [Prise en charge des terminaux](/vibe/code/cli/terminal-support) pour connaître les terminaux recommandés et les solutions de contournement.
:::

| Raccourci | Action |
|---|---|
| `Enter` | Soumettre le message. |
| `Ctrl+J` ou `Shift+Enter` | Insérer une nouvelle ligne. `Shift+Enter` ne fonctionne que dans les terminaux qui le prennent en charge. |
| `Ctrl+C` | Si du texte est sélectionné, le copier. Sinon, effacer l'entrée. Avec une entrée vide, refuser l'approbation en attente, supprimer le message le plus récent de la file d'attente ou interrompre l'agent. Lorsque rien ne s'exécute, appuyer deux fois pour quitter. |
| `Ctrl+D` | Supprimer le caractère à droite. Avec une entrée vide, appuyer deux fois pour quitter, ou une seule fois lorsque `ask_confirmation_on_exit = false`. |
| `Ctrl+Z` | Suspendre la CLI (macOS et Linux). |
| `Escape` | Interrompre l'opération en cours ou fermer la boîte de dialogue ouverte. |
| `Escape` deux fois | Ouvrir le rewind pour revenir à un message précédent. Si l'entrée contient du texte, l'effacer à la place. |
| `Ctrl+O` | Activer ou désactiver l’affichage de la sortie des outils. |
| `Ctrl+G` | Modifier l'entrée en cours dans un éditeur externe. |
| `Ctrl+R` | Démarrer ou arrêter l'enregistrement vocal lorsque le mode vocal est activé. `Escape` annule l'enregistrement. |
| `Ctrl+Y` | Copier la sélection en cours (macOS et Linux). |
| `Ctrl+Shift+C` ou `Cmd+C` | Copier la sélection en cours. |
| `Shift+Tab` | Parcourir les agents en boucle. |
| `Shift+Up` | Faire défiler la conversation vers le haut. |
| `Shift+Down` | Faire défiler la conversation vers le bas. |
| `Cmd+\` ou `Alt+\` | Afficher ou masquer le panneau de la liste de tâches. |
| `Ctrl+\` | Activer ou désactiver la console de débogage. |

Vous pouvez également cliquer sur les options d'approbation des outils, les options de réponse aux questions et les entrées des sélecteurs, ainsi que faire glisser les barres de défilement avec la souris. Faites glisser pour sélectionner du texte : un double-clic sélectionne un mot et un triple-clic sélectionne un paragraphe. Vibe copie la sélection lorsque vous relâchez la souris, sauf si vous définissez `autocopy_to_clipboard = false`.
