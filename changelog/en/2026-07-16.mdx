- We released OCR 4.1 (`mistral-ocr-4-1`). `mistral-ocr-latest` and `mistral-ocr-4` now point to it. <Tag model/>
- The OCR API `confidence_scores_granularity` parameter now supports `"block"` granularity. `"page"` returns page-level scores only, `"block"` returns page-level and block-level scores, and `"word"` returns page-level and word-level scores. <Tag api/>
