# Formats audio

Cette page répertorie les formats audio acceptés et renvoyés par chaque API audio. Les pages consacrées aux fonctionnalités renvoient ici plutôt que de répéter ces listes.

<SectionTab as="h2" sectionId="transcription-input">Entrée de transcription</SectionTab>

Chaque mode de transcription accepte l'audio sous une forme différente :

| Mode | Comment envoyer l'audio | Formats | Détails |
| --- | --- | --- | --- |
| Transcription de fichiers | Un fichier par requête : `file` (téléchargement), `file_url` (une URL de 2 083 caractères maximum), ou `file_id` (un fichier téléchargé sur `/v1/files` avec `purpose=audio`) |  | [Transcription de fichiers](/studio/audio/speech-to-text/transcribe-files#choose-input) |
| Transcription en temps réel | Audio brut en fragments base64, décrit par `audio_format` dans `session.update` | `pcm_s16le` (PCM signé 16 bits little-endian, mono). Fréquence d'échantillonnage par défaut : 16 000 Hz.  | [Transcription en temps réel](/studio/audio/speech-to-text/transcribe-in-realtime#session-fields) |

{/* Sources: file_url maxLength 2083 and the three inputs: public/openapi.yaml (AudioTranscriptionRequest); file_id with purpose=audio tested Oct 7 (transcribe-files/input_file_id.sh). Realtime default audio_format: session.created, Oct 7 and Oct 9 probes. */}

<SectionTab as="h2" sectionId="speech-output">Sortie Speech</SectionTab>

La génération de voix renvoie l'audio au format que vous définissez avec `response_format` :

| Format | Utilisation |
| --- | --- |
| `mp3` (par défaut) | Lecture dans les navigateurs et les applications, quand la taille du fichier compte |
| `opus` | Streaming et lecture en cas de bande passante limitée |
| `wav` | Montage, ou quand vous avez besoin d'audio non compressé dans un fichier standard |
| `flac` | Archivage sans perte à une taille inférieure à celle du WAV |
| `pcm` | Pipelines bruts et passerelles de téléphonie qui acceptent des échantillons bruts, sans en-tête de fichier |

 Pour définir le format dans une requête, voir [Formats de réponse](/studio/audio/text-to-speech/generate-speech#response-formats).

Same values in RFC-555 section 3.1 and the SDK SpeechOutputFormat. The "Use it for" column is general guidance on the formats, not a Mistral-specific claim. */}

<SectionTab as="h2" sectionId="voice-agents-sdk">SDK des agents audio</SectionTab>

Le SDK Audio Agents utilise un format audio qui lui est propre, pour l'entrée et la sortie :

| --- | --- | --- |
| Interface audio personnalisée, ou audio envoyé manuellement | PCM signé 16 bits, mono, 48 kHz | [Audio personnalisé](/studio/audio/voice-agents/custom-audio) |
