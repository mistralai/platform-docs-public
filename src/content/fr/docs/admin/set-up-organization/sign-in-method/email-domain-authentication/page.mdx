# Authentification par domaine e-mail

:::info
L’authentification par domaine e-mail est disponible avec les offres Team et supérieures.
:::

L’authentification par domaine e-mail permet aux utilisateurs de rejoindre votre Organisation avec une adresse e-mail appartenant à un domaine vérifié. Lorsqu’elle est activée, ces utilisateurs peuvent rejoindre votre Organisation depuis <AppLink href="https://admin.mistral.ai/join">Join Organisation</AppLink>.

<SectionTab as="h1" sectionId="how-it-works">Fonctionnement</SectionTab>

- Les utilisateurs dont l’adresse e-mail appartient à un domaine vérifié peuvent rejoindre votre Organisation depuis <AppLink href="https://admin.mistral.ai/join">Join Organisation</AppLink>.
- Les utilisateurs **créent et gèrent toujours leurs propres identifiants** e-mail et mot de passe. Cette fonctionnalité contrôle l’appartenance à l’Organisation, pas l’authentification.
- Pour une connexion unique **sans identifiants séparés**, utilisez plutôt [SSO](/admin/set-up-organization/sign-in-method/saml-sso). Cette option nécessite une offre Enterprise.

<SectionTab as="h1" sectionId="prerequisites">Prérequis</SectionTab>

Vous devez **vérifier la propriété de votre domaine** avant d’activer cette fonctionnalité. La vérification de domaine utilise un enregistrement DNS TXT. Consultez la page [vérification de domaine](/admin/set-up-organization/verify-domain) pour les étapes de configuration complètes.

<SectionTab as="h1" sectionId="enabling">Activer l’authentification par domaine e-mail</SectionTab>

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/access" path={["Panneau d’administration", "Administration", "Access"]} />.
2. Dans la section `Domain Ownership`, trouvez le domaine vérifié que vous voulez rendre visible.
3. Activez `Discoverable` pour ce domaine.

Le Panneau d’administration affiche le message de confirmation suivant : `Email domain authentication enabled for domain.com`.

<SectionTab as="h1" sectionId="disabling">Désactiver l’authentification par domaine e-mail</SectionTab>

Vous pouvez désactiver l’authentification par domaine e-mail en désactivant `Discoverable` pour le domaine dans la section `Domain Ownership`.

- Les utilisateurs dont l’adresse e-mail appartient au domaine ne peuvent plus rejoindre automatiquement l’Organisation depuis <AppLink href="https://admin.mistral.ai/join">Join Organisation</AppLink>.
- Les membres existants ne sont pas affectés.
- Vous devez inviter les nouveaux utilisateurs manuellement, sauf si [SSO](/admin/set-up-organization/sign-in-method/saml-sso) est configuré.

:::caution
Si vous réactivez la fonctionnalité, vous devez recommencer la configuration.
:::
