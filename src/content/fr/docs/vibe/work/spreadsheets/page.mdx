# Tableurs

:::note
Les tableurs sont disponibles sur les plans payants uniquement, jusqu’à nouvel ordre.
:::

Vibe Work peut créer des tableurs avec plusieurs feuilles, des formules et des données mises en forme. Vous créez et modifiez vos tableurs directement dans Work — aucun compte Google ni Microsoft n’est nécessaire. Le résultat s’ouvre directement dans le **panneau Canvas**, où vous pouvez le consulter, l’éditer, l’exporter et le partager sans quitter la conversation.

<SectionTab as="h2" sectionId="create">Créer un tableur</SectionTab>

Demandez à Work de créer un tableur en langage naturel. Décrivez la structure, l’objectif ou les données dont vous avez besoin, et Work génère automatiquement les feuilles et les formules.

Exemples de prompts :

- *« Créer un modèle de projection financière sur 3 ans avec un compte de résultat, un tableau de flux de trésorerie et un bilan. »*
- *« Construire un suivi de projet avec des colonnes pour les tâches, le responsable, le statut, la date limite et la priorité. »*
- *« Créer un tableur de budget avec des catégories de revenus et de dépenses mensuelles. »*

Le tableur s’affiche directement dans la conversation sous forme du panneau Canvas. Un tableur peut contenir plusieurs feuilles, chacune sous forme d’un onglet distinct dans le fichier. Passez de l’une à l’autre à l’aide des onglets en bas du panneau. Cliquez sur `Agrandir` en bas du panneau pour l’ouvrir dans la vue Canvas.

<SectionTab as="h2" sectionId="edit">Modifier le tableur</SectionTab>

Vous pouvez travailler directement avec le tableur dans Canvas :

- **Cliquez sur n’importe quelle cellule** pour la sélectionner et modifier son contenu ou sa formule.
- **Demandez à Work de le modifier** dans la conversation. Par exemple, *« Ajoutez une feuille de tableau de bord qui résume les indicateurs clés »* ou *« Mets à jour le taux de taxe à 30 % »*.
- **Cliquez sur `Agrandir`** (en bas du panneau Canvas) pour ouvrir le tableur dans la vue Canvas.
- **Cliquez sur `Modifier`** (en haut à droite de la vue Canvas) pour basculer entre le mode affichage et le mode édition.

<SectionTab as="h2" sectionId="export">Exporter en Excel</SectionTab>

Pour télécharger le tableur sous forme de fichier Excel (`.xlsx`) :

Cliquez sur l’icône de téléchargement dans le coin supérieur droit du panneau Canvas.

Le fichier est téléchargé sur votre appareil et peut être ouvert dans Excel, Numbers, LibreOffice ou toute application compatible.

<SectionTab as="h2" sectionId="google-sheets">Ouvrir dans Google Sheets</SectionTab>

Pour continuer à travailler dans Google Sheets :

Cliquez sur `Ouvrir dans Google Sheets` dans le coin supérieur droit du panneau Canvas.

Le tableur s’ouvre dans un nouvel onglet dans Google Sheets. À partir de là, vous pouvez le modifier, le partager avec des collaborateurs et utiliser toutes les fonctionnalités de Google Sheets. Les modifications apportées dans Google Sheets sont indépendantes. Elles ne se synchronisent pas avec la version Canvas.

<SectionTab as="h2" sectionId="share">Partager le tableur</SectionTab>

Pour partager le tableur sous forme de lien public :

1. Cliquez sur `Partager` dans le coin supérieur droit du panneau Canvas.
2. Activez l’interrupteur `Lien accessible à tous`.
3. Cliquez sur `Copier le lien` pour copier l’URL publique dans votre presse-papiers, ou utilisez l’un des boutons `Partager vers` pour l’envoyer directement par e-mail, X, LinkedIn, Reddit ou WhatsApp.

Toute personne disposant du lien peut consulter le tableur. Vos **messages de la conversation ne sont pas partagés**. Seul le contenu du tableur est accessible via le lien.

Pour arrêter le partage, retournez à la fenêtre Partager et désactivez l’interrupteur `Lien accessible à tous`.
