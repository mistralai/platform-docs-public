# Transcription en temps réel

Cette page couvre la transcription audio en direct vers du texte via une session WebSocket, à privilégier pour les flux audio nécessitant une faible latence (par opposition aux fichiers audio enregistrés – voir [Transcrire des fichiers](Transcribe files)). À la fin de cette lecture, vous comprendrez le cycle de vie d’une session et comment contrôler la latence.

## Comprendre le cycle de vie

Avant tout code, voici le modèle mental : ouvrez une session, validez votre configuration avant le premier fragment audio, envoyez l’audio, recevez les mises à jour de transcription, finalisez, puis fermez. Chaque étape a une signification précise : quand afficher, remplacer, finaliser ou conserver les résultats.
