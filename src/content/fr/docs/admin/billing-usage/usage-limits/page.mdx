# Utilisation et limites

Utilisez `Utilisation et limites` pour comprendre comment votre Organisation consomme les services Mistral et quelles limites s'appliquent. Cette page couvre le tableau d'utilisation global, les limites de dépenses de l'Organisation, les limites de dépenses des Workspaces et les limites de débit de l'API.

<SectionTab as="h1" sectionId="open-usage-and-limits">Ouvrir Utilisation et limites</SectionTab>

Utilisez ces pages de l'Admin Panel selon ce que vous devez vérifier ou modifier :

| Tâche | Page de l'Admin Panel |
| --- | --- |
| Consulter les répartitions d'utilisation et de coût | <AppLink href="https://admin.mistral.ai/organization/usage" path={["Admin Panel", "API", "Usage"]} /> |
| Consulter les limites de débit de l'API | <AppLink href="https://admin.mistral.ai/plateforme/limits" path={["Admin Panel", "API", "Limits"]} /> |
| Définir la limite de dépenses de l'Organisation | <AppLink href="https://admin.mistral.ai/organization/billing" path={["Admin Panel", "Subscriptions", "Billing"]} /> |
| Définir une limite de dépenses de Workspace | <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Admin Panel", "Administration", "Workspaces"]} /> |

<SectionTab as="h1" sectionId="usage-dashboard">Tableau d'utilisation</SectionTab>

Le tableau d'utilisation affiche l'utilisation de l'Organisation pour une période de facturation donnée. Utilisez-le pour comprendre les dépenses, identifier les zones de forte utilisation et décider si vous devez ajuster les plafonds des Workspaces ou les limites de l'API.

Le tableau peut afficher :

- le coût total ;
- le coût par jour ;
- l'utilisation des completions ;
- l'utilisation de Vibe au-delà du quota ;
- l'utilisation d'OCR ;
- l'utilisation des Agents et Connectors ;
- l'utilisation de l'API Libraries ;
- l'utilisation Audio ;
- le stockage Document Library.

<SectionTab as="h2" variant="secondary" sectionId="usage-breakdowns">Répartitions de l'utilisation</SectionTab>

Utilisez les répartitions pour trouver l'origine de l'utilisation. Selon le service, le tableau peut répartir l'utilisation par :

- modèle ;
- tokens d'entrée et de sortie ;
- API ou capacité ;
- Workspace ;
- stockage et Libraries.

Pour le reporting d'utilisation programmatique, consultez [Mesures d'utilisation avec l'Admin API](/admin/admin-api/usage-metrics).

<SectionTab as="h1" sectionId="organization-spending-limit">Limite de dépenses de l'Organisation</SectionTab>

La limite de dépenses mensuelles de l'Organisation plafonne la consommation de l'API et de Vibe dans toute l'Organisation. Elle utilise la devise de facturation de l'Organisation.

:::warning
Si l'Organisation atteint sa limite de dépenses mensuelles, l'accès à l'API peut être suspendu jusqu'au début du mois suivant ou jusqu'à ce qu'un admin augmente la limite. Si des paiements de facture récents échouent, l'accès peut aussi être affecté jusqu'à ce que les paiements soient traités à nouveau.
:::

Les limites de dépenses des Workspaces ne peuvent pas dépasser la limite de dépenses de l'Organisation. Pour gérer les paiements, les crédits, les informations de facturation et les factures, consultez [Facturation](/admin/billing-usage/billing).

<SectionTab as="h1" sectionId="workspace-spending-limits">Limites de dépenses des Workspaces</SectionTab>

Une limite de dépenses de Workspace plafonne la consommation de l'API et de Vibe pour un Workspace. Utilisez les plafonds de Workspace pour modéliser les budgets d'équipe, les budgets de projet ou les environnements.

Pour configurer un plafond de Workspace :

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Admin Panel", "Administration", "Workspaces"]} />.
2. Sélectionnez le Workspace.
3. Ouvrez l'onglet `Settings`.
4. Définissez `Monthly spending limit`.
5. Enregistrez vos modifications.

Pour un guide consacré aux Workspaces, consultez [Utilisation et limites des Workspaces](/admin/workspaces/usage-limits).

<SectionTab as="h1" sectionId="api-rate-limits">Limites de débit de l'API</SectionTab>

Les limites de débit de l'API définissent le volume de trafic que votre Organisation peut envoyer. Elles sont affichées dans <AppLink href="https://admin.mistral.ai/plateforme/limits" path={["Admin Panel", "API", "Limits"]} />.

<SectionTab as="h2" variant="secondary" sectionId="completion-rate-limits">Limites de débit des completions</SectionTab>

Les limites de débit des completions sont listées par modèle et incluent :

- **Tokens par minute** : la limite de débit en tokens pour le modèle.
- **Requêtes par seconde** : la limite de débit en requêtes pour le modèle.

<SectionTab as="h2" variant="secondary" sectionId="audio-rate-limits">Limites audio</SectionTab>

Les limites audio s'appliquent à la consommation de l'API Audio et peuvent inclure :

- des secondes audio par minute ;
- des secondes audio par mois.

<SectionTab as="h2" variant="secondary" sectionId="ocr-rate-limits">Limites OCR des documents</SectionTab>

Les limites OCR des documents s'appliquent à la consommation de l'API OCR et peuvent inclure des pages par minute.

<SectionTab as="h2" variant="secondary" sectionId="document-limits">Limites des documents</SectionTab>

Les limites des documents contrôlent les comportements d'import et de téléchargement. Elles peuvent inclure :

- la taille maximale des fichiers importés ;
- l'autorisation de télécharger des documents depuis les Libraries.

<SectionTab as="h1" sectionId="plan-usage-and-limits">Plan, utilisation et limites</SectionTab>

Votre plan Mistral définit l'utilisation mensuelle incluse et les limites disponibles pour votre Organisation.

- **Mode gratuit** : vous pouvez créer des clés API et utiliser l'utilisation mensuelle incluse dans les limites affichées sur la page `Limits`.
- **Paiement à l'usage** : vous pouvez étendre l'utilisation au-delà de l'utilisation mensuelle incluse. Ce n'est pas un plan séparé pour l'API.

Pour connaître les tarifs actuels et la disponibilité des modèles, consultez la [tarification Mistral](https://mistral.ai/pricing/). Pour consulter votre plan, l'utilisation mensuelle incluse et les paramètres de paiement à l'usage, consultez [Abonnements](/admin/billing-usage/subscriptions).

<SectionTab as="h1" sectionId="request-higher-limits">Demander des limites plus élevées</SectionTab>

Si vous avez besoin de limites plus élevées, contactez le [support](https://help.mistral.ai) avec :

- les modèles ou API que vous prévoyez d'utiliser ;
- le nombre cible de requêtes par seconde ;
- le nombre attendu de tokens par minute et par mois ;
- une courte description de votre cas d'usage.
