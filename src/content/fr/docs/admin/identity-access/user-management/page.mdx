# Gestion des utilisateurs

Utilisez la page `Membres` pour gérer les personnes qui appartiennent à votre Organisation, leur rôle Organisation, les sièges des produits qu’elles utilisent, ainsi que les espaces de travail et les groupes auxquels elles appartiennent.

:::info
Pour inviter des membres dans Vibe, votre Organisation doit disposer d’un plan Team ou Enterprise. Pour inviter des membres avec un accès Studio et API, votre Organisation doit disposer d’un plan Scale. Vous devez avoir le rôle d’administrateur Organisation pour gérer les membres.
:::

<SectionTab as="h1" sectionId="open-members">Ouvrir la page des membres</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Panneau d’administration", "Administration", "Members"]} />.

La page `Membres` contient deux listes :

- `Utilisateurs actifs` : membres qui appartiennent déjà à l’Organisation.
- `Utilisateurs invités` : invitations en attente, y compris les invitations expirées.

Utilisez la recherche pour trouver des membres par nom de famille ou adresse e-mail. Dans `Utilisateurs actifs`, filtrez par rôle Organisation : `Admin`, `Member` ou `Billing`.

<SectionTab as="h1" sectionId="invite-members">Inviter des membres</SectionTab>

Invitez les membres manuellement lorsque votre Organisation **n’utilise pas SSO**.

:::info
Si [SAML SSO](/admin/set-up-organization/sign-in-method/saml-sso) est activé, les utilisateurs rejoignent l’Organisation via votre fournisseur d’identité configuré.
:::

Pour inviter des membres :

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Panneau d’administration", "Administration", "Members"]} />.
2. Cliquez sur `Inviter des membres`.
3. Saisissez une ou plusieurs adresses e-mail.
4. Choisissez le rôle Organisation des personnes invitées.
5. Attribuez des sièges des produits si nécessaire.
6. Envoyez les invitations.

Les personnes invitées reçoivent un e-mail avec les instructions pour rejoindre l’Organisation. Utilisez `Utilisateurs invités` pour suivre les invitations en attente et expirées.

Pour chaque invitation, vous pouvez :

- renvoyer l’invitation si elle a expiré ;
- révoquer l’invitation pour empêcher la personne invitée de rejoindre l’Organisation.

<SectionTab as="h1" sectionId="manage-members">Gérer les membres</SectionTab>

Utilisez `Utilisateurs actifs` pour gérer rapidement les membres. Depuis la liste des membres, vous pouvez :

- modifier le rôle Organisation du membre ;
- activer ou désactiver les sièges Vibe ;
- activer ou désactiver les sièges Mistral Code.

Pour accéder à plus de paramètres, cliquez sur un membre dans `Utilisateurs actifs` pour ouvrir `Détails de l’utilisateur`. Le panneau de détails vous permet de consulter le profil du membre, ses abonnements, ses espaces de travail, ses groupes et ses clés API.

<SectionTab as="h2" variant="secondary" sectionId="user-profile">Consulter le profil</SectionTab>

L’onglet `Profil` affiche :

- l’adresse e-mail ;
- le prénom et le nom ;
- l’identifiant utilisateur ;
- si le profil est géré de façon externe par SSO ou SCIM.

:::note
Si un profil est géré de façon externe, le nom et l’adresse e-mail sont synchronisés depuis votre fournisseur d’identité et ne peuvent pas être modifiés dans le Panneau Admin.
:::

<SectionTab as="h2" variant="secondary" sectionId="organization-roles">Gérer les rôles Organisation</SectionTab>

Les rôles Organisation contrôlent ce qu’un membre peut faire au niveau de l’Organisation.

| Rôle | Accès |
| --- | --- |
| `Admin` | Administration complète de l’Organisation. |
| `Billing` | Facturation, abonnements, factures, moyens de paiement et informations d’utilisation. |
| `Member` | Accès produit et paramètres du profil personnel. |

Pour une description complète des rôles, consultez [Rôles et permissions](/admin/identity-access/roles-permissions).

<SectionTab as="h2" variant="secondary" sectionId="seats-and-subscriptions">Gérer les sièges et les abonnements</SectionTab>

Utilisez `Abonnements` dans `Détails de l’utilisateur` pour consulter et gérer les sièges des produits du membre.

Les sièges peuvent inclure :

- l’offre API ;
- Vibe ;
- Mistral Code.

Lorsque SAML SSO est activé, les administrateurs Organisation peuvent activer l’**attribution automatique des sièges** depuis <AppLink href="https://admin.mistral.ai/organization/access" path={["Panneau d’administration", "Administration", "Access"]} />.

:::info
Avec l’attribution automatique des sièges, les utilisateurs reçoivent un siège lors de leur première connexion via SSO lorsqu’ils ont accès à l’Organisation et que des sièges sont disponibles.
:::

<SectionTab as="h2" variant="secondary" sectionId="workspace-access">Gérer l’accès aux espaces de travail</SectionTab>

L’onglet `Espaces de travail` dans `Détails de l’utilisateur` liste les espaces de travail auxquels le membre appartient et son rôle dans chacun d’eux.

Depuis cet onglet, vous pouvez :

- ajouter le membre à un espace de travail existant ;
- modifier le rôle du membre dans l’espace de travail ;
- retirer le membre d’un espace de travail ;
- consulter les espaces de travail du membre.

:::note
Vous pouvez ajouter un membre uniquement à un espace de travail existant. Vous ne pouvez pas retirer un membre de l’espace de travail par défaut.
:::

Les rôles d’espace de travail sont séparés des rôles Organisation. Par exemple, un membre `Billing` de l’Organisation peut aussi être `Workspace Contributor` dans un espace de travail. Consultez [Rôles et permissions](/admin/identity-access/roles-permissions) pour le détail des rôles d’espace de travail.

<SectionTab as="h2" variant="secondary" sectionId="groups">Gérer les groupes</SectionTab>

L’onglet `Groups` dans `Détails de l’utilisateur` affiche les groupes auxquels le membre appartient.

Utilisez-le pour ajouter le membre à des groupes ou consulter son appartenance aux groupes. Les groupes permettent d’attribuer les mêmes accès et rôles à plusieurs utilisateurs. Consultez [Groupes](/admin/identity-access/groups).

<SectionTab as="h2" variant="secondary" sectionId="api-keys">Consulter les clés API d’un membre</SectionTab>

L’onglet `API Keys` dans `Détails de l’utilisateur` affiche les clés API du membre et l’espace de travail auquel chaque clé appartient.

Les clés API sont associées à un espace de travail. Consultez [Clés API](/admin/identity-access/api-keys) pour les détails de gestion des clés.

<SectionTab as="h1" sectionId="remove-members">Retirer un membre</SectionTab>

Retirez un membre lorsqu’il n’a plus besoin d’accéder à l’Organisation.

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/members" path={["Panneau d’administration", "Administration", "Members"]} />.
2. Trouvez le membre dans `Utilisateurs actifs`.
3. Ouvrez le panneau `Détails de l’utilisateur` du membre.
4. Cliquez sur `Remove user` et confirmez.

Retirer un membre supprime son accès à l’Organisation et ses appartenances aux espaces de travail. Les ressources créées par le membre peuvent rester disponibles pour les autres membres de l’Organisation.

:::warning
Vous ne pouvez pas retirer le dernier administrateur Organisation. Au moins un administrateur Organisation doit rester.
:::
