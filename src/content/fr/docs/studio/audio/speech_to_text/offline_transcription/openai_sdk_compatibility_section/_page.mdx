L’endpoint de transcription Mistral utilise la même structure de requête que l’API de transcriptions audio d’OpenAI. Vous pouvez utiliser le SDK OpenAI en le configurant avec l’URL de base Mistral et en remplaçant le nom du modèle.

:::warning
Nous ne recommandons pas d’utiliser le SDK OpenAI à long terme : cette couche de compatibilité est destinée aux tests rapides et au prototypage. En production, nous recommandons d’utiliser le [SDK Mistral](/resources/sdks) pour bénéficier de la prise en charge de toutes les fonctionnalités.
:::
