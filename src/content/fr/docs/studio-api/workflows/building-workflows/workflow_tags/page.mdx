# Balises de workflow

Les workflows prennent en charge des balises de métadonnées recherchables pour le filtrage et la découverte. Les balises sont des chaînes de caractères filtrables attachées aux définitions de workflow (et non aux exécutions) et affichées dans l’interface de Studio et via l’API.

## Définir des balises

Les workflows sont créés avec des balises vides lors de l’enregistrement de l’agent, puis les utilisateurs les étiquettent via le point de terminaison de mise à jour :

```http
PUT /v1/workflows/{workflow_identifier}
```

```json
{
  "tags": ["ocr", "document-processing"]
}
```

La mise à jour des balises **remplace** la liste de balises existante. Passez une liste vide pour supprimer toutes les balises. Si vous omettez `tags` du corps de la requête, les balises existantes restent inchangées.

## Filtrer par balises

Le point de terminaison de liste accepte les balises comme paramètre de filtre avec une logique **ET** : seuls les workflows disposant de **toutes** les balises spécifiées sont retournés :

```http
GET /v1/workflows?tags=ocr&tags=document-processing
```

## Validation

| Règle | Détail |
|------|--------|
| Longueur maximale | 100 caractères par balise |
| Espaces | Supprimés des deux côtés |
| Balises vides | Refusées (y compris contenant uniquement des espaces) |
| Doublons | Dédoublonnés silencieusement |
| Nombre maximal | Aucune limite appliquée |
