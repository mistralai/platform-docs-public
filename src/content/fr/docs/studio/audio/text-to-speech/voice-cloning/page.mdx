# Clonage de la voix

Le clonage de la voix génère de la parole avec la voix de l'enregistrement que vous fournissez, sans entraînement. Clonez une voix pour une requête unique, ou enregistrez-la dans votre espace de travail et réutilisez-la via son ID.

:::info
Pour comparer une voix clonée et une voix prédéfinie, et savoir ce qu'elle conserve de son enregistrement, voir [Voix](/studio/audio/concepts/voices) dans Concepts.
:::

<SectionTab as="h2" sectionId="zero-shot-cloning">Clonage zero-shot</SectionTab>

Le clonage zero-shot reproduit une voix à partir d’un court enregistrement, sans entraînement. Utilisez l’enregistrement pour une seule requête, ou enregistrez-le comme voix dans votre espace de travail pour le réutiliser à l’aide de son identifiant.

<SectionTab as="h3" variant="secondary" sectionId="clone-for-one-request">Cloner une voix pour une seule requête</SectionTab>

<Tabs groupId="code">
  <TabItem value="curl" label="curl" default>

```bash
jq -n --arg ref_audio "$(base64 < voice_sample.mp3 | tr -d '\n')" '{
  model: "voxtral-mini-tts-3-0",
  input: "Your order shipped this morning and should arrive on Thursday.",
  ref_audio: $ref_audio,
  response_format: "wav"
}' | curl -s https://api.mistral.ai/v1/audio/speech \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d @- | jq -r '.audio_data' | base64 --decode > cloned_one_off.wav
```

  </TabItem>
  <TabItem value="python" label="python">

```python
import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

reference = Path("voice_sample.mp3")
response = client.audio.speech.complete(
    model="voxtral-mini-tts-3-0",
    input="Your order shipped this morning and should arrive on Thursday.",
    ref_audio=base64.b64encode(reference.read_bytes()).decode(),
    response_format="wav",
)

output = Path("cloned_one_off.wav")
output.write_bytes(base64.b64decode(response.audio_data))
print(f"Saved {output.resolve()}")
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { readFile, writeFile } from "node:fs/promises";
import { resolve } from "node:path";

import { Mistral } from "@mistralai/mistralai";

const client = new Mistral({ apiKey: process.env.MISTRAL_API_KEY });

const reference = "voice_sample.mp3";
const response = await client.audio.speech.complete({
  model: "voxtral-mini-tts-3-0",
  input: "Your order shipped this morning and should arrive on Thursday.",
  refAudio: (await readFile(reference)).toString("base64"),
  responseFormat: "wav",
});

const output = "cloned_one_off.wav";
await writeFile(output, Buffer.from(response.audioData, "base64"));
console.log(`Saved ${resolve(output)}`);
```

<SectionTab as="h3" variant="secondary" sectionId="save-a-cloned-voice">Enregistrer une voix clonée</SectionTab>

Créez une voix à partir de l'enregistrement, puis transmettez son ID comme `voice_id`. 

<Tabs groupId="code">
  <TabItem value="python" label="python" default>

```python
import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

sample = Path("voice_sample.mp3")
voice = client.audio.voices.create(
    name="Support agent",
    sample_audio=base64.b64encode(sample.read_bytes()).decode(),
    sample_filename=sample.name,
    languages=["en"],
)
print(f"Created voice {voice.id}")

response = client.audio.speech.complete(
    model="voxtral-mini-tts-3-0",
    input="Your order shipped this morning and should arrive on Thursday.",
    voice_id=voice.id,
    response_format="wav",
)

output = Path("cloned_saved_voice.wav")
output.write_bytes(base64.b64decode(response.audio_data))
print(f"Saved {output.resolve()}")
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { readFile, writeFile } from "node:fs/promises";
import { resolve } from "node:path";

import { Mistral } from "@mistralai/mistralai";

const client = new Mistral({ apiKey: process.env.MISTRAL_API_KEY });

const sample = "voice_sample.mp3";
const voice = await client.audio.voices.create({
  name: "Support agent",
  sampleAudio: (await readFile(sample)).toString("base64"),
  sampleFilename: sample,
  languages: ["en"],
});
console.log(`Created voice ${voice.id}`);

const response = await client.audio.speech.complete({
  model: "voxtral-mini-tts-3-0",
  input: "Your order shipped this morning and should arrive on Thursday.",
  voiceId: voice.id,
  responseFormat: "wav",
});

const output = "cloned_saved_voice.wav";
await writeFile(output, Buffer.from(response.audioData, "base64"));
console.log(`Saved ${resolve(output)}`);
```

  </TabItem>
</Tabs>

Les exemples lisent l'enregistrement à partir du fichier `voice_sample.mp3` dans le répertoire de travail.

Pour lister, renommer ou supprimer une voix enregistrée, voir [Gérer les voix](/studio/audio/text-to-speech/voices#manage-voices).
