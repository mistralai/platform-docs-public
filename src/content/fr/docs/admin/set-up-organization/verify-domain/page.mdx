# Vérifier votre domaine

La vérification de domaine prouve que vous contrôlez un ou plusieurs domaines e-mail. Elle est requise avant d’activer [l’authentification par domaine e-mail](/admin/set-up-organization/sign-in-method/email-domain-authentication), [SAML SSO](/admin/set-up-organization/sign-in-method/saml-sso) et d’autres fonctionnalités d’accès Enterprise.

<SectionTab as="h1" sectionId="verify">Vérifier un domaine</SectionTab>

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/access" path={["Panneau d’administration", "Administration", "Access"]} />.
2. Dans la section `Domain Ownership`, cliquez sur `Add Domain`.
3. Saisissez votre domaine, par exemple `yourcompany.com`.
4. Cliquez sur `Add domain`.
5. Cliquez sur `Verify domain`.
6. Copiez l’enregistrement DNS TXT fourni.
7. Chez votre fournisseur DNS ou votre bureau d’enregistrement, ajoutez un enregistrement TXT :
   - `Type` : `TXT`
   - `Host/Name` : `@` ou votre domaine. Le format exact dépend de votre fournisseur.
   - `Value` : collez le code de vérification, par exemple `mistral-domain-verification=xxxxxx`.
8. Enregistrez l’enregistrement.
9. Attendez la propagation DNS. Elle prend généralement entre 10 minutes et 24 heures.

Le Panneau d’administration met à jour le statut du domaine sur `Verified` lorsque la propagation est terminée. Vous pouvez ajouter et vérifier d’autres domaines depuis la même section `Domain Ownership`. Pour vérifier la propagation manuellement :

```bash
nslookup -type=TXT yourcompany.com
```

:::caution
Conservez l’enregistrement DNS TXT actif pour chaque domaine vérifié. Si vous supprimez un enregistrement, l’authentification par domaine e-mail, SSO ou d’autres fonctionnalités d’accès Enterprise peuvent ne plus fonctionner pour ce domaine.
:::

<SectionTab as="h1" sectionId="next-steps">Étapes suivantes</SectionTab>

Lorsque votre domaine est vérifié :

- Activez [l’authentification par domaine e-mail](/admin/set-up-organization/sign-in-method/email-domain-authentication) pour ajouter automatiquement les utilisateurs dont l’adresse e-mail appartient au domaine.
- Configurez [SAML SSO](/admin/set-up-organization/sign-in-method/saml-sso) pour authentifier les utilisateurs avec votre fournisseur d’identité. Cette option nécessite une offre Enterprise.
