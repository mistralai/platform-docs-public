# Audio

L'audio de Mistral couvre trois usages : transformer la parole en texte, transformer le texte en parole, et faire fonctionner les deux dans des conversations en direct. Les modèles Voxtral 3 transcrivent des fichiers enregistrés et des flux en direct, avec étiquettes de locuteur, horodatages et vocabulaire personnalisé. Ils génèrent de la parole avec des voix prédéfinies ou clonées, que vous dirigez avec des balises d'émotion et de rythme. Vous pouvez aussi envoyer de l'audio à un modèle de chat pour résumer ou interroger un enregistrement, et construire des agents audio qui répondent aux appelants en temps réel.

Cette section s'adresse aux développeurs qui intègrent l'audio via l'API et les SDK, et aux équipes produit qui évaluent ce que Voxtral peut faire.

:::tip
Vous n'êtes pas développeur ? Dictez des prompts et discutez avec Travail en [mode vocal](/vibe/work/voice-mode), ou analysez un enregistrement en le téléchargeant dans une conversation. sans écrire une ligne de code.
:::

<SectionTab as="h3" variant="secondary" sectionId="create-an-api-key">1. Créer une clé API</SectionTab>

Chaque requête nécessite une clé API issue d'AI Studio.

1. Sélectionnez `Créez une nouvelle clé`, donnez un nom à la clé et définissez une date d'expiration.
2. Copiez la clé. Elle ne s'affiche qu'une seule fois.
3. Stockez la clé dans la variable d'environnement `MISTRAL_API_KEY`, où les exemples la lisent :

```bash
export MISTRAL_API_KEY="your-api-key"
```

:::info
Pour des captures d'écran et toutes les options de clé, consultez [Activer Studio et générer une clé API](/getting-started/quickstarts/studio/activate-and-generate-api-key). Si votre organisation gère les clés de manière centralisée, consultez [Clés API](/admin/identity-access/api-keys) dans la documentation Admin.
:::

  <ExplorerTab value="realtime" label="Transcrire en temps réel">

Diffusez l'audio au fur et à mesure de son enregistrement et affichez la transcription pendant que le locuteur parle. Les exemples diffusent un fichier WAV au rythme du temps réel pour simuler une source en direct. La transcription en temps réel passe par un WebSocket, il n'y a donc pas d'exemple curl. Téléchargez d'abord l'<a href="/audio/chat.wav" download className="text-primary-soft hover:text-primary">enregistrement d'exemple</a>, ou récupérez-le depuis la ligne de commande :

```bash
curl -O https://docs.mistral.ai/audio/chat.wav
```

<Tabs groupId="code">
  <TabItem value="python" label="python" default>

```python
import asyncio
import os
import wave

from mistralai.client import Mistral
from mistralai.client.models import (
    AudioFormat,
    RealtimeTranscriptionError,
    TranscriptionStreamDone,
    TranscriptionStreamTextDelta,
)

AUDIO_FILE = "chat.wav"  # 16-bit mono PCM WAV

async def read_chunks(path):
    with wave.open(path, "rb") as wav:
        while chunk := wav.readframes(wav.getframerate() // 10):
            yield chunk
            await asyncio.sleep(0.1)  # send 100 ms of audio every 100 ms, like a live source

async def main():
    with wave.open(AUDIO_FILE, "rb") as wav:
        sample_rate = wav.getframerate()

    client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])
    async for event in client.audio.realtime.transcribe_stream(
        read_chunks(AUDIO_FILE),
        model="voxtral-mini-transcribe-realtime-3",
        audio_format=AudioFormat(encoding="pcm_s16le", sample_rate=sample_rate),
    ):
        if isinstance(event, TranscriptionStreamTextDelta):
            print(event.text, end="", flush=True)
        elif isinstance(event, TranscriptionStreamDone):
            print(f"\n\nFinal transcript: {event.text}")
        elif isinstance(event, RealtimeTranscriptionError):
            print(f"\nError: {event.error.message}")

asyncio.run(main())
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { readFileSync } from "node:fs";
import { setTimeout as sleep } from "node:timers/promises";

import { AudioEncoding, RealtimeTranscription } from "@mistralai/mistralai/extra/realtime";

const wav = readFileSync("chat.wav"); // 16-bit mono PCM WAV
const sampleRate = wav.readUInt32LE(24);
const pcm = wav.subarray(wav.indexOf("data") + 8);

async function* readChunks() {
  const chunkSize = (sampleRate / 10) * 2; // 100 ms of 16-bit audio
  for (let i = 0; i < pcm.length; i += chunkSize) {
    yield pcm.subarray(i, i + chunkSize);
    await sleep(100); // send 100 ms of audio every 100 ms, like a live source
  }
}

const client = new RealtimeTranscription({ apiKey: process.env.MISTRAL_API_KEY });

for await (const event of client.transcribeStream(
  readChunks(),
  "voxtral-mini-transcribe-realtime-3",
  { audioFormat: { encoding: AudioEncoding.PcmS16le, sampleRate } },
)) {
  if (event.type === "transcription.text.delta") {
    process.stdout.write(event.text);
  } else if (event.type === "transcription.done") {
    console.log(`\n\nFinal transcript: ${event.text}`);
  } else if (event.type === "error") {
    console.error(`\nError: ${JSON.stringify(event.error.message)}`);
  }
}
```

```python
import asyncio
import os

from mistralai.voice.agents import MistralVoiceAgent
from mistralai.voice.agents.audio import DefaultAudioInterface
from mistralai.voice.agents.models import (
    AudioLLMConfig,
    AudioTTSConfig,
    TranscriptEvent,
)

async def main() -> None:
    client = MistralVoiceAgent(api_key=os.environ["MISTRAL_API_KEY"])

    session = await client.connect(
        llm=AudioLLMConfig(model="mistral-small-latest"),
        tts=AudioTTSConfig(voice_id="fr_marie_neutral"),
        instructions="You are a helpful voice assistant.",
        audio_interface=DefaultAudioInterface(),
    )

    def on_transcript(event: TranscriptEvent) -> None:
        print(f"{event.role}: {event.content}")

    session.on("transcript", on_transcript)

    print("Voice agent connected. Press Ctrl+C to stop.")
    try:
        await session.wait()
    finally:
        await session.close()

asyncio.run(main())
```

```typescript
import { MistralVoiceAgent } from "@mistralai/voice-agents";
import { DefaultAudioInterface } from "@mistralai/voice-agents/audio/node";
import type { TranscriptEvent } from "@mistralai/voice-agents/types";

const client = new MistralVoiceAgent({ apiKey: process.env.MISTRAL_API_KEY! });

const session = await client.connect({
  llm: { model: "mistral-small-latest" },
  tts: { voiceId: "fr_marie_neutral" },
  instructions: "You are a helpful voice assistant.",
  audioInterface: new DefaultAudioInterface(),
});

session.on("transcript", (event: TranscriptEvent) => {
  console.log(`${event.role}: ${event.content}`);
});

console.log("Voice agent connected. Press Ctrl+C to stop.");
try {
  await session.wait();
} finally {
  await session.close();
}
```

<SectionTab as="h2" sectionId="meet-the-models">Découvrez les modèles</SectionTab>

Voxtral 3 compte cinq modèles : trois transforment la parole en texte, et deux transforment le texte en parole.

Pour choisir, partez de ce que vous avez à faire :

| Modèle | Utilisez-le pour | Chiffres clés |
| --- | --- | --- |
| Voxtral Mini Transcribe 3 (`voxtral-mini-transcribe-3-0`) | Transcrire des fichiers enregistrés, avec des étiquettes de locuteur, des horodatages de segments et un vocabulaire personnalisé | |  | |
| Voxtral Mini Transcribe Realtime 3 (`voxtral-mini-transcribe-realtime-3-0`) | Transcrire de l'audio en direct pour des sous-titres et des agents audio, avec détection des tours de parole | Latence de streaming de 80 à 1 200 ms, ou 2 400 ms, définie par session |
| Voxtral Small Transcribe 3 (`voxtral-small-transcribe-3-0`) | Transcrire des fichiers enregistrés avec une qualité supérieure | |  | |
| Voxtral TTS 3 (`voxtral-mini-tts-3-0`) | Générer de la parole à partir de texte avec des voix prédéfinies ou clonées | 5 formats de sortie, WAV à 24 kHz ; 34 balises d'émotion et 2 balises de rythme |
| Voxtral TTS Realtime 3 (`voxtral-mini-tts-realtime-3-0`) | Diffuser de la parole pour des conversations en direct |  |

Pour comparer en détail les modes, les options et les fonctionnalités, consultez [Reconnaissance vocale](/studio/audio/speech-to-text/overview) et [Synthèse vocale](/studio/audio/text-to-speech/overview).
