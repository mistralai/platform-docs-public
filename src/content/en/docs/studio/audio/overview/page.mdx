# Audio

Mistral audio covers three jobs: turning speech into text, turning text into speech, and running both in live conversations. Voxtral 3 models transcribe recorded files and live streams, with speaker labels, timestamps, and custom vocabulary. They generate speech with preset or cloned voices, which you direct with emotion and pace tags. You can also send audio to a chat model to summarize or question a recording, and build voice agents that answer callers in real time.

This section is for developers who integrate audio through the API and SDKs, and for product teams who evaluate what Voxtral can do.

:::tip
Not a developer? Dictate prompts and talk with Work in [Voice mode](/vibe/work/voice-mode), or analyze a recording by uploading it to a chat. with no code to write.
:::

<SectionTab as="h3" variant="secondary" sectionId="create-an-api-key">1. Create an API key</SectionTab>

Every request needs an API key from AI Studio.

1. Select `Create new key`, give the key a name, and set an expiration date.
2. Copy the key. It appears only once.
3. Store the key in the `MISTRAL_API_KEY` environment variable, where the examples read it:

```bash
export MISTRAL_API_KEY="your-api-key"
```

:::info
For screenshots and every key option, see [Activate Studio and generate an API key](/getting-started/quickstarts/studio/activate-and-generate-api-key). If your organization manages keys centrally, see [API keys](/admin/identity-access/api-keys) in the Admin docs.
:::

  <ExplorerTab value="realtime" label="Transcribe in realtime">

Stream audio as it's recorded and print the transcript while the speaker talks. The examples stream a WAV file at real-time pace to stand in for a live source. Realtime transcription runs over a WebSocket, so there's no curl example. Download the <a href="/audio/chat.wav" download className="text-primary-soft hover:text-primary">sample recording</a> first, or fetch it from the command line:

```bash
curl -O https://docs.mistral.ai/audio/chat.wav
```

<Tabs groupId="code">
  <TabItem value="python" label="python" default>

```python
import asyncio
import os
import wave

from mistralai.client import Mistral
from mistralai.client.models import (
    AudioFormat,
    RealtimeTranscriptionError,
    TranscriptionStreamDone,
    TranscriptionStreamTextDelta,
)

AUDIO_FILE = "chat.wav"  # 16-bit mono PCM WAV

async def read_chunks(path):
    with wave.open(path, "rb") as wav:
        while chunk := wav.readframes(wav.getframerate() // 10):
            yield chunk
            await asyncio.sleep(0.1)  # send 100 ms of audio every 100 ms, like a live source

async def main():
    with wave.open(AUDIO_FILE, "rb") as wav:
        sample_rate = wav.getframerate()

    client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])
    async for event in client.audio.realtime.transcribe_stream(
        read_chunks(AUDIO_FILE),
        model="voxtral-mini-transcribe-realtime-3",
        audio_format=AudioFormat(encoding="pcm_s16le", sample_rate=sample_rate),
    ):
        if isinstance(event, TranscriptionStreamTextDelta):
            print(event.text, end="", flush=True)
        elif isinstance(event, TranscriptionStreamDone):
            print(f"\n\nFinal transcript: {event.text}")
        elif isinstance(event, RealtimeTranscriptionError):
            print(f"\nError: {event.error.message}")

asyncio.run(main())
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { readFileSync } from "node:fs";
import { setTimeout as sleep } from "node:timers/promises";

import { AudioEncoding, RealtimeTranscription } from "@mistralai/mistralai/extra/realtime";

const wav = readFileSync("chat.wav"); // 16-bit mono PCM WAV
const sampleRate = wav.readUInt32LE(24);
const pcm = wav.subarray(wav.indexOf("data") + 8);

async function* readChunks() {
  const chunkSize = (sampleRate / 10) * 2; // 100 ms of 16-bit audio
  for (let i = 0; i < pcm.length; i += chunkSize) {
    yield pcm.subarray(i, i + chunkSize);
    await sleep(100); // send 100 ms of audio every 100 ms, like a live source
  }
}

const client = new RealtimeTranscription({ apiKey: process.env.MISTRAL_API_KEY });

for await (const event of client.transcribeStream(
  readChunks(),
  "voxtral-mini-transcribe-realtime-3",
  { audioFormat: { encoding: AudioEncoding.PcmS16le, sampleRate } },
)) {
  if (event.type === "transcription.text.delta") {
    process.stdout.write(event.text);
  } else if (event.type === "transcription.done") {
    console.log(`\n\nFinal transcript: ${event.text}`);
  } else if (event.type === "error") {
    console.error(`\nError: ${JSON.stringify(event.error.message)}`);
  }
}
```

<Tabs groupId="code">
  <TabItem value="python" label="python" default>

```python
import asyncio
import os

from mistralai.voice.agents import MistralVoiceAgent
from mistralai.voice.agents.audio import DefaultAudioInterface
from mistralai.voice.agents.models import (
    AudioLLMConfig,
    AudioTTSConfig,
    TranscriptEvent,
)

async def main() -> None:
    client = MistralVoiceAgent(api_key=os.environ["MISTRAL_API_KEY"])

    session = await client.connect(
        llm=AudioLLMConfig(model="mistral-small-latest"),
        tts=AudioTTSConfig(voice_id="fr_marie_neutral"),
        instructions="You are a helpful voice assistant.",
        audio_interface=DefaultAudioInterface(),
    )

    def on_transcript(event: TranscriptEvent) -> None:
        print(f"{event.role}: {event.content}")

    session.on("transcript", on_transcript)

    print("Voice agent connected. Press Ctrl+C to stop.")
    try:
        await session.wait()
    finally:
        await session.close()

asyncio.run(main())
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { MistralVoiceAgent } from "@mistralai/voice-agents";
import { DefaultAudioInterface } from "@mistralai/voice-agents/audio/node";
import type { TranscriptEvent } from "@mistralai/voice-agents/types";

const client = new MistralVoiceAgent({ apiKey: process.env.MISTRAL_API_KEY! });

const session = await client.connect({
  llm: { model: "mistral-small-latest" },
  tts: { voiceId: "fr_marie_neutral" },
  instructions: "You are a helpful voice assistant.",
  audioInterface: new DefaultAudioInterface(),
});

session.on("transcript", (event: TranscriptEvent) => {
  console.log(`${event.role}: ${event.content}`);
});

console.log("Voice agent connected. Press Ctrl+C to stop.");
try {
  await session.wait();
} finally {
  await session.close();
}
```

<SectionTab as="h2" sectionId="meet-the-models">Meet the models</SectionTab>

Voxtral 3 has five models: three turn speech into text, and two turn text into speech.

<SectionTab as="h3" variant="secondary" sectionId="models-speech-to-text">Speech to text</SectionTab>

<TempAudioModelCards group="stt" />

<SectionTab as="h3" variant="secondary" sectionId="models-text-to-speech">Text to speech</SectionTab>

<TempAudioModelCards group="tts" />

To choose, start from what you need to do:

| Model | Use it to | Key numbers |
| --- | --- | --- |
| Voxtral Mini Transcribe 3 (`voxtral-mini-transcribe-3-0`) | Transcribe recorded files, with speaker labels, segment timestamps, and custom vocabulary | 65,536-token context, shared by the audio and the vocabulary list |
| Voxtral Mini Transcribe Realtime 3 (`voxtral-mini-transcribe-realtime-3-0`) | Transcribe live audio for captions and voice agents, with turn detection | Streaming delay from 80 to 1,200 ms, or 2,400 ms, set per session |
| Voxtral Small Transcribe 3 (`voxtral-small-transcribe-3-0`) | Transcribe recorded files at higher quality | Transcription only at launch |
| Voxtral TTS 3 (`voxtral-mini-tts-3-0`) | Generate speech from text with preset or cloned voices | 5 output formats, WAV at 24 kHz; 34 emotion tags and 2 pace tags |
| Voxtral TTS Realtime 3 (`voxtral-mini-tts-realtime-3-0`) | Stream speech for live conversations |  |

To compare modes, options, and features in detail, see [Speech to Text](/studio/audio/speech-to-text/overview) and [Text to Speech](/studio/audio/text-to-speech/overview).

{/* Key numbers sources (Oct 8): context limit = Oct 7 STT test "Prompt 38268 > 32768 maximum context length" (code 3059), model not recorded in the handoff; streaming delay = realtime session.update accepted 80-1200 and 2400 ("trained values"); TTS = 5 response formats tested, WAV 24 kHz mono 16-bit, 34 emotion tags (Rakesh, Oct 7), pace tags slow / fast (Rakesh, Oct 9; medium dropped). No latency figure: none is scoped and sourced yet. */}
