# Rétention zéro des données

La rétention zéro des données (ZDR) contrôle si les entrées et sorties d'API prises en charge sont conservées après que Mistral a renvoyé une réponse. Utilisez ce guide pour comprendre ce que couvre ZDR, ce qu'il exclut, et comment le demander pour votre Organisation.

:::info
**ZDR est disponible avec les offres payantes pour les appels API sans état pris en charge.** Il donne aux Organisations éligibles un contrôle plus strict sur la conservation des entrées et sorties d'API après traitement.
:::

<SectionTab as="h1" sectionId="what-zdr-covers">Ce que couvre la rétention zéro des données</SectionTab>

Lorsque ZDR est activé, Mistral **ne stocke pas les entrées et sorties des requêtes API prises en charge**, et n'en conserve aucun log au-delà de la durée nécessaire pour générer la sortie.

ZDR s'applique aux **appels API sans état**. Un appel API sans état n'a pas besoin de stocker votre entrée ou votre sortie après la fin de la requête pour que l'endpoint fonctionne.

<SectionTab as="h1" sectionId="supported-endpoints">Endpoints API pris en charge</SectionTab>

ZDR s'applique aux endpoints API sans état suivants :

| Endpoint | Couverture |
|----------|----------|
| `/v1/chat/completions` | Complétions de chat |
| `/v1/fim/completions` | Complétions fill-in-the-middle |
| `/v1/embeddings` | Embeddings |
| `/v1/moderations` | Modération de texte |
| `/v1/chat/moderations` | Modération de chat |
| `/v1/classifications` | Classification de texte |
| `/v1/chat/classifications` | Classification de chat |
| `/v1/ocr` | OCR |
| `/v1/audio/speech` | Génération vocale |
| `/v1/audio/transcriptions` | Transcription vocale |

ZDR s'applique aux endpoints pris en charge sur l'ensemble des modèles, **à l'exception des modèles Labs**.

<SectionTab as="h1" sectionId="what-zdr-does-not-cover">Ce que la rétention zéro des données ne couvre pas</SectionTab>

ZDR **ne s'applique pas aux API avec état ni aux produits avec état**. Ces services doivent stocker des données pour fonctionner, par exemple pour afficher l'historique, maintenir l'état de l'application, traiter des fichiers ou récupérer des documents plus tard.

ZDR ne s'applique pas à :

- Agents
- Fichiers de traitement batch
- Conversations
- Libraries
- `/v1/files`
- Vibe Work
- Chat

Par exemple, l'API Files stocke les fichiers téléchargés et n'entre **pas dans le champ de ZDR**. Vibe Work et Chat stockent les données de conversation afin que vous puissiez accéder à vos travaux précédents et à l'historique de conversation.

<SectionTab as="h1" sectionId="vibe-cli">Application de ZDR à Vibe CLI</SectionTab>

Vibe CLI s'exécute sur votre machine et appelle des API sans état. Si ZDR est activé pour votre Organisation avec une offre payante, les appels API de Vibe CLI suivent les règles ZDR de **l'endpoint API sous-jacent**.

<SectionTab as="h1" sectionId="training-opt-out">Différence entre ZDR et la désactivation de l'entraînement</SectionTab>

ZDR et la désactivation de l'entraînement sont **deux contrôles distincts**.

| Contrôle | Ce qu'il contrôle |
|---------|------------------|
| ZDR | Si les entrées et sorties d'API prises en charge sont conservées après traitement. |
| Désactivation de l'entraînement | Si les données éligibles peuvent être utilisées pour améliorer les modèles Mistral. |

**Vous n'avez pas besoin de ZDR pour refuser l'utilisation de vos données dans l'entraînement des modèles.** Pour gérer les préférences d'entraînement, consultez [Confidentialité et contrôles des données](/admin/monitor-comply/privacy-data-controls).

<SectionTab as="h1" sectionId="request-zdr">Demander la rétention zéro des données</SectionTab>

Pour demander ZDR, contactez le support via [l'article du Centre d'aide ZDR](https://help.mistral.ai/en/articles/347612-can-i-activate-zero-data-retention-zdr) ou [contactez le support Mistral](https://help.mistral.ai/en/articles/347458-how-do-i-contact-support).

Ajoutez suffisamment de détails sur le motif légitime de votre demande ZDR. **Nous examinons chaque demande et pouvons l'approuver ou la refuser.**

<SectionTab as="h1" sectionId="check-zdr-status">Vérifier si ZDR est actif</SectionTab>

Une fois votre demande approuvée, **ZDR apparaît dans les paramètres de confidentialité d'Admin**.

Ouvrez <AppLink href={"https://" + "admin.mistral.ai/plateforme/privacy"} path={["Admin Panel", "API", "Privacy"]} />.

Si ZDR n'apparaît pas dans vos paramètres de confidentialité, votre demande n'a pas encore été traitée. Si votre demande est rejetée, vous recevez un e-mail.
