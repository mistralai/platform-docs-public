# Gérer les espaces de travail avec l’API Admin

Gérez les espaces de travail et leurs membres à l’aide de l’API Admin.

:::info[Réservé aux plans Entreprise]
L'API administrateur n'est disponible que sur les plans Entreprise, et l'accès ne s'obtient pas en libre-service. Sur les autres plans, vous ne pouvez pas créer de clé API administrateur, et une clé API standard ne fonctionne pas avec les endpoints d'administration. Pour demander l'accès, contactez votre équipe de compte Mistral ou [notre équipe commerciale](https://mistral.ai/contact).
:::

<SectionTab as="h1" sectionId="before-you-start">Avant de commencer</SectionTab>

Toutes les requêtes utilisent l’URL de base `https://console.mistral.ai/api/admin` et une clé API Admin dans l’en-tête `x-api-key`. Consultez [Authentification et clés API Admin](/admin/admin-api/authentication).

<SectionTab as="h1" sectionId="workspace-roles">Rôles d’espace de travail</SectionTab>

Utilisez le champ pluriel `role_names` pour attribuer les rôles d’espace de travail. Listez les rôles disponibles et leurs UUID avec `GET /api/admin/roles`. Consultez [Gérer les groupes et les rôles](/admin/admin-api/manage-groups-roles#roles) pour la liste complète des rôles.

:::note
Les champs singuliers `role` et `role_name` sont obsolètes. Préférez les champs pluriels `roles` et `role_names`.
:::

<SectionTab as="h1" sectionId="list-workspaces">Lister les espaces de travail</SectionTab>

L’endpoint accepte les paramètres de requête `is_archived`, `page`, `page_size` et `search`.

```bash
curl "https://api.mistral.ai/v1/admin/workspaces?page=1&page_size=50" \
  -H "x-api-key: $ADMIN_API_KEY"
```

<SectionTab as="h1" sectionId="create-workspace">Créer un espace de travail</SectionTab>

`name` et `admin_user_id` sont obligatoires. Les champs `description`, `icon` et `add_all_org_members` sont facultatifs.

```bash
curl -X POST https://api.mistral.ai/v1/admin/workspaces \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{
    "name": "MySpace",
    "description": "Small Workspace",
    "icon": "",
    "add_all_org_members": false,
    "admin_user_id": "<USER_UUID>"
  }'
```

La réponse inclut l’`uuid` de l’espace de travail.

<SectionTab as="h1" sectionId="update-workspace">Mettre à jour un espace de travail</SectionTab>

```bash
curl -X PATCH https://api.mistral.ai/v1/admin/workspaces/<WORKSPACE_UUID> \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"name": "Renamed Workspace", "description": "Updated description"}'
```

<SectionTab as="h1" sectionId="delete-workspace">Supprimer un espace de travail</SectionTab>

```bash
curl -X DELETE https://api.mistral.ai/v1/admin/workspaces/<WORKSPACE_UUID> \
  -H "x-api-key: $ADMIN_API_KEY"
```

<SectionTab as="h1" sectionId="members">Gérer les membres</SectionTab>

Ajoutez ou mettez à jour des membres avec un tableau `members`. Chaque objet doit inclure `user_uuid` et `role_names`.

```bash
# Add members
curl -X POST https://api.mistral.ai/v1/admin/workspaces/<WORKSPACE_UUID>/add-users \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"members": [{"user_uuid": "<USER_UUID>", "role_names": ["user"]}]}'

# Add or update members (idempotent)
curl -X PATCH https://api.mistral.ai/v1/admin/workspaces/<WORKSPACE_UUID>/users \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"members": [{"user_uuid": "<USER_UUID>", "role_names": ["workspace_admin"]}]}'
```

<SectionTab as="h2" variant="secondary" sectionId="remove-members">Retirer des membres</SectionTab>

Cette opération retire les utilisateurs listés de l’espace de travail et supprime leurs permissions dans cet espace.

```bash
curl -X DELETE https://api.mistral.ai/v1/admin/workspaces/<WORKSPACE_UUID>/remove-users \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"members": [{"user_uuid": "<USER_UUID_1>"}, {"user_uuid": "<USER_UUID_2>"}]}'
```
