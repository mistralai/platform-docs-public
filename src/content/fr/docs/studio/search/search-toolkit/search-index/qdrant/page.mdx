# Qdrant

[Qdrant](https://qdrant.tech/) est un moteur de recherche vectorielle open source. Le plugin Qdrant l’intègre comme backend d’index de recherche pour Search Toolkit. Il implémente les protocoles `VectorStoreIndex`, `NavigableIndex` et `PatchableIndex`, et fournit la gestion de schéma pour vos collections Qdrant.

<CommunityPlugin />

- **PyPI** : `mistralai-search-toolkit-plugins-qdrant` — [pypi.org/project/mistralai-search-toolkit-plugins-qdrant](https://pypi.org/project/mistralai-search-toolkit-plugins-qdrant/)
- **Source et documentation** : [github.com/qdrant-labs/mistral-qdrant-plugin](https://github.com/qdrant-labs/mistral-qdrant-plugin)

Installez le plugin avec `uv` ou `pip` :

```bash
uv add mistralai-search-toolkit-plugins-qdrant
```

Pour les étapes d’installation, la configuration et l’utilisation, consultez le dépôt du plugin.
