# Commandes et raccourcis clavier

Utilisez les **commandes slash** et les **raccourcis clavier** pour contrôler une session Vibe sans quitter le terminal.

<SectionTab as="h2" sectionId="slash-commands">Commandes slash</SectionTab>

Tapez `/` dans l’invite de ligne de commande pour ouvrir le sélecteur de commandes slash. La saisie semi-automatique propose des commandes correspondantes au fur et à mesure de votre saisie. Le tableau ci-dessous répertorie les commandes intégrées.

:::tip
[Skills](/vibe/code/cli/skills) can also expose themselves as slash commands. If you see a `/` command that isn't in this list, it likely comes from a local skill (check `~/.vibe/skills/` or your project's `.vibe/skills/`).
:::

| Commande | Alias | Description |
|---|---|---|
| `/branch` |  | Dupliquer la conversation actuelle dans une nouvelle session que vous pouvez reprendre, sans modifier cette session. Reprenez la copie avec `vibe --resume <id>`. |
| `/clear` | `/new` | Démarrer une nouvelle conversation. Vous pouvez fournir un prompt initial. |
| `/compact` |  | Réduire l'historique de conversation en le résumant. Vous pouvez fournir des instructions pour orienter le résumé |
| `/config` |  | Modifier les paramètres de configuration |
| `/copy` |  | Copier le dernier message de l'agent dans le presse-papiers |
| `/data-retention` |  | Afficher les informations sur la conservation des données |
| `/debug` |  | Afficher ou masquer la console de débogage |
| `/exit` | `:q`, `:quit`, `exit`, `quit` | Quitter l'application |
| `/help` |  | Afficher le message d'aide |
| `/leanstall` |  | Installer l'agent Lean 4 (leanstral) |
| `/log` |  | Afficher le chemin du fichier log de l'interaction actuelle |
| `/log-level` |  | Modifier le niveau de log pour cette session ou l'enregistrer dans config.toml. |
| `/loop` |  | Planifier un prompt récurrent en langage naturel : `/loop [schedule] [prompt]` |
| `/mcp` | `/connectors` | Afficher les serveurs MCP et les connecteurs disponibles. Fournissez un nom pour lister les outils ; sous-commandes : add \<url> [--transport http\|streamable-http], status, login \<alias>, logout \<alias> |
| `/model` |  | Sélectionner le modèle actif |
| `/paste-image` |  | Coller une image du presse-papiers du système dans le prompt |
| `/plugins` |  | Afficher les plugins utilisés par cette session |
| `/proxy-setup` |  | Configurer les paramètres du proxy et des certificats SSL |
| `/reload` |  | Recharger la configuration, les instructions de l'agent et les skills depuis le disque |
| `/reload-plugins` |  | Fixer à nouveau les versions des plugins de cette session et signaler les modifications |
| `/remote-project` |  | Sélectionner le projet Vibe Code Web pour ce dépôt |
| `/rename` |  | Renommer la session actuelle |
| `/resume` | `/continue` | Parcourir, reprendre ou supprimer les sessions enregistrées |
| `/retry` |  | Reprendre une réponse interrompue du modèle ; vous pouvez fournir des instructions supplémentaires |
| `/rewind` |  | Revenir à un message précédent (ou appuyer deux fois sur Échap) |
| `/skills` |  | Parcourir, importer et gérer les skills |
| `/status` |  | Afficher les statistiques de l'agent et les détails du modèle et du fournisseur |
| `/teleport` |  | Basculer la session vers Vibe Code Web |
| `/theme` |  | Sélectionner le thème |
| `/thinking` |  | Sélectionner le niveau de réflexion |
| `/todo` |  | Afficher la liste de tâches actuelle |
| `/unleanstall` |  | Désinstaller l'agent Lean 4 |
| `/voice` |  | Configurer les paramètres de voix |
| `/whoami` |  | Afficher le compte utilisateur connecté à Mistral, l'espace de travail et le plan |

<SectionTab as="h2" sectionId="keyboard-shortcuts">Raccourcis clavier</SectionTab>

:::warning
Some shortcuts may not work in every combination of terminal emulator, SSH session, or terminal multiplexer (such as tmux). For the best experience, we recommend [Ghostty](https://ghostty.org/), [Kitty](https://sw.kovidgoyal.net/kitty/), [WezTerm](https://wezterm.org/), or [iTerm2](https://iterm2.com/).
:::

| Raccourci | Action |
|---|---|
| `Ctrl+C` | Si du texte est sélectionné, le copier. Sinon, effacer la saisie. Avec une saisie vide, quitter ou interrompre l’opération en cours. |
| `Ctrl+D` | Supprimer le caractère à droite ou quitter si la saisie est vide. |
| `Ctrl+Z` | Suspendre le CLI. |
| `Escape` | Interrompre l’opération en cours. |
| `Ctrl+O` | Activer ou désactiver l’affichage de la sortie des outils. |
| `Ctrl+Y` | Copier la sélection en cours. |
| `Ctrl+Shift+C` | Copier la sélection en cours. |
| `Shift+Tab` | Passer en revue les modes ou agents disponibles. |
| `Shift+Up` | Faire défiler la conversation vers le haut. |
| `Shift+Down` | Faire défiler la conversation vers le bas. |
| `Ctrl+G` | Modifier le plan actuel dans un éditeur externe. |
| `Ctrl+\` | Activer ou désactiver la console de débogage. |
| `Alt+Up` (`Option+Up` sur macOS) | Revenir au message précédent. |
| `Ctrl+P` | Revenir au message précédent. |
| `Alt+Down` (`Option+Down` sur macOS) | Aller au message suivant après un retour en arrière. |
| `Ctrl+N` | Aller au message suivant après un retour en arrière. |
