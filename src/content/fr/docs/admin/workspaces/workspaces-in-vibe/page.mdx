# Espaces de travail dans Vibe

Vibe utilise l’espace de travail actif comme contexte pour ce qu’un utilisateur peut voir et faire. Changer d’espace de travail modifie les conversations, les projets, les outils, les Connecteurs, les paramètres des fonctionnalités et les politiques disponibles pour cet utilisateur.

Ce guide explique comment la sélection d’un espace de travail affecte les utilisateurs Vibe et ce que les administrateurs peuvent configurer depuis le Panneau d’administration.

<SectionTab as="h1" sectionId="user-impact">Ce qui change pour les utilisateurs Vibe</SectionTab>

Tout dans Vibe est rattaché à un espace de travail.

L’espace de travail actif affecte :

- **Historique de conversation** : les conversations et les artefacts appartiennent à l’espace de travail où ils ont été créés.
- **Projets** : les définitions de projet et leurs conversations liées sont rattachées à l’espace de travail.
- **Compétences et agents** : les utilisateurs voient les Compétences et agents disponibles dans l’espace de travail actif.
- **Tâches planifiées** : les planifications s’exécutent dans l’espace de travail où elles ont été créées.
- **Authentifications de Connecteur** : les utilisateurs connectent des services tiers dans un contexte d’espace de travail.
- **Instructions personnalisées** : les instructions peuvent varier selon l’espace de travail.

<SectionTab as="h1" sectionId="switch-workspace">Changer d’espace de travail dans Vibe</SectionTab>

Les utilisateurs changent d’espace de travail en sélectionnant le nom de leur Organisation dans le coin inférieur gauche de Vibe. Le sélecteur affiche l’espace de travail actuel, les autres espaces de travail de la même Organisation et les autres Organisations auxquelles ils appartiennent.

Changer d’espace de travail réinitialise le contexte actif dans les onglets ouverts. Pour consulter le guide utilisateur complet, consultez [Changer d’Organisation ou d’espace de travail](/vibe/work/switch-organization-workspace).

<SectionTab as="h1" sectionId="admin-settings">Paramètres d’administration pour Vibe</SectionTab>

Les administrateurs Organisation configurent les paramètres d’espace de travail liés à Vibe depuis <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Espaces de travail"]} />.

<SectionTab as="h2" variant="secondary" sectionId="feature-toggles">Paramètres des fonctionnalités</SectionTab>

Dans les paramètres de l’espace de travail, les administrateurs peuvent activer ou désactiver des fonctionnalités Vibe pour un espace de travail.

- Mode Travail
- Agents
- Canvas
- Interpréteur de code
- Recherche approfondie
- Génération d’images
- Souvenirs
- Mode Réflexion
- Recherche web

:::warning
La désactivation d’une fonctionnalité la retire de Vibe pour tous les membres de cet espace de travail. Utilisez ce réglage lorsqu’un espace de travail a besoin de contrôles plus stricts, par exemple pour du travail interne sensible.
:::

<SectionTab as="h2" variant="secondary" sectionId="retention-policy">Politique de conservation des conversations</SectionTab>

Utilisez `Politique de conservation des conversations` pour supprimer automatiquement les conversations d’un espace de travail et leurs artefacts après 30, 90, 180 ou 365 jours, ou jamais.

:::info
Vous pouvez sélectionner uniquement des valeurs plus strictes que <AppLink href="https://admin.mistral.ai/vibe/privacy" path={["Panneau d’administration", "Vibe", "Confidentialité"]} />.
:::

<SectionTab as="h2" variant="secondary" sectionId="conversation-tracing">Traçage des conversations</SectionTab>

Utilisez `Traçage des conversations` pour collecter les traces, l’utilisation de tokens et les métriques d’erreur des conversations dans un espace de travail. Les données sont disponibles dans [Observability](/studio/observability) dans Studio.

<SectionTab as="h2" variant="secondary" sectionId="connectors">Connecteurs</SectionTab>

Les administrateurs peuvent gérer les Connecteurs et les outils de Connecteur disponibles dans Vibe et Studio pour chaque espace de travail. Consultez [Connecteurs](/admin/identity-access/connectors).

<SectionTab as="h2" variant="secondary" sectionId="member-access">Accès des membres</SectionTab>

Les administrateurs contrôlent quels membres peuvent accéder à un espace de travail et quels rôles d’espace de travail ils reçoivent. Consultez [Rôles et permissions](/admin/identity-access/roles-permissions) pour les détails des rôles.
