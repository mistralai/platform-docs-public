The Mistral transcription endpoint follows the same request structure as the OpenAI audio transcriptions API. You can use the OpenAI SDK by pointing it at the Mistral base URL and swapping the model name.

:::warning
We don't recommend using the OpenAI SDK for long-term use. This compatibility layer targets quick testing and prototyping. For production usage, we recommend using the [Mistral SDK](/resources/sdks) for full feature support.
:::
