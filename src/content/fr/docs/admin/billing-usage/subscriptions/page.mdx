# Abonnements

Utilisez la page `Abonnements` pour consulter les offres et les sièges actifs dans votre Organisation. La page Admin présente séparément les abonnements aux produits pour Vibe et Mistral Code de l’offre API utilisée pour Studio et l’utilisation de l’API.

Pour les détails des offres et les tarifs à jour, utilisez les pages publiques de tarification :

- [Tarifs Vibe](https://mistral.ai/pricing/)
- [Tarifs API et modèles](https://mistral.ai/pricing/#api)

<SectionTab as="h1" sectionId="open-subscriptions">Ouvrir les abonnements</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/subscriptions" path={["Panneau d’administration", "Subscriptions", "Plans"]} />.

Dans `Abonnements`, vous pouvez consulter :

- l’abonnement Vibe et les sièges ;
- l’`Offre API`, y compris les modes `Gratuit` et `Scale` ;
- les sièges Mistral Code ;
- les paramètres de paiement à l’usage pour la CLI Vibe.

<SectionTab as="h1" sectionId="vibe-plans">Offres Vibe</SectionTab>

Les offres Vibe contrôlent l’accès aux fonctionnalités et aux sièges Vibe. Dans Admin, vous pouvez voir combien de sièges Team sont utilisés et disponibles.

Pour les fonctionnalités, tarifs et limites des offres, consultez [Tarifs Vibe](https://mistral.ai/pricing/).

:::tip
Les étudiants et les enseignants peuvent vérifier leur éligibilité à une réduction dans [l’article sur la réduction étudiant et enseignant](https://help.mistral.ai/en/articles/698530-i-m-a-student-or-a-teacher-am-i-eligible-for-a-discount).
:::

<SectionTab as="h1" sectionId="api-plan">API Plan</SectionTab>

L’offre API contrôle l’utilisation de Studio et de l’API. Elle est séparée de l’abonnement Vibe.

Vous pouvez consulter votre offre API depuis <AppLink href="https://admin.mistral.ai/subscriptions" path={["Panneau d’administration", "Subscriptions", "Subscriptions"]} />, dans l’onglet `Offre API`.

<SectionTab as="h2" variant="secondary" sectionId="free-mode">Mode Free</SectionTab>

Le mode `Gratuit` vous permet de créer des clés API et d’utiliser le niveau gratuit dans les limites affichées sur la page [Utilisation et limites](/admin/billing-usage/usage-limits). Cet usage gratuit est inclus avec votre abonnement Vibe si vous en avez un. Il est disponible par défaut si vous n’en avez pas.

<SectionTab as="h2" variant="secondary" sectionId="scale-plan">Plan Scale</SectionTab>

`Scale` est l’offre API avec paiement à l’usage. Elle donne accès à l’utilisation payante de l’API et à des limites plus élevées, y compris les modèles de pointe, les agents, le fine-tuning et les fonctionnalités en préversion ou en version bêta.

Pour les tarifs exacts des modèles, les limites incluses et la disponibilité des fonctionnalités, consultez [Tarifs API et modèles](https://mistral.ai/pricing/#api).

Pour passer à Scale, ouvrez la [page de mise à niveau Scale](https://console.mistral.ai/upgrade/subscribe?via=subscriptions).

<SectionTab as="h1" sectionId="mistral-code">Mistral Code et Vibe Code</SectionTab>

Certaines Organisations affichent encore des sièges Mistral Code. Les sièges Mistral Code sont des sièges Enterprise d’une offre antérieure pour l’assistant de code. Vibe Code couvre la CLI, les extensions d’éditeur et les processus de développement.

Si vous devez modifier le nombre de sièges Mistral Code Enterprise, contactez le [support](https://help.mistral.ai).
