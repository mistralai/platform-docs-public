# Le panneau d'administration

Le <AppLink href="https://admin.mistral.ai">panneau d’administration</AppLink> centralise l’administration de votre Organisation. Utilisez-le pour configurer votre Organisation, gérer les accès et suivre l’utilisation.

<SectionTab as="h2" sectionId="open-admin">Ouvrir le panneau d’administration</SectionTab>

Vous pouvez ouvrir panneau d’administration de deux façons :

- Accédez directement au <AppLink href="https://admin.mistral.ai">panneau d’administration</AppLink>.
- Depuis Vibe ou Studio, ouvrez le menu principal et sélectionnez `Admin`.

:::info
Vous n’avez pas besoin de vous reconnecter. Les sessions sont partagées entre Vibe, Studio et le panneau d’administration.
:::

:::note
Vous devez disposer du rôle d’administrateur Organisation ou d’administrateur d’espace de travail pour accéder au panneau d’administration. Les pages et les actions disponibles dépendent de votre rôle.
:::

<SectionTab as="h2" sectionId="how-admin-fits-together">Organisation des ressources dans le panneau d’administration</SectionTab>

Les équipes utilisent Vibe pour travailler avec les modèles Mistral et les outils de développement, et Studio pour créer des applications avec les API et services Mistral. Admin permet de gérer les ressources utilisées par ces produits. Vous y définissez les accès, l’organisation des équipes et des espaces de travail, le suivi de l’utilisation et les politiques applicables.

Le panneau d’administration repose sur trois concepts :

- **Organisation** : compte principal de votre entreprise.
- **Espaces de travail** : environnements séparés qui organisent les équipes, les produits et les budgets.
- **Membres** : personnes qui appartiennent à cette Organisation.

Les membres appartiennent à une Organisation et accèdent à un ou plusieurs espaces de travail grâce à des rôles, des groupes et des règles d’accès.

<SectionTab as="h3" variant="secondary" sectionId="organization-level-settings">Paramètres au niveau Organisation</SectionTab>

Les paramètres au niveau Organisation s’appliquent à toute l’Organisation, notamment les paramètres d’accès, de facturation et de conformité :

- [Vérifiez votre domaine](/admin/set-up-organization/verify-domain) avant de configurer les méthodes de connexion.
- [Configurez SAML SSO](/admin/set-up-organization/sign-in-method/saml-sso) si votre Organisation utilise la connexion unique.
- [Gérez les abonnements](/admin/billing-usage/subscriptions) et la [facturation](/admin/billing-usage/billing).
- [Consultez les journaux d’audit](/admin/monitor-comply/audit-logs/overview) et les [contrôles de confidentialité](/admin/monitor-comply/privacy-data-controls).

<SectionTab as="h3" variant="secondary" sectionId="members-roles-and-groups">Membres, rôles et groupes</SectionTab>

Les membres sont les personnes de votre Organisation. Les rôles définissent ce qu’un membre peut voir ou modifier, et les sièges contrôlent l’accès aux produits payants. Pour les étapes de configuration, consultez [Gestion des utilisateurs](/admin/identity-access/user-management).

:::tip
Utilisez le contrôle d’accès basé sur les rôles (`RBAC`) pour accorder uniquement les permissions nécessaires à chaque personne. Les groupes permettent de gérer l’accès de plusieurs membres à la fois.
:::

<SectionTab as="h3" variant="secondary" sectionId="workspaces">Espaces de travail</SectionTab>

Les espaces de travail séparent les équipes, les produits, les environnements ou les unités commerciales au sein de la même Organisation. Chaque espace de travail peut avoir ses propres membres, son utilisation et ses limites.

Utilisez les espaces de travail lorsque des équipes ont besoin de budgets distincts, d’un suivi d’utilisation, de limites d’accès ou de ressources produit séparées. Pour les détails de configuration, consultez [Créer votre premier espace de travail](/admin/workspaces/your-first-workspace).

<SectionTab as="h2" sectionId="get-started">Commencer</SectionTab>
