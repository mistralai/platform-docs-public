# interpréteur de code

:::note
L’interpréteur de code est disponible uniquement avec les offres payantes.
:::

L’interpréteur de code vous permet d’**exécuter du code directement dans Vibe Work**. Il s’exécute dans une sandbox native qui prend en charge Python et TypeScript, et remplace l’ancien interpréteur de code de Chat avec les mêmes fonctionnalités.

Vous n’êtes pas développeur ? Aucun problème. Décrivez ce que vous voulez en langage naturel, et le mode Travail génère et exécute le code pour vous.

:::info
Le code s’exécute dans un **environnement sécurisé et isolé**, sans accès à Internet. Il ne peut pas accéder à votre système ni à des services externes. Les packages courants d’analyse de données sont préinstallés (pandas, numpy, matplotlib pour Python ; bibliothèques de graphiques pour TypeScript). Les fichiers téléchargés sont disponibles uniquement pour la conversation en cours.
:::

<SectionTab as="h2" sectionId="use-cases">Cas d’utilisation courants</SectionTab>

L’interpréteur de code combine la polyvalence de Travail avec la précision de l’exécution du code. Il convient notamment pour :

- **Analyse de données** : explorez des fichiers CSV, XLSX ou JSON. Résumez, filtrez, signalez les valeurs aberrantes ou nettoyez les valeurs manquantes.
- **Graphiques et visuels** : générez des courbes, des histogrammes, des diagrammes circulaires ou d’autres visualisations à partir de vos données.
- **Calculs** : traitez des formules, des modèles financiers ou des conversions d’unités avec une précision vérifiée.
- **Transformations de fichiers** : convertissez des formats, fusionnez des ensembles de données ou exportez les résultats traités sous forme de fichiers téléchargeables.

:::note
L’utilisation de l’interpréteur de code est **soumise à des limites de débit** selon votre plan. Pour plus de détails, consultez notre [page des tarifs](https://mistral.ai/pricing).
:::

<SectionTab as="h2" sectionId="running-code">Exécuter du code</SectionTab>

Décrivez ce que vous voulez **en langage naturel**, et Travail écrit puis exécute le code pour vous.

```text
Load this CSV and show the top 5 rows, then plot sales by month.
```

Le code s’exécute dans la sandbox et renvoie des tableaux, des figures ou des fichiers directement dans la conversation. Vous pouvez poursuivre l’échange pour affiner les résultats, ajuster les filtres ou demander des explications sur le fonctionnement du code.

:::info
L’interpréteur de code ne peut pas récupérer des fichiers directement depuis des URL. Si vos données sont en ligne, récupérez-les en local, puis téléchargez le fichier dans la conversation. Vous pouvez aussi activer [Recherche sur le Web](/vibe/work/web-search-open-url) et demander au mode Travail de récupérer les données avant d’exécuter le code.
:::

<SectionTab as="h2" sectionId="working-with-files">Travailler avec des fichiers</SectionTab>

Téléchargez des fichiers avec le bouton `+` dans la barre d’outils du chat. Formats pris en charge :

- **Documents** : PDF, Word (`.docx`, `.doc`), PowerPoint (`.pptx`, `.ppt`), ODT, EPUB, RTF
- **Feuilles de calcul** : Excel (`.xlsx`, `.xls`), CSV, ODS, Numbers
- **Images** : PNG, JPEG, WebP, GIF
- **Texte et balisage** : TXT, Markdown, RST, LaTeX
- **Formats de données** : JSON, JSONL, XML, YAML
- **Fichiers de code** : Python, JavaScript/TypeScript, Java, Go, Rust, C/C++, Ruby, PHP, SQL, et bien d’autres
- **E-mail** : EML, MSG

Exemples de prompts :

- *« Résume cette feuille de calcul et signale les valeurs aberrantes. »*
- *« Nettoie ce CSV, corrige les valeurs manquantes et exporte un nouveau fichier. »*
- *« Extrais tous les e-mails de ce PDF et donne-moi un CSV. »*

:::note
Pour plus de détails et pour les workflows avancés, consultez l’article [Fichiers et Canvas](/vibe/work/files-and-canvas).
:::

<SectionTab as="h2" sectionId="tips-for-better-results">Conseils pour de meilleurs résultats</SectionTab>

- **Soyez précis.** Pour les graphiques ou les tableaux, indiquez les noms des colonnes, les filtres et le format de sortie souhaité.
- **Demandez des explications.** Essayez *« Explique les étapes et affiche le code »* pour comprendre ce qui se passe.
- **Procédez par itérations.** Poursuivez avec des demandes pour affiner la sortie (par exemple, *« Ajoute maintenant une moyenne glissante et nomme les axes. »*)
- **Testez avec des fichiers plus petits.** Si vous atteignez une limite, téléchargez un échantillon pour tester votre approche, puis passez à des fichiers plus volumineux.
- **Évitez de partager des secrets.** Ne partagez jamais de clés API ni d’identifiants dans le chat ou dans le code.
