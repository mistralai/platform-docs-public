# Abonnements

Utilisez la page `Abonnements` pour consulter l’offre Mistral, les sièges, l’utilisation mensuelle incluse et les paramètres de paiement à l’usage actifs dans votre Organisation. Les offres Mistral sont globales : la même offre s’applique à Vibe, à Studio et à l’API.

Pour les détails des offres et les tarifs à jour, consultez [Tarifs Mistral](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="open-subscriptions">Ouvrir les abonnements</SectionTab>

Ouvrez <AppLink href="https://admin.mistral.ai/subscription" path={["Panneau d’administration", "Abonnement"]} />.

Dans `Abonnements`, vous pouvez consulter :

- votre offre Mistral et vos sièges ;
- l’utilisation mensuelle incluse ;
- l’utilisation estimée en cours ;
- les paramètres de paiement à l’usage ;
- les sièges Mistral Code, le cas échéant.

<SectionTab as="h1" sectionId="mistral-plan">Offre Mistral</SectionTab>

Votre offre Mistral contrôle l’accès à Vibe, à Studio et à l’API. Les offres disponibles incluent le mode Gratuit, Pro, Education, Team et Enterprise.

Le mode Gratuit est l’état par défaut des nouveaux comptes. Les offres payantes ajoutent des sièges, des fonctionnalités et une utilisation mensuelle incluse. Pour les fonctionnalités, tarifs et limites des offres, consultez [Tarifs Mistral](https://mistral.ai/pricing/).

:::tip
Les étudiants et les enseignants peuvent vérifier leur éligibilité à une réduction dans [l’article sur la réduction étudiant et enseignant](https://help.mistral.ai/en/articles/698530-i-m-a-student-or-a-teacher-am-i-eligible-for-a-discount).
:::

<SectionTab as="h1" sectionId="included-monthly-usage">Utilisation mensuelle incluse</SectionTab>

Chaque offre Mistral inclut une utilisation mensuelle partagée entre Studio, l’API et Vibe Code. L’utilisation consomme d’abord cette allocation mensuelle.

Lorsque votre utilisation mensuelle incluse est épuisée, l’accès dépend des paramètres de votre offre. Si le paiement à l’usage est activé, l’utilisation supplémentaire est déduite de vos crédits prépayés. S’il n’est pas activé, l’utilisation peut s’arrêter jusqu’à la prochaine période de facturation ou jusqu’à ce qu’un administrateur modifie les paramètres.

<SectionTab as="h1" sectionId="pay-as-you-go">Paiement à l’usage</SectionTab>

Le paiement à l’usage vous permet d’aller au-delà de l’utilisation mensuelle incluse. Il ne s’agit pas d’une offre API ou Vibe distincte.

Le paiement à l’usage est prépayé : votre Organisation a donc besoin de crédits avant de l’activer. Les crédits peuvent être achetés ou obtenus avec un code cadeau. Pour plus de détails, consultez [Crédits](/admin/billing-usage/billing#credits).

Pour activer le paiement à l’usage, ouvrez <AppLink href="https://admin.mistral.ai/subscription" path={["Panneau d’administration", "Abonnement"]} />.

Pour les tarifs exacts des modèles, les limites incluses et la disponibilité des fonctionnalités, consultez [Tarifs Mistral](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="mistral-code">Mistral Code et Vibe Code</SectionTab>

Certaines Organisations affichent encore des sièges Mistral Code. Les sièges Mistral Code sont des sièges Enterprise d’une offre antérieure pour l’assistant de code. Vibe Code couvre la CLI, les extensions d’éditeur et les processus de développement.

Si vous devez modifier le nombre de sièges Mistral Code Enterprise, contactez le [support](https://help.mistral.ai).

<SectionTab as="h1" sectionId="manage-subscription">Gérer un abonnement</SectionTab>

Utilisez <AppLink href="https://admin.mistral.ai/subscription" path={["Panneau d’administration", "Abonnement"]} /> pour gérer votre offre Mistral, vos sièges, l’utilisation mensuelle incluse et les paramètres de paiement à l’usage.
