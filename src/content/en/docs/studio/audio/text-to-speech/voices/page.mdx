# Voices

This page lists the preset voices you can pass to a speech request, and shows how to list, hear, create, and manage voices through the API.

:::info
For what a voice sets and how preset, cloned, and saved voices differ, see [Voices](/studio/audio/concepts/voices) in Concepts.
:::

<SectionTab as="h2" sectionId="use-a-voice-id">Use a voice ID</SectionTab>

Pass the voice ID as `voice_id` in a speech request. A preset voice has a slug, such as `gb_jane_neutral` or `voice_478`. A voice saved in your workspace has no slug: use the ID that the API returns when you create it. If the ID doesn't match any voice, the request fails with a `404` error.

:::info
For a complete request, see the [quickstart](/studio/audio/text-to-speech/quickstarts/generate-speech) or [Speech generation](/studio/audio/text-to-speech/generate-speech).
:::

<SectionTab as="h2" sectionId="manage-voices">Manage voices</SectionTab>

The voices API covers the preset voices and the voices saved in your workspace. The following table shows what each operation applies to.

{/* SDK METHOD COLUMN (Gregory, Oct 9): the method names are the Python SDK's (mistralai 3.x). The TypeScript SDK 2.7.0 has no voices.search: its voices.list uses the v1 endpoint and drops the type field, so the TypeScript tab calls GET /v2/audio/voices with fetch. Revisit the column and the voices.search note when the TypeScript SDK catches up. */}

| Operation | SDK method | Applies to |
| --- | --- | --- |
| List voices | `voices.search` | Preset voices and your saved voices. The `type` field tells them apart: `preset` or `custom`. |
| Hear a voice | `voices.get_sample_audio` |  |
| Create a voice | `voices.create` | A new saved voice, cloned from a recording |
| Get, rename, delete | `voices.get`, `voices.update`, `voices.delete` | Your saved voices |

```python
import os

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

page = client.audio.voices.search(page_size=50)
while page is not None:
    for voice in page.result.data:
        languages = ", ".join(voice.languages or []) or "-"
        print(f"{voice.slug or voice.id:<38} {voice.name:<28} {voice.type:<7} {languages}")
    page = page.next()
```

```typescript
const apiKey = process.env.MISTRAL_API_KEY;

let pageToken: string | undefined;
do {
  const url = new URL("https://api.mistral.ai/v2/audio/voices");
  url.searchParams.set("page_size", "50");
  if (pageToken) url.searchParams.set("page_token", pageToken);

  const response = await fetch(url, { headers: { Authorization: `Bearer ${apiKey}` } });
  if (!response.ok) throw new Error(`${response.status}: ${await response.text()}`);
  const page = await response.json();

  for (const voice of page.data) {
    const languages = (voice.languages ?? []).join(", ") || "-";
    console.log(`${(voice.slug ?? voice.id).padEnd(38)} ${voice.name.padEnd(28)} ${voice.type.padEnd(7)} ${languages}`);
  }
  pageToken = page.next_page_token || undefined;
} while (pageToken);
```

from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

response = client.audio.voices.get_sample_audio(voice_id="gb_jane_neutral")

import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

sample = Path("voice_sample.mp3")
voice = client.audio.voices.create(
    name="Support agent",
    sample_audio=base64.b64encode(sample.read_bytes()).decode(),
    sample_filename=sample.name,
    languages=["en"],
)
print(f"Created voice {voice.id} ({voice.name})")

import os

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

voice = client.audio.voices.update(voice_id=voice_id, name="Support agent (EU)")

print(f"Deleted {voice_id}")

The examples read the recording from `voice_sample.mp3` in the working directory, and the voice ID to manage from the `VOICE_ID` environment variable. Saved voices carry a `retention_notice` field (default 30 days, min 1, max 365). Set it when creating or updating a voice via the API. Voices created from the AI Studio UI default to 30 days.

:::note
To list voices, use `voices.search`. The SDK marks `voices.list` as deprecated.
:::

:::info
For the recording to provide and how to use a cloned voice, see [Voice cloning](/studio/audio/text-to-speech/voice-cloning).
:::

Saved voices can be shared within your workspace. Sharing is managed in AI Studio: workspace admins control whether a voice is private or shared with the workspace. The `sharing_scope` field in the voice list response indicates the current scope (`private`, `workspace`, or `global`). The sharing API endpoints are internal for now; sharing is done through the AI Studio interface.
