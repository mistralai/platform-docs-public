# Gérer les utilisateurs avec l’API Admin

Gérez les membres de votre Organisation à l’aide de l’API Admin. Pour un processus d’intégration complet, consultez [Provisionnement des utilisateurs](/admin/admin-api/user-provisioning).

<SectionTab as="h1" sectionId="before-you-start">Avant de commencer</SectionTab>

Toutes les requêtes utilisent l’URL de base `https://console.mistral.ai/api/admin` et une clé API Admin dans l’en-tête `x-api-key`. Consultez [Authentification et clés API Admin](/admin/admin-api/authentication).

<SectionTab as="h1" sectionId="organization-roles">Rôles Organisation</SectionTab>

Utilisez le champ pluriel `role_names` pour attribuer des rôles Organisation. Les noms acceptés sont `member`, `billing_manager` et `organization_admin`. Vous pouvez aussi transmettre les UUID des rôles dans `roles`. Listez-les avec `GET /api/admin/roles`.

:::note
Les champs singuliers `role` et `role_name` sont obsolètes. Préférez les champs pluriels `roles` et `role_names`, qui permettent d’attribuer plusieurs rôles.
:::

<SectionTab as="h1" sectionId="list-users">Lister les utilisateurs</SectionTab>

L’endpoint accepte les paramètres de requête `page`, `page_size` et `email`.

```bash
curl "https://console.mistral.ai/api/admin/users?page=1&page_size=50" \
  -H "x-api-key: $ADMIN_API_KEY"
```

<SectionTab as="h2" variant="secondary" sectionId="get-user">Consulter un utilisateur</SectionTab>

```bash
curl https://console.mistral.ai/api/admin/users/<USER_UUID> \
  -H "x-api-key: $ADMIN_API_KEY"
```

<SectionTab as="h1" sectionId="create-users">Créer des utilisateurs</SectionTab>

Envoyez un tableau d’utilisateurs. Chaque objet doit inclure `email`, `first_name` et `last_name`. Définissez les rôles avec `role_names` et l’accès aux produits avec `subscription_types` (`CHAT`, `MISTRAL_CODE`).

```bash
curl -X POST https://console.mistral.ai/api/admin/users \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '[
    {"email": "ada@example.com", "first_name": "Ada", "last_name": "Lovelace", "role_names": ["organization_admin"]},
    {"email": "alan@example.com", "first_name": "Alan", "last_name": "Turing", "role_names": ["member"], "subscription_types": ["CHAT", "MISTRAL_CODE"]}
  ]'
```

La réponse associe chaque adresse e-mail à l’ID de l’utilisateur créé. Les utilisateurs créés se connectent en saisissant leur adresse e-mail et en suivant la procédure de récupération du compte.

<SectionTab as="h1" sectionId="update-user">Mettre à jour un utilisateur</SectionTab>

Modifiez les rôles ou les abonnements aux produits d’un utilisateur.

```bash
curl -X PATCH https://console.mistral.ai/api/admin/users/<USER_UUID> \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"role_names": ["member"], "subscription_types": ["CHAT"]}'
```

<SectionTab as="h1" sectionId="delete-user">Supprimer un utilisateur</SectionTab>

```bash
curl -X DELETE https://console.mistral.ai/api/admin/users/<USER_UUID> \
  -H "x-api-key: $ADMIN_API_KEY"
```

<SectionTab as="h1" sectionId="invitations">Invitations</SectionTab>

Invitez les utilisateurs par e-mail au lieu de les créer directement. Le champ `email` est obligatoire. Il accepte une adresse ou plusieurs adresses séparées par des virgules ou des sauts de ligne. Les champs facultatifs incluent `role_names`, `subscription_types`, `workspace_uuids` et `email_language`.

```bash
# Créer une invitation
curl -X POST https://console.mistral.ai/api/admin/users-invite \
  -H "Content-Type: application/json" \
  -H "x-api-key: $ADMIN_API_KEY" \
  -d '{"email": "grace@example.com", "role_names": ["member"], "workspace_uuids": ["<WORKSPACE_UUID>"]}'

# Lister les invitations
curl https://console.mistral.ai/api/admin/users-invite \
  -H "x-api-key: $ADMIN_API_KEY"

# Supprimer une invitation
curl -X DELETE https://console.mistral.ai/api/admin/users-invite/<INVITATION_UUID> \
  -H "x-api-key: $ADMIN_API_KEY"
```
