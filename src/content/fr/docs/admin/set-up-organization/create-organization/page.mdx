# Créer votre Organisation

Lorsque vous vous inscrivez à Mistral, une Organisation est créée automatiquement. Pour créer une autre Organisation, par exemple pour séparer un compte personnel d’un compte d’entreprise, suivez ces étapes.

<SectionTab as="h1" sectionId="create">Créer une Organisation</SectionTab>

1. Dans Studio, cliquez sur le nom de votre Organisation.
2. Dans la section `Organisations`, cliquez sur `Add`.
3. Saisissez un nom pour l’Organisation.
4. Acceptez les conditions d’utilisation.
5. Cliquez sur `Create Organisation`.

La nouvelle Organisation vous attribue le rôle `Admin` et crée un espace de travail par défaut.

<SectionTab as="h1" sectionId="view-organization-details">Consulter les détails de l’Organisation</SectionTab>

Une fois l’Organisation créée, utilisez la page `Your Organisation` pour vérifier son nom, son identifiant et le nombre de membres actifs.

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization" path={["Panneau d’administration", "Administration", "Organisation"]}/>.
2. Consultez `Active members` pour voir combien de membres actifs appartiennent à l’Organisation.
3. Vérifiez votre `Organisation ID`.
4. Consultez ou mettez à jour l’`Organisation name`.

:::tip
Gardez votre `Organisation ID` à portée de main. Vous en avez besoin pour automatiser l’administration avec l’[API Admin](/admin/admin-api/overview) ou pour aider le [support](https://help.mistral.ai/en/articles/347458-how-do-i-contact-support) à identifier votre Organisation.
:::

<SectionTab as="h1" sectionId="delete-organization">Supprimer une Organisation</SectionTab>

La section `Danger zone` dans les paramètres de l’Organisation permet de supprimer définitivement une Organisation.

:::danger
La suppression d’une Organisation est définitive. Cette action supprime l’Organisation et ses ressources, données, espaces de travail, clés API, paramètres, historique d’utilisation et autres contenus associés. Elle **ne supprime pas les comptes utilisateur** des anciens membres.
:::

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization" path={["Panneau d’administration", "Administration", "Organisation"]} />.
2. Accédez à la section `Danger zone`.
3. Cliquez sur `Delete Organisation`.
4. Confirmez la suppression.

<SectionTab as="h1" sectionId="next-steps">Étapes suivantes</SectionTab>

Après avoir créé votre Organisation, vous pouvez :

- [Configurer la facturation](/admin/billing-usage/billing) : ajoutez un moyen de paiement pour activer l’accès API au-delà du niveau gratuit.
- [Vérifier votre domaine](/admin/set-up-organization/verify-domain) : requis pour activer l’authentification par domaine e-mail ou SSO.
- [Inviter des membres](/admin/identity-access/user-management) : ajoutez des utilisateurs et attribuez des rôles.
