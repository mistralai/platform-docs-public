# Groupes d’utilisateurs

Un groupe d’utilisateurs est un ensemble d’utilisateurs identifié par un nom et géré comme une seule entité. Au lieu d’accorder l’accès à un espace de travail utilisateur par utilisateur, vous attribuez le groupe à l’espace de travail en une seule opération. Chaque membre obtient alors l’accès avec le rôle que vous choisissez.

Vous pouvez créer et gérer des groupes depuis <AppLink href="https://admin.mistral.ai/organization/groups" path={["Panneau d’administration", "Administration", "Groups"]} /> ou avec l’[API Admin](/admin/admin-api/manage-groups-roles).

<SectionTab as="h1" sectionId="how-it-works">Fonctionnement des groupes d’utilisateurs</SectionTab>

- Un groupe regroupe des utilisateurs sous un nom et une description.
- Vous ajoutez ou retirez des membres à l’aide de leur identifiant utilisateur.
- Vous attribuez un groupe à un espace de travail avec un rôle. Chaque membre actuel du groupe obtient accès à cet espace de travail avec ce rôle.
- Un groupe peut être attribué à plusieurs espaces de travail, et un utilisateur peut appartenir à plusieurs groupes.

<SectionTab as="h1" sectionId="groups-workspaces-roles">Groupes, espaces de travail et rôles</SectionTab>

Les groupes d’utilisateurs s’ajoutent au modèle d’accès existant :

- **Organisation** : compte de niveau supérieur auquel les utilisateurs appartiennent.
- **Espace de travail** : environnement isolé avec ses propres membres, clés API et utilisation. Chaque membre a un rôle d’espace de travail.
- **Groupe d’utilisateurs** : moyen d’attribuer le même accès à plusieurs utilisateurs dans un espace de travail, avec le rôle choisi.

Lorsque vous attribuez un groupe à un espace de travail, vous définissez le rôle d’espace de travail appliqué à ses membres. Consultez [Votre premier espace de travail](/admin/workspaces/your-first-workspace) pour comprendre le fonctionnement des rôles d’espace de travail, et [Rôles et permissions](/admin/identity-access/roles-permissions) pour les noms de rôles et les champs API.

<SectionTab as="h1" sectionId="externally-managed-groups">Groupes gérés de façon externe</SectionTab>

Si votre Organisation utilise un fournisseur d’identité avec SSO ou le provisionnement SCIM, certains groupes et membres peuvent être gérés de façon externe. Votre fournisseur d’identité est alors la source de référence pour leur identité, leur appartenance ou leur cycle de vie.

Les utilisateurs et groupes gérés de façon externe ne peuvent pas être modifiés directement dans Mistral pour les champs contrôlés par le fournisseur d’identité. Gérez ces champs dans votre fournisseur d’identité. Les modifications sont appliquées à Mistral lors de la synchronisation suivante.

<SectionTab as="h1" sectionId="typical-workflow">Workflow courant</SectionTab>

1. Créez un groupe.
2. Ajoutez des membres au groupe.
3. Attribuez le groupe à un espace de travail avec un rôle.

Pour les appels API correspondants, consultez [Gérer les groupes et les rôles](/admin/admin-api/manage-groups-roles) et [Provisionnement des utilisateurs](/admin/admin-api/user-provisioning).
