# Utilisation et limites

Utilisez la page `Utilisation et limites` pour comprendre comment votre Organisation consomme les services Mistral et quelles limites s’appliquent. Cette page couvre le tableau de bord d’utilisation global, les limites de dépenses de l’Organisation, les limites de dépenses des espaces de travail et les limites de débit API.

<SectionTab as="h1" sectionId="open-usage-and-limits">Ouvrir l’utilisation et les limites</SectionTab>

Utilisez ces pages du Panneau Admin selon ce que vous devez vérifier ou modifier :

| Tâche | Page du Panneau Admin |
| --- | --- |
| Consulter les ventilations d’utilisation et de coûts | <AppLink href="https://admin.mistral.ai/organization/usage" path={["Panneau d’administration", "API", "Usage"]} /> |
| Consulter les limites de débit API | <AppLink href="https://admin.mistral.ai/plateforme/limits" path={["Panneau d’administration", "API", "Limits"]} /> |
| Définir la limite de dépenses de l’Organisation | <AppLink href="https://admin.mistral.ai/organization/billing" path={["Panneau d’administration", "Subscriptions", "Billing"]} /> |
| Définir la limite de dépenses d’un espace de travail | <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Workspaces"]} /> |

<SectionTab as="h1" sectionId="usage-dashboard">Tableau de bord d’utilisation</SectionTab>

Le tableau de bord d’utilisation affiche l’utilisation de l’Organisation pour une période de facturation sélectionnée. Utilisez-le pour comprendre les dépenses, identifier les services qui génèrent le plus d’utilisation et décider s’il faut ajuster les plafonds des espaces de travail ou les limites API.

Le tableau de bord peut afficher :

- le coût total ;
- le coût par jour ;
- l’utilisation des complétions ;
- l’utilisation Vibe hors quota ;
- l’utilisation OCR ;
- l’utilisation des agents et Connecteurs ;
- l’utilisation de l’API des Libraries ;
- l’utilisation audio ;
- le stockage des documents dans les Libraries.

<SectionTab as="h2" variant="secondary" sectionId="usage-breakdowns">Ventilations d’utilisation</SectionTab>

Utilisez les ventilations pour trouver l’origine de l’utilisation. Selon le service, le tableau de bord peut ventiler l’utilisation par :

- modèle ;
- tokens d’entrée et de sortie ;
- API ou capacité ;
- espace de travail ;
- stockage et Libraries.

Pour les rapports d’utilisation avec l’API Admin, consultez [Métriques d’utilisation avec l’API Admin](/admin/admin-api/usage-metrics).

<SectionTab as="h1" sectionId="organization-spending-limit">Limite de dépenses de l’Organisation</SectionTab>

La limite de dépenses mensuelle de l’Organisation plafonne la consommation API et Vibe dans toute l’Organisation. Elle utilise la devise de facturation de l’Organisation.

:::warning
Si l’Organisation atteint sa limite de dépenses mensuelle, l’accès API peut être suspendu jusqu’au début du mois suivant ou jusqu’à ce qu’un administrateur augmente la limite. En cas d’échec du paiement d’une facture récente, l’accès peut aussi être affecté jusqu’au traitement du paiement.
:::

Les limites de dépenses des espaces de travail ne peuvent pas dépasser la limite de dépenses de l’Organisation. Pour gérer les paiements, crédits, informations de facturation et factures, consultez [Facturation](/admin/billing-usage/billing).

<SectionTab as="h1" sectionId="workspace-spending-limits">Limites de dépenses des espaces de travail</SectionTab>

Une limite de dépenses d’espace de travail plafonne la consommation API et Vibe pour un espace de travail. Utilisez les plafonds d’espace de travail pour définir des budgets par équipe, projet ou environnement.

Pour configurer un plafond d’espace de travail :

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Workspaces"]} />.
2. Sélectionnez l’espace de travail.
3. Ouvrez l’onglet `Paramètres`.
4. Définissez `Limite de dépenses mensuelle`.
5. Enregistrez vos modifications.

Pour un guide centré sur les espaces de travail, consultez [Utilisation et limites des espaces de travail](/admin/workspaces/usage-limits).

<SectionTab as="h1" sectionId="api-rate-limits">Limites de débit API</SectionTab>

Les limites de débit API définissent le volume de trafic que votre Organisation peut envoyer. Elles s’affichent dans <AppLink href="https://admin.mistral.ai/plateforme/limits" path={["Panneau d’administration", "API", "Limits"]} />.

<SectionTab as="h2" variant="secondary" sectionId="completion-rate-limits">Limites de débit des complétions</SectionTab>

Les limites de débit des complétions sont listées par modèle et incluent :

- **Tokens par minute** : limite de débit de tokens pour le modèle.
- **Requêtes par seconde** : limite de débit des requêtes pour le modèle.

<SectionTab as="h2" variant="secondary" sectionId="audio-rate-limits">Limites audio</SectionTab>

Les limites audio s’appliquent à la consommation de l’API audio et peuvent inclure :

- secondes audio par minute ;
- secondes audio par mois.

<SectionTab as="h2" variant="secondary" sectionId="ocr-rate-limits">Limites OCR des documents</SectionTab>

Les limites OCR des documents s’appliquent à la consommation de l’API OCR et peuvent inclure un nombre de pages par minute.

<SectionTab as="h2" variant="secondary" sectionId="document-limits">Limites des documents</SectionTab>

Les limites des documents définissent les limites d’importation et de téléchargement des documents. Elles peuvent inclure :

- la taille maximale des fichiers importés ;
- la possibilité pour les utilisateurs de télécharger des documents depuis Libraries.

<SectionTab as="h1" sectionId="api-plan-and-tiers">Offre API et niveaux d’utilisation</SectionTab>

Votre offre API affecte les limites disponibles pour votre Organisation.

- Le mode `Gratuit` permet de créer des clés API et d’utiliser le niveau gratuit dans les limites affichées sur la page `Limites`.
- `Scale` est l’offre API avec paiement à l’usage. Elle donne accès à l’utilisation payante de l’API et à des limites plus élevées.

Pour les tarifs API actuels et la disponibilité des modèles, consultez [Tarifs API et modèles](https://mistral.ai/pricing/#api). Pour consulter votre offre, consultez [Abonnements](/admin/billing-usage/subscriptions).

<SectionTab as="h1" sectionId="request-higher-limits">Demander des limites plus élevées</SectionTab>

Si vous avez besoin de limites plus élevées, contactez le [support](https://help.mistral.ai) avec :

- les modèles ou API que vous prévoyez d’utiliser ;
- le nombre cible de requêtes par seconde ;
- les tokens par minute et tokens par mois prévus ;
- une brève description de votre cas d’usage.
