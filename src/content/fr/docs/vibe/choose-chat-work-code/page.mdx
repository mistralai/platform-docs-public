# Choisissez Work ou Code

Aperçu de chaque mode Vibe : quand l’utiliser, ce qu’il permet, et comment démarrer.

<SectionTab as="h2" sectionId="work">Work</SectionTab>

**Choisissez Work autant pour les conversations que pour le travail en plusieurs étapes.** Disponible dans les applications web et mobile Vibe avec une interface chat, Work est l’expérience unifiée : le **bouton fast/think** bascule entre des réponses conversationnelles rapides et des workflows agentiques plus poussés, dans la même conversation. C’est le mode adapté quand votre tâche implique plusieurs étapes, diverses sources ou des actions dans des outils connectés, et si vous souhaitez valider le résultat avant de l’utiliser.

Exemples de tâches :

- *« Faites-moi un récapitulatif de ce qui s’est passé sur le projet de lancement Q4 cette semaine. »*
- *« Synthétisez ce contrat de 80 pages et signalez les risques de renouvellement. »*
- *« Rédigez des réponses à mes emails non lus de l’équipe juridique. »*
- *« Analysez les 5 principaux concurrents de notre secteur et créez une synthèse d’une page. »*
- *« Trouvez les derniers retours clients dans Notion, classez-les par thème et préparez un support de présentation. »*

Avec Work, vous bénéficiez de :

- **Exécution de tâches via un nombre illimité de [Connecteurs](/vibe/work/connectors)**, dont Gmail, Outlook, Slack, Notion, Linear, GitHub, Atlassian, Google Drive, SharePoint et Stripe.
- Suivi en temps réel de l’avancement et des appels d’outils, avec questions de clarification en cas de consigne ambiguë.
- Validation demandée avant chaque action sensible (envoi d’email, modification ou suppression de données).
- [Skills](/vibe/work/skills) et [Projects](/vibe/work/projects) pour faciliter l’automatisation de tâches répétées.
- [Planification de tâches](/vibe/work/scheduled-tasks) pour exécuter automatiquement une consigne, une fois ou à une fréquence régulière (quotidienne, hebdomadaire, mensuelle ou annuelle).
- **Chat temporaire** : des conversations exclues de votre historique, de la recherche, de la mémoire et de l’entraînement des modèles.

<SectionTab as="h2" sectionId="code">Code</SectionTab>

**Choisissez Code lorsque la tâche dépend d’un codebase, d’un terminal, d’un IDE ou d’une session de code.** Disponible en CLI, extension VS Code ou sessions distantes via le web, Code est le mode développeur : Vibe lit les fichiers, édite le code, lance des commandes et ouvre des pull requests.

Exemples de tâches :

- *« Expliquez le fonctionnement de l’authentification dans ce repo. »*
- *« Refactorisez `src/api/handlers/` pour utiliser le nouveau modèle de gestion d’erreurs. »*
- *« Ajoutez des tests unitaires à la fonction `parseInvoice`. »*
- *« Lancez la suite de tests, corrigez les échecs et ouvrez une PR. »*
- *« Reprenez la session démarrée sur la CLI depuis le web. »*

Avec Code, vous bénéficiez de :

- **CLI** : interface terminal native, scriptable, idéale pour les repos locaux et l’automatisation.
- **Extension VS Code** : assistance intégrée, édition de fichier et chat dans l’éditeur.
- **Sessions à distance** : sandbox cloud accessible depuis n’importe quel environnement (web, mobile, desktop, IDE, CLI) pour travailler sur un repo GitHub.

<SectionTab as="h2" sectionId="chat">Chat (hérité)</SectionTab>

L’onglet **Chat** était le mode conversationnel au tour par tour, avec les fonctionnalités antérieures à l’unification : Agents, Think mode, Code Interpreter et Memories. Sa fusion avec Work simplifie l’usage de Vibe — une seule surface pour tout, le **bouton fast/think** réglant la profondeur au lieu d’un choix d’onglet. Il disparaît progressivement : les comptes des offres Free, Pro et Teams en libre-service migrent en premier vers l’expérience unifiée, et les organisations Enterprise peuvent encore voir l’onglet Chat pendant une fenêtre de migration de six mois — les administrateurs choisissent la date de migration dans le panneau d’administration ou déclenchent la fusion immédiatement.

Si vous y avez encore accès, les fonctionnalités héritées continuent de fonctionner comme avant. Sinon, voici où les retrouver :

**Fonctionnalités de Chat et leurs équivalents unifiés :**
| Fonctionnalité Chat | Équivalent unifié |
|---|---|
| [Agents](/vibe/chat-legacy/agents) : assistants spécialisés avec leurs propres outils et instructions. | Utilisez plutôt les [Skills](/vibe/work/skills) ; invoquez-les avec `@`. |
| [Think mode](/vibe/chat-legacy/think-mode) : raisonnement étendu pour les questions nécessitant une analyse en profondeur. | Le **bouton fast/think** de l’expérience unifiée. |
| [Deep Research](/vibe/chat-legacy/deep-research) : recherche multi-sources avec rapport structuré et référencé. | La [compétence Deep Research](/vibe/work/skills) dans Work. |
| [Code Interpreter](/vibe/chat-legacy/code-interpreter) : Python en environnement isolé pour les graphiques et l’analyse de données. | Pas d’équivalent direct. Work répond toujours aux questions sur vos données et génère des graphiques à partir des fichiers téléversés — voir [Fichiers et Canvas](/vibe/work/files-and-canvas). |
| [Memories](/vibe/chat-legacy/memories) : faits et préférences mémorisés à long terme dans les chats. | [Base de connaissances](/vibe/work/knowledge) : connaissances persistantes qui s'adaptent à votre contexte et vos Projets. |
