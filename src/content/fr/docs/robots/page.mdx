# Robots d'exploration Mistral

Mistral utilise des robots d'exploration web, aussi appelés _crawlers_ ou _robots_, ainsi que des chaînes de 'user-agent' pour exécuter des tâches automatiques ou à la demande d'un utilisateur. Pour aider les webmasters à contrôler la façon dont leurs sites et leurs contenus interagissent avec l'IA, Mistral utilise des directives `robots.txt` spécifiques.

<SectionTab as="h1" sectionId="mistralai-user">MistralAI-User</SectionTab>

`MistralAI-User` correspond aux **actions utilisateur dans Vibe**. Lorsqu'un utilisateur pose une question dans Vibe, Vibe peut **consulter une page web** pour produire une réponse et **inclure un lien vers la source utilisée**.

`MistralAI-User` détermine les sites que ces requêtes utilisateur peuvent consulter. Il ne sert **pas** à explorer le web de façon automatique ni à collecter du contenu pour l'entraînement de modèles d'IA générative.

<SectionTab as="h2" variant="secondary" sectionId="mistralai-user-info">Informations sur le robot</SectionTab>

Chaîne de 'user-agent' complète :

- `Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; MistralAI-User/1.0; +https://docs.mistral.ai/robots)`

Adresses IP publiées :

- [Adresses IP de MistralAI-User](https://mistral.ai/mistralai-user-ips.json)

<SectionTab as="h1" sectionId="mistralai-index">MistralAI-Index</SectionTab>

`MistralAI-Index` correspond à l'**exploration automatisée** du web à des fins d'**indexation uniquement**. Il indexe du contenu pour la recherche Mistral, qui aide Vibe à répondre aux questions des utilisateurs.

Le contenu exploré par `MistralAI-Index` n'est **pas** utilisé pour entraîner des modèles d'IA générative.

<SectionTab as="h2" variant="secondary" sectionId="mistralai-index-info">Informations sur le robot</SectionTab>

Chaîne d'agent utilisateur complète :

- `Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; MistralAI-Index/1.0; +https://docs.mistral.ai/robots)`

Adresses IP publiées :

- [Adresses IP de MistralAI-Index](https://mistral.ai/mistralai-index-ips.json)

<SectionTab as="h1" sectionId="mistralai-training">MistralAI-Training</SectionTab>

`MistralAI-Training` explore des contenus web pour aider à constituer des jeux de données destinés à l'entraînement des modèles d'IA générative de Mistral. Les webmasters peuvent interdire cet agent utilisateur dans leur fichier `robots.txt`.

Ce robot ne sert pas à l'indexation de recherche ni aux réponses en direct dans Vibe.

<SectionTab as="h2" variant="secondary" sectionId="mistralai-training-info">Informations sur le robot</SectionTab>

Chaîne d'agent utilisateur complète :

- `Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; MistralAI-Training/1.0; +https://docs.mistral.ai/robots)`

`MistralAI-Training` explore des contenus web pour aider à constituer des jeux de données destinés à l'entraînement des modèles d'IA générative de Mistral. Les webmasters peuvent interdire ce 'user-agent' dans leur fichier `robots.txt`.
