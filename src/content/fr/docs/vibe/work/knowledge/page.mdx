# Base de connaissances

La Base de connaissances enregistre **ce qui compte dans vos conversations** afin que Vibe puisse le réutiliser plus tard. Au lieu de rappeler vos préférences, projets et contexte au début de chaque échange, vous expliquez une fois et la Base de connaissances **porte ce contexte plus loin**.

Moins de répétition signifie **des réponses plus pertinentes et des conversations plus productives**. La Base de connaissances met aussi à votre disposition ce qu'elle sait lorsque vous recherchez un détail précis, pour retrouver un fait ou une préférence sans parcourir vos anciennes conversations.

:::info
La Base de connaissances est le successeur des [Mémoires](/vibe/chat-legacy/memories) et est disponible dans Vibe Work. Si vous utilisiez les Mémoires dans Chat, vos mémoires existantes migreront dans la Base de connaissances sous forme de sujet de connaissance. La Base de connaissances est disponible uniquement en mode Work pour le moment ; les Mémoires de Chat restent disponibles jusqu'à la fin de la migration.
:::

<SectionTab as="h2" sectionId="how-it-works">Comment ça marche</SectionTab>

Considérez la Base de connaissances comme un bloc-notes auto-organisé : elle enregistre ce que vous lui demandez explicitement d'enregistrer, et capte les informations récurrentes de vos conversations en second mode. Deux mécanismes décident de ce qui est stocké.

- **Enregistrement explicite** : utilisez des mots-clés comme « retiens » ou « enregistre » pour dire à Vibe de stocker un fait précis. Par exemple, *« Retiens que je travaille avec TypeScript »* ou *« Enregistre que mon équipe utilise Linear pour le suivi. »* C'est le mode qui fonctionne le mieux pour tout ce que vous voulez retrouver de façon fiable.
- **Enregistrement implicite** : Vibe détecte aussi les détails récurrents qui seront utiles plus tard, tels que vos formats préférés ou les outils dont vous dépendez, et les enregistre de lui-même.

Au fil de la conversation, Vibe examine vos connaissances à chaque tour et détermine quelles entrées de connaissance sont pertinentes pour la tâche en cours. La récupération est non déterministe : une même connaissance n'est pas utilisée dans chaque conversation, uniquement quand elle correspond à la demande.

Vous pouvez voir quand cela se produit. Vibe affiche une pastille **lecture** lorsqu'il consulte vos connaissances et une pastille **écriture** lorsqu'il enregistre une nouvelle entrée. Ces pastilles apparaissent dans le chat, pour que vous sachiez toujours quand la Base de connaissances est active.

:::info
La Base de connaissances capture les informations issues de vos conversations et prend en charge le contenu Markdown et texte. Vous gérez tout depuis l'interface de chat ; il n'existe pas d'API distincte pour les entrées de connaissance.
:::

<SectionTab as="h2" sectionId="get-started">Premiers pas</SectionTab>

La Base de connaissances est activée par défaut. Pour la configurer une première fois :

1. Dans la barre latérale, cliquez sur `Contexte`.
2. Cliquez sur `Connaissances`.
3. Cliquez sur le bouton `Commencer` pour la tester lors d'une première conversation.

:::tip
Une fois configurée, la Base de connaissances fonctionne en arrière-plan. Vous n'avez pas besoin de l'activer pour chaque conversation. Vous pouvez la désactiver dans vos paramètres de `Confidentialité` ou depuis la page `Connaissances`.
:::

<SectionTab as="h2" sectionId="manage">Gérer vos connaissances</SectionTab>

Toutes vos entrées de connaissance figurent dans la section `Connaissances`, où vous pouvez consulter et contrôler ce qui est stocké. Vous pouvez aussi activer la Base de connaissances et supprimer toutes vos connaissances depuis le bouton d'action en haut à droite de la page des connaissances, en plus de vos `Paramètres`.

- **Lister** : ouvrez la section `Connaissances` pour voir toutes les entrées enregistrées par Vibe, avec un titre et une description pour chacune.
- **Modifier** : sélectionnez l'information que vous souhaitez changer et demandez au modèle de l'affiner. Par exemple, *« Rends-la plus précise »* ou *« Ajoute que j'utilise désormais PostgreSQL. »* Vous ne pouvez pas modifier le texte d'une entrée directement ; les changements passent par le modèle dans le chat.
- **Supprimer un sujet** : cliquez sur les trois points `...` en haut à droite de la page des connaissances et sélectionnez l'option de suppression pour retirer un sujet entier.
- **Supprimer une seule entrée** : demandez directement à Vibe dans la conversation de retirer un fait précis. Par exemple, *« Oublie que j'ai mentionné ma localisation. »*
- **Tout supprimer** : retirez toutes vos entrées de connaissance en une fois depuis le bouton d'action en haut à droite de la page des connaissances ou depuis les `Paramètres`. Cette action est définitive.
- **Exporter** : exportez vos données à tout moment depuis les `Paramètres` pour obtenir une copie à jour de ce qui est stocké.

Vous pouvez aussi demander directement à Vibe dans une conversation de retirer, corriger ou modifier une entrée de connaissance.

<SectionTab as="h2" sectionId="turning-off">Désactiver la Base de connaissances</SectionTab>

Pour désactiver la Base de connaissances pour votre compte, cliquez sur le nom de votre organisation en bas à gauche de la barre latérale, puis sur `Confidentialité`. Dans la section `Personnalisation`, désactivez `Connaissances` (« Autoriser Vibe à enregistrer et organiser automatiquement les informations clés de vos chats »). Vous pouvez aussi la désactiver depuis la page `Connaissances`. Vos entrées de connaissance existantes restent visibles, mais elles n'influencent plus les réponses tant que vous ne réactivez pas la fonctionnalité.

:::caution
Désactiver la Base de connaissances ne supprime pas les entrées stockées. Pour les effacer, utilisez `Supprimer toutes les connaissances` avant de désactiver.
:::

<SectionTab as="h2" sectionId="privacy">Confidentialité et données</SectionTab>

La Base de connaissances est conçue pour vous laisser contrôler ce qui est stocké et comment c'est utilisé.

- **Les données sensibles sont traitées avec soin.** Aucune donnée sensible (opinions politiques, croyances religieuses, détails de santé) n'est stockée dans vos connaissances, à l'exception de vos Mémoires précédentes conservées dans la Base de connaissances, le cas échéant.
- **Transparence.** Lorsqu'un fait est ajouté à vos connaissances, il est indiqué comme une entrée de la Base de connaissances, pour que vous sachiez toujours ce qui a été enregistré.
- **Pas d'inférence ni de création d'informations.** La Base de connaissances capture les informations issues de vos conversations ; elle ne déduit ni ne crée de nouvelles informations elle-même. C'est une source de contexte pour étayer les réponses de Vibe, pas une étape de raisonnement distincte.
- **Pas d'action autonome.** La Base de connaissances ne permet pas à Vibe d'agir de lui-même. Vibe reste soumis à vos permissions de Connecteurs et aux mêmes validations que n'importe quelle autre tâche.
- **Contrôle au niveau de l'organisation.** Les administrateurs de l'espace de travail peuvent désactiver la Base de connaissances pour toute l'organisation :
  1. Ouvrez la console d'administration à l'adresse `admin.mistral.ai/vibe/preferences`.
  2. Allez dans la section `Outils`.
  3. Désactivez `Connaissances` (« Autoriser les utilisateurs à enregistrer et utiliser leurs Connaissances personnelles dans les conversations en mode Work »).

  Une fois désactivée, la Base de connaissances est indisponible pour tous les membres.

<SectionTab as="h2" sectionId="related-features">Fonctionnalités associées</SectionTab>

La Base de connaissances fonctionne aux côtés d'autres sources de contexte dans Work :

- **[Instructions personnalisées](/vibe/work/custom-instructions)** : définissez des préférences persistantes comme le ton, le format et le rôle, valables pour chaque tâche.
- **[Projects](/vibe/work/projects)** : regroupez conversations et contexte autour d'une équipe, d'un client ou d'une initiative.
- **[Connecteurs](/vibe/work/connectors)** : laissez Work lire et agir dans les outils connectés tels que l'email, l'agenda, Slack et Notion.
