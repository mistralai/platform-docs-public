# Créer votre premier espace de travail

Un espace de travail est un **environnement partagé** pour une équipe ou un cas d’usage au sein de votre Organisation. Il définit les ressources, les accès, l’utilisation et les limites applicables au travail effectué dans cet espace.

Chaque espace de travail peut avoir ses propres :

- **Membres et rôles** : déterminez qui peut accéder à l’espace de travail et ce que chaque membre peut y faire.
- **Clés API** : limitez l’utilisation de l’API à un espace de travail.
- **Ressources** : séparez par espace de travail les ressources Vibe et Studio, telles que les prompts, les Bibliothèques et les Compétences. Vous pouvez également configurer les connexions des Connecteurs et leurs permissions pour chaque espace de travail.

{/* TODO: add link to the Connecteurs admin config when published */}
- **Utilisation et limites** : suivez la consommation et définissez des limites de dépenses par espace de travail.
- **Paramètres produits** : activez ou désactivez les fonctionnalités de Vibe pour un espace de travail spécifique.

Pour un utilisateur, changer d’espace de travail modifie le contexte du produit dans lequel il travaille. Consultez [Espaces de travail dans Studio](/admin/workspaces/workspaces-in-studio) et [Espaces de travail dans Vibe](/admin/workspaces/workspaces-in-vibe) pour comprendre comment l’espace sélectionné affecte les ressources dans chaque produit.

:::note
Une Organisation peut compter jusqu’à **500 espaces de travail actifs**. Les noms des espaces de travail doivent être uniques au sein d’une Organisation.
:::

<SectionTab as="h1" sectionId="create-workspace">Créer un espace de travail</SectionTab>

Toute Organisation **commence avec un espace de travail par défaut**. Les administrateurs Organisation peuvent créer des espaces de travail supplémentaires lorsqu’ils ont besoin de séparer davantage les équipes, les produits ou les environnements.

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Espaces de travail"]} />.
2. Cliquez sur `Nouvel espace de travail`.
3. Choisissez une icône pour représenter l’espace de travail.
4. Saisissez un nom. Ce libellé apparaît dans les interfaces et les exports.
5. Si nécessaire, saisissez une description.
6. Si nécessaire, ajoutez des membres.
7. Attribuez-leur des rôles d’espace de travail. Consultez [Accès à l’espace de travail](#workspace-access) pour comprendre comment les rôles s’appliquent.
8. Cliquez sur `Créer`.

:::tip
Le rôle d’administrateur d’espace de travail est attribué automatiquement à la personne qui crée l’espace.
:::

<SectionTab as="h1" sectionId="workspace-access">Accès à l’espace de travail</SectionTab>

Les membres appartiennent d’abord à l’Organisation, puis accèdent à un ou plusieurs espaces de travail. Vous pouvez ajouter des membres directement à un espace de travail ou gérer leur accès avec des [groupes](/admin/identity-access/groups).

Le rôle d’un membre dans un espace de travail contrôle ce qu’il peut faire dans cet espace. Son rôle dans l’Organisation contrôle ce qu’il peut faire dans l’ensemble de l’Organisation. Ces deux rôles sont indépendants. Par exemple, un membre de l’Organisation peut être administrateur d’un espace de travail spécifique.

:::info
Les administrateurs Organisation ont toujours accès à tous les espaces de travail de l’Organisation, même s’ils n’en sont pas explicitement membres.
:::

Pour consulter la liste complète des rôles dans un espace de travail et de leurs permissions, consultez [Rôles et permissions](/admin/identity-access/roles-permissions).

<SectionTab as="h1" sectionId="archive-workspace">Archiver un espace de travail</SectionTab>

Archivez un espace de travail lorsque les membres n’ont plus besoin d’y accéder, mais que vous souhaitez le conserver dans l’historique de l’Organisation.

1. Ouvrez <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Espaces de travail"]} />.
2. Trouvez l’espace de travail dans la liste.
3. Cliquez sur l’icône `Archiver`.
4. Confirmez l’archivage.

:::warning
L’archivage d’un espace de travail le rend inaccessible à tous les membres. Cette action est irréversible. Vous ne pouvez pas archiver l’espace de travail par défaut.
:::

<SectionTab as="h1" sectionId="next-steps">Étapes suivantes</SectionTab>

Après avoir créé un espace de travail, configurez-le pour Studio et Vibe, puis définissez des limites et consultez l’utilisation :

- [Espaces de travail dans Studio](/admin/workspaces/workspaces-in-studio) : comprenez comment la sélection d’un espace de travail affecte les clés API, les ressources développeur, l’utilisation, les limites et les Connecteurs dans Studio.
- [Espaces de travail dans Vibe](/admin/workspaces/workspaces-in-vibe) : comprenez comment la sélection d’un espace de travail affecte les conversations, les projets, les outils, les paramètres des fonctionnalités, la conservation des données, le traçage et les Connecteurs dans Vibe.
- [Utilisation et limites par espace de travail](/admin/workspaces/usage-limits) : définissez des limites de dépenses et consultez l’utilisation des espaces de travail.
