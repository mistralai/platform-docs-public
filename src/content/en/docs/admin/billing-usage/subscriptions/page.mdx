# Subscription

Use Subscription to review the Mistral plan, seats, included monthly usage, and pay-as-you-go settings active on your Organization. Mistral plans are global: the same plan applies across Vibe, Studio, and API usage.

For the latest plan details, usage budgets, and model pricing, see [Mistral pricing](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="open-subscriptions">Open Subscription</SectionTab>

Open <AppLink href="https://admin.mistral.ai/subscription" path={["Admin Panel", "Subscription"]} />.

In Subscription, you can review:

- your Mistral plan and seats;
- included monthly usage;
- current estimated usage;
- pay-as-you-go settings;
- Mistral Code seats, when they apply.

<SectionTab as="h1" sectionId="mistral-plan">Mistral plan</SectionTab>

Your Mistral plan controls access across Vibe, Studio, and the API. Available plans include Free mode, Pro, Education, Team, and Enterprise.

Free mode is the default state for new accounts. Paid plans add seats, features, and included monthly usage. For current plan features and limits, see [Mistral pricing](https://mistral.ai/pricing/).

:::tip
Students and teachers can check whether they are eligible for a discount in the [student and teacher discount article](https://help.mistral.ai/en/articles/698530-i-m-a-student-or-a-teacher-am-i-eligible-for-a-discount).
:::

<SectionTab as="h1" sectionId="included-monthly-usage">Included monthly usage</SectionTab>

Each Mistral plan includes monthly usage that is shared across Studio, the API, and Vibe Code. Usage consumes this monthly allowance first.

When your included monthly usage is exhausted, access depends on your plan settings. If pay-as-you-go is enabled, additional usage is billed per token. If it is not enabled, usage can stop until the next billing period or until an admin changes the settings.

<SectionTab as="h1" sectionId="pay-as-you-go">Pay-as-you-go</SectionTab>

Pay-as-you-go lets you extend usage beyond the included monthly usage. It is not a separate API or Vibe plan.

To enable pay-as-you-go, open <AppLink href="https://admin.mistral.ai/subscription" path={["Admin Panel", "Subscription"]} />.

For exact model pricing, included usage, and feature availability, see [Mistral pricing](https://mistral.ai/pricing/).

<SectionTab as="h1" sectionId="mistral-code">Mistral Code and Vibe Code</SectionTab>

Some Organizations still show Mistral Code seats. Mistral Code seats are legacy Enterprise seats for the coding assistant. Vibe Code covers the CLI, editor extensions, and coding workflows.

If you need to change the number of Mistral Code Enterprise seats, contact Mistral.
