# Balises d'émotion et de rythme

Les balises d’émotion et de débit modifient la façon dont une voix prononce une partie du texte : écrivez-les directement dans `input`, entre crochets, par exemple `[emotion=happy]` ou `[pace=slow]`. Pour définir l’interprétation de l’ensemble de l’entrée, utilisez plutôt les [instructions de style](/studio/audio/text-to-speech/style-instructions).

:::info
Pour comparer les balises aux autres façons de diriger une voix, et pour comprendre le fonctionnement des émotions dans Voxtral 2 et Voxtral 3, consultez [Voix](/studio/audio/concepts/voices#choose-and-direct).
:::

<SectionTab as="h2" sectionId="tag-syntax">Syntaxe des balises</SectionTab>

Les balises d’émotion et de débit partagent la même syntaxe et les mêmes règles :

| Règle | Détails |
| --- | --- |
| Format | `[emotion=<value>]` ou `[pace=<value>]`, avec une valeur issue des tableaux de cette page |
| Emplacement | Dans `input`, avant le texte auquel elle s’applique : au début ou au milieu d’une phrase |
| Prononcé | Non : la balise n’est pas lue à voix haute |
| Combinaison | Écrivez une balise d’émotion et une balise de débit l’une à la suite de l’autre, par exemple `[emotion=calm][pace=slow]` |
| Portée |  |

<SectionTab as="h2" sectionId="tag-an-emotion">Ajouter une balise d’émotion</SectionTab>

Placez la balise d’émotion dans `input`, avant le texte à prononcer avec cette émotion :

<Tabs groupId="code">
  <TabItem value="curl" label="curl" default>

```bash
curl -s https://api.mistral.ai/v1/audio/speech \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "voxtral-mini-tts-3-0",
    "input": "[emotion=happy]We passed the audit!",
    "voice_id": "voice_478",
    "response_format": "wav"
  }' | jq -r '.audio_data' | base64 --decode > happy.wav
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

response = client.audio.speech.complete(
    model="voxtral-mini-tts-3-0",
    input="[emotion=happy]We passed the audit!",
    voice_id="voice_478",
    response_format="wav",
)

output = Path("happy.wav")
output.write_bytes(base64.b64decode(response.audio_data))
print(f"Saved {output.resolve()}")
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { writeFile } from "node:fs/promises";
import { resolve } from "node:path";

import { Mistral } from "@mistralai/mistralai";

const client = new Mistral({ apiKey: process.env.MISTRAL_API_KEY });

const response = await client.audio.speech.complete({
  model: "voxtral-mini-tts-3-0",
  input: "[emotion=happy]We passed the audit!",
  voiceId: "voice_478",
  responseFormat: "wav",
});

const output = "happy.wav";
await writeFile(output, Buffer.from(response.audioData, "base64"));
console.log(`Saved ${resolve(output)}`);
```

<SectionTab as="h2" sectionId="pace-tags">Balises de rythme</SectionTab>

Les balises de débit règlent le débit de parole. Utilisez-les pour lire une mention légale plus lentement, ou pour dérouler une liste plus rapidement :

| Rythme | Effet |
| --- | --- |
| `slow` | La voix parle plus lentement qu’à son débit normal. |
| `fast` | La voix parle plus rapidement qu’à son débit normal. |

 L’exemple suivant génère la même phrase pour chaque débit :

<Tabs groupId="code">
  <TabItem value="python" label="python" default>

```python
import base64
import os
from pathlib import Path

from mistralai.client import Mistral

client = Mistral(api_key=os.environ["MISTRAL_API_KEY"])

for pace in ["slow", "fast"]:
    response = client.audio.speech.complete(
        model="voxtral-mini-tts-3-0",
        input=f"[pace={pace}]Please read the terms carefully before you sign.",
        voice_id="voice_478",
        response_format="wav",
    )
    output = Path(f"pace_{pace}.wav")
    output.write_bytes(base64.b64decode(response.audio_data))
    print(f"Saved {output.resolve()}")
```

  </TabItem>
  <TabItem value="typescript" label="typescript">

```typescript
import { writeFile } from "node:fs/promises";
import { resolve } from "node:path";

import { Mistral } from "@mistralai/mistralai";

const client = new Mistral({ apiKey: process.env.MISTRAL_API_KEY });

for (const pace of ["slow", "fast"]) {
  const response = await client.audio.speech.complete({
    model: "voxtral-mini-tts-3-0",
    input: `[pace=${pace}]Please read the terms carefully before you sign.`,
    voiceId: "voice_478",
    responseFormat: "wav",
  });
  const output = `pace_${pace}.wav`;
  await writeFile(output, Buffer.from(response.audioData, "base64"));
  console.log(`Saved ${resolve(output)}`);
}
```

<SectionTab as="h2" sectionId="combine-with-instructions">Combiner des balises avec une instruction de style</SectionTab>

Les balises et une instruction de style agissent à des niveaux différents.  Consultez [Instructions de style](/studio/audio/text-to-speech/style-instructions).

<SectionTab as="h2" sectionId="unsupported-values">Valeurs non prises en charge</SectionTab>

L’API ne rejette pas une balise dont la valeur ne figure pas dans les tableaux de cette page. Une requête comme `[emotion=ecstatic]` renvoie une réponse normale, et la balise n’est pas prononcée.
