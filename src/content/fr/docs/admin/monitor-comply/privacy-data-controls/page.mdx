# Confidentialité

Utilisez les contrôles de confidentialité et de données pour gérer le traitement de vos données dans Vibe et l’API. Ces contrôles couvrent les politiques d’utilisation des données, la désactivation de l’entraînement et les droits RGPD.

<SectionTab as="h1" sectionId="data-usage">Utilisation des données</SectionTab>

- **Vibe (plan Free)** : les conversations peuvent être utilisées pour améliorer nos modèles. Vous pouvez vous y opposer à tout moment depuis le Panneau Admin.
- **Vibe (Pro, Team, Enterprise)** : les conversations ne sont pas utilisées par défaut pour l’entraînement des modèles.
- **API** : les données envoyées avec l’API ne sont pas utilisées pour l’entraînement des modèles.
- **Connecteurs** : les données accessibles avec les Connecteurs sont récupérées à la demande et ne sont pas stockées de façon permanente. Les données des Connecteurs ne sont pas utilisées pour l’entraînement.
- **Libraries** : les documents importés sont stockés de manière sécurisée et ne sont pas utilisés pour l’entraînement.

:::info
Pour plus d’informations sur la confiance, la sécurité et la conformité, consultez la [collection du centre d’aide sur la confiance, la sécurité et la conformité](https://help.mistral.ai/en/collections/789666-trust-security-compliance).
:::

<SectionTab as="h1" sectionId="vibe-privacy-controls">Contrôles de confidentialité Vibe</SectionTab>

Utilisez les contrôles de confidentialité Vibe pour gérer l’entraînement des modèles, le partage public des conversations, les retours utilisateur et la rétention des conversations pour votre Organisation.

Ouvrez <AppLink href="https://admin.mistral.ai/vibe/privacy" path={["Panneau d’administration", "Vibe", "Privacy"]} />.

Depuis cette page, vous pouvez configurer :

- `Model training` : autorise ou désactive l’utilisation des interactions Vibe pour entraîner les modèles Mistral. Si vous désactivez cette option, les nouvelles interactions de vos utilisateurs ne sont pas utilisées pour entraîner les modèles.
- `Public chat sharing` : autorise les membres de l’Organisation à partager des conversations publiquement, y compris l’accès aux Libraries de documents. Si vous désactivez cette option, les membres peuvent toujours partager des conversations dans l’Organisation.
- `Model response feedback` : autorise les membres de l’Organisation à envoyer des avis positifs, des avis négatifs et des commentaires libres sur les réponses des modèles.
- `Chat Retention Policy` : supprime automatiquement les conversations et leurs artefacts après une période définie à partir de leur création. Vous pouvez choisir `Never`, `30 days`, `60 days`, `90 days`, `180 days` ou `1 year`.

<SectionTab as="h1" sectionId="api-privacy-controls">Contrôles de confidentialité API</SectionTab>

Utilisez les contrôles de confidentialité API pour gérer l’entraînement des modèles, la rétention des données et l’accès aux modèles Labs pour l’usage API.

Ouvrez <AppLink href="https://admin.mistral.ai/plateforme/privacy" path={["Panneau d’administration", "API", "Privacy"]} />.

Depuis cette page, vous pouvez configurer :

- `Data usage for improving our services` : autorise ou désactive l’utilisation des appels API pour entraîner les modèles Mistral. Si vous désactivez cette option, les nouvelles interactions de vos utilisateurs ne sont pas utilisées pour entraîner les modèles.
- `Zero data retention` : indique si les données de dépannage et d’analyse sont stockées pour votre Organisation. Lorsque `Zero data retention` est activé, les données de dépannage et d’analyse ne sont pas stockées. Consultez [Activer la rétention zéro des données](https://help.mistral.ai/en/articles/347612-can-i-activate-zero-data-retention-zdr).
- `Labs models` : active les modèles Labs pour l’Organisation. Si vous activez les modèles Labs, les données peuvent être utilisées pour entraîner les modèles Mistral, quels que soient votre offre ou vos paramètres de désactivation, conformément aux conditions commerciales d’utilisation.

<SectionTab as="h1" sectionId="gdpr">Droits RGPD</SectionTab>

Selon le RGPD, vous disposez des droits suivants :

| Droit | Description |
|-------|-------------|
| **Accès** | Obtenir des copies de vos données personnelles |
| **Rectification** | Corriger des informations personnelles inexactes |
| **Effacement** | Supprimer votre compte et les données associées |
| **Portabilité des données** | Demander vos données dans un format transférable |
| **Opposition** | Vous opposer à certaines activités de traitement |
| **Restriction** | Demander des limitations au traitement des données |

Pour exercer ces droits, suivez [Exercer vos droits RGPD](https://help.mistral.ai/en/articles/347639-how-can-i-exercise-my-gdpr-rights). Utilisez l’adresse e-mail associée à votre compte et précisez les données ou activités concernées.

Pour modifier les données de compte, utilisez directement le Panneau Admin. Pour exporter vos données, téléchargez-les depuis Vibe ou Studio.

:::warning
La suppression du compte est définitive et irréversible. Toutes les instructions, sorties et données personnelles sont supprimées et ne peuvent pas être récupérées.
:::
