The Evaluation SDK is a **client** for the AI Studio (Dora) backend that ships inside your
Mistral AI Studio (MAIS) deployment. A newer SDK assumes a newer backend, so the version you
install must match the MAIS release you run against.

<Admonition type="tip">
**Pin the SDK version that ships with your MAIS release.** Running a newer SDK is not supported: Dora
ignores request fields it doesn't know, so newer features (e.g. metric `direction`) quietly become
no-ops against an older backend rather than erroring.
</Admonition>

## Which SDK version for which MAIS

| MAIS release | Package | Version |
|---|---|---|
| 2026.5 | `mistralai-observability` | **0.4.1** |
| 2026.8 | `mistralai-observability` | **0.5.1** |
| 2026.11 | `mistralai-evaluations` | **0.7.x** |

<Tag other>MAIS ≥ 2026.11</Tag>

Notes:

- **`mistralai-observability` 0.6.0 is not the 2026.8 version.** On MAIS 2026.8, use **0.5.1**. 0.6.0
  adds the `0.5.x → 0.6.0` metric-`direction` change; the 2026.8 backend has no `direction` field, so
  it silently ignores it (the metric stays default `maximize`). 0.6.0 matches the next backend line
  (2026.11), which is not cut yet.
- The package was **renamed** `mistralai-observability` → `mistralai-evaluations` at MAIS 2026.11.
  `mistralai-observability` is frozen at `0.6.0`, which is API-identical to `mistralai-evaluations`
  `0.7.0` (a pure rename): if you must keep the old package name on 2026.11, pin `0.6.0`. See the
  [Migration Guide](/docs/observability/evaluation-sdk/guides/migrating/).
- Do **not** jump to `mistralai-evaluations` 0.7.x on MAIS 2026.8 or earlier, for the same reason as 0.6.0.
- The two-step `run()` + `rescore()` flow requires the **2026.11** backend; against an older backend the
  `rescore` endpoint isn't available, so pin the SDK to the version that ships with your MAIS release.

  <Tag other>SDK ≥ 0.7.1</Tag> <Tag other>MAIS ≥ 2026.11</Tag>

- 2026.11 is the **public-preview** release (alongside Studio v2).

### Old package name (frozen)

| Old package | Version | Compatible MAIS |
|---|---|---|
| `mistralai-observability` | **0.6.0** (frozen, = `mistralai-evaluations` 0.7.0) | 2026.11 _(projected)_ |

## Finding your MAIS version

Ask your platform admin, or check the version surfaced in the AI Studio UI / deployment manifest.
Then install the matching version, e.g. for MAIS 2026.8:

```bash
pip install "mistralai-observability==0.5.1"
```
