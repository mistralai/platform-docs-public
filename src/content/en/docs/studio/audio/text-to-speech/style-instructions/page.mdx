# Style instructions

A style instruction describes, in your own words, how to say the whole input, such as a calm and slow delivery. Use it to set one delivery for the whole output; to change the emotion or the pace of part of the text, use [emotion and pace tags](/studio/audio/text-to-speech/emotion-tags).

:::info
For how instructions compare with the other ways to direct a voice, see [Voices](/studio/audio/concepts/voices#choose-and-direct).
:::

<SectionTab as="h2" sectionId="give-an-instruction">Give a delivery instruction</SectionTab>

Add `instruction` to the speech request, next to `input` and the voice. The value is a short sentence in plain language:

<Tabs groupId="code">
  <TabItem value="curl" label="curl" default>

```bash
curl -s https://api.mistral.ai/v1/audio/speech \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "voxtral-mini-tts-3-0",
    "input": "Your order shipped this morning and should arrive on Thursday.",
    "voice_id": "gb_jane_neutral",
    "instruction": "A calm, slow delivery.",
    "response_format": "wav"
  }' | jq -r '.audio_data' | base64 --decode > calm.wav
```

  </TabItem>
  <TabItem value="python" label="python">

```python
import base64
import os
from pathlib import Path

import httpx

response = httpx.post(
    "https://api.mistral.ai/v1/audio/speech",
    headers={"Authorization": f"Bearer {os.environ['MISTRAL_API_KEY']}"},
    json={
        "model": "voxtral-mini-tts-3-0",
        "input": "Your order shipped this morning and should arrive on Thursday.",
        "voice_id": "gb_jane_neutral",
        "instruction": "A calm, slow delivery.",
        "response_format": "wav",
    },
    timeout=60,
)
response.raise_for_status()

output = Path("calm.wav")
output.write_bytes(base64.b64decode(response.json()["audio_data"]))
print(f"Saved {output.resolve()}")
```

<SectionTab as="h2" sectionId="instructions-and-tags">Instructions, tags, and expressiveness</SectionTab>

Three request settings shape the delivery, at different levels:

| Setting | Applies to | Details |
| --- | --- | --- |
| `instruction` | The whole input | This page |
| Emotion and pace tags in `input` | Part of the text | [Emotion and pace tags](/studio/audio/text-to-speech/emotion-tags) |
| `expressiveness` | Controls how expressive the speech is. Higher values trade voice similarity and stability for stronger delivery. | [Generate speech](/studio/audio/text-to-speech/generate-speech) |

Style instructions are not available at launch.

<SectionTab as="h2" sectionId="limits-and-errors">Limits and errors</SectionTab>

These errors come from the `instruction` field:

| Error | Cause | Fix |
| --- | --- | --- |
| 422 `Extra inputs are not permitted` | A misspelled field name, such as `instructions` | Use `instruction`, singular. |
| 422 with type `string_type` | `instruction` isn't a string | Send the instruction as text. |
| Style instructions are not available at launch. | The instruction is over the length limit. It isn't shortened for you. | Shorten the instruction. |
| Style instructions are not available at launch. | The model doesn't support style instructions. | Use a model that supports them. |

For other speech generation errors, see [Troubleshooting](/studio/audio/text-to-speech/troubleshooting).
