## <Pill variant="primary"><b>POST</b></Pill> /v1/admin/scim/sync \{#operation-users_api_admin_scim_sync_trigger_scim_sync\}

</OperationTitleSection>

<OperationSummarySection slot="summary">

_Déclencher une synchronisation SCIM_

</OperationSummarySection>

<OperationDescriptionSection slot="description">

Déclencher une synchronisation SCIM à la demande pour l'Organization.

Nécessite que l'authentification SAML soit activée et que l'Organization soit en mode
approvisionnement d'utilisateurs SCIM. Un essai à blanc prévisualise chaque modification sans l'appliquer;
une exécution réelle applique les catégories sélectionnées dans `sync_config`. Une seule exécution peut être active à la fois —
une demande conflictuelle retourne l'exécution déjà active.

</OperationDescriptionSection>
