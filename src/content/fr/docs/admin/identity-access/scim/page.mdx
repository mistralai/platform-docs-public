# Provisionnement automatisé (SCIM)

Le protocole SCIM (*System for Cross-domain Identity Management*) permet à un fournisseur d’identité de créer, mettre à jour et désactiver des utilisateurs automatiquement. Utilisez-le quand votre Organisation a besoin d’automatiser le provisionnement et le déprovisionnement des utilisateurs, par exemple pour la conformité ou la gestion du cycle de vie à grande échelle.

:::note
La documentation SCIM n’est pas incluse dans la première version des docs Admin. Nous attendons la confirmation de l’équipe IAM sur la disponibilité, les étapes de configuration et le comportement de synchronisation des groupes.
:::
