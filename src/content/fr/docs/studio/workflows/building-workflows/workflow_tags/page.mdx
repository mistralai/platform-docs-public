# Balises de workflow

Les workflows prennent en charge des balises de métadonnées interrogeables, utiles pour le filtrage et la découverte. Les balises sont des chaînes de caractères filtrables attachées aux définitions de workflows (et non aux exécutions), et visibles dans l'interface d'AI Studio et via l'API.

## Définir des balises

Les workflows sont créés sans balises lors de l'enregistrement du worker, puis les utilisateurs les balisent via l'endpoint de mise à jour :

```http
PUT /v1/workflows/{workflow_identifier}
```

```json
{
  "tags": ["ocr", "document-processing"]
}
```

La mise à jour des balises **remplace** la liste existante. Transmettez une liste vide pour supprimer toutes les balises. Si vous omettez `tags` du corps de la requête, les balises existantes restent inchangées.

## Filtrage par balises

L'endpoint de liste accepte les balises comme paramètre de filtre avec une sémantique **ET** — seuls les workflows comportant **toutes** les balises spécifiées sont renvoyés :

```http
GET /v1/workflows?tags=ocr&tags=document-processing
```

## La validation

| Règle | Détail |
|------|--------|
| Longueur maximale | 100 caractères par balise |
| Espaces | Supprimés aux deux extrémités |
| Balises vides | Rejetées (y compris celles composées uniquement d'espaces) |
| Doublons | Dédupliqués silencieusement |
| Nombre maximal | Aucune limite appliquée |
