# Espaces de travail dans Studio

Studio utilise l’espace de travail actif comme contexte pour ce qu’un développeur peut voir, créer et surveiller. Changer d’espace de travail modifie les clés API, l’état du Playground, les ressources, l’utilisation, les limites et les données d’observabilité disponibles pour cet utilisateur.

Ce guide explique comment la sélection d’un espace de travail affecte les utilisateurs Studio et ce que les administrateurs peuvent configurer depuis le Panneau d’administration.

<SectionTab as="h1" sectionId="user-impact">Ce qui change pour les utilisateurs Studio</SectionTab>

Tout dans Studio est rattaché à un espace de travail.

L’espace de travail actif affecte :

- **Clés API** : les utilisateurs voient et créent des clés uniquement pour l’espace de travail actif.
- **Playground** : les requêtes de test s’exécutent dans le contexte de l’espace de travail actif.
- **Agents** : les définitions d’agents appartiennent à l’espace de travail où elles ont été créées.
- **Batches** : les jobs batch et leurs résultats sont rattachés à l’espace de travail.
- **Document AI** : les ressources de traitement de documents sont rattachées à l’espace de travail.
- **Workflows** : les ressources de workflow appartiennent à l’espace de travail actif.
- **Audio** : les ressources de transcription et de synthèse vocale sont rattachées à l’espace de travail.
- **Observability** : Campaigns, Judges, datasets, traces, utilisation de tokens et métriques d’erreur sont rattachés à l’espace de travail.
- **Prompts et Compétences** : les prompts et les Compétences enregistrés appartiennent à l’espace de travail où ils ont été créés.
- **Fichiers et Bibliothèques** : les fichiers téléchargés et les Bibliothèques sont rattachés à l’espace de travail.
- **Connecteurs** : l’accès aux Connecteurs et les outils peuvent être gérés par espace de travail.
- **Paramètres et clés de la CLI Vibe Code** : les paramètres et les clés sont rattachés à l’espace de travail.

<SectionTab as="h1" sectionId="switch-workspace">Changer d’espace de travail dans Studio</SectionTab>

Les utilisateurs changent d’espace de travail depuis le sélecteur d’Organisation ou d’espace de travail dans l’en-tête Studio. Après la sélection d’un autre espace de travail, Studio met à jour les clés API, l’état du Playground, les ressources, l’utilisation et les vues d’observabilité pour cet espace de travail.

<SectionTab as="h1" sectionId="admin-settings">Paramètres d’administration pour Studio</SectionTab>

Les administrateurs Organisation configurent les paramètres d’espace de travail liés à Studio depuis <AppLink href="https://admin.mistral.ai/organization/workspaces" path={["Panneau d’administration", "Administration", "Espaces de travail"]} />. Ouvrez un espace de travail pour gérer ses membres, son utilisation, sa limite de dépenses, son paramètre de création de clés API et son accès aux Connecteurs.

<SectionTab as="h2" variant="secondary" sectionId="api-key-creation">Création de clés API</SectionTab>

Utilisez `Création de clés API` pour autoriser ou empêcher les utilisateurs de créer des clés API dans un espace de travail.

:::info
Les clés créées dans un espace de travail utilisent le quota, les limites et les ressources de cet espace de travail.
:::

<SectionTab as="h2" variant="secondary" sectionId="usage-and-limits">Utilisation et limites</SectionTab>

Chaque espace de travail a sa propre utilisation et ses propres limites. Les administrateurs peuvent :

- consulter l’utilisation depuis la vue détaillée de l’espace de travail ;
- définir une limite de dépenses mensuelle pour la consommation API et Vibe ;
- utiliser un plafond inférieur ou égal à la limite de dépenses de l’Organisation.

:::warning
Si un espace de travail atteint sa limite de dépenses mensuelle, l’accès API de cet espace de travail est suspendu jusqu’au début du mois suivant ou jusqu’à l’augmentation de la limite.
:::

Une limite de dépenses d’espace de travail ne peut pas dépasser la limite de dépenses de l’Organisation. Si un paiement récent échoue, l’accès peut être affecté jusqu’à ce que le paiement soit traité à nouveau.

Pour les détails de configuration, consultez [Utilisation et limites par espace de travail](/admin/workspaces/usage-limits).

<SectionTab as="h2" variant="secondary" sectionId="connectors">Connecteurs</SectionTab>

Les administrateurs peuvent gérer les Connecteurs et les outils de Connecteur disponibles dans Studio et Vibe pour chaque espace de travail. Consultez [Connecteurs](/admin/identity-access/connectors).
