# Vibe

Vibe est l’**agent unifié** de Mistral pour la productivité et le développement, conçu pour un usage professionnel et accessible sur le web, mobile, dans votre éditeur de code ou le terminal.

Il fonctionne selon deux modes, chacun adapté à un type de tâche spécifique :

- **Work** : l’expérience unifiée dans les applications web et mobile de Vibe. Les conversations rapides et les tâches professionnelles en plusieurs étapes (recherche, brouillons, synthèses, exécutions programmées) se déroulent au même endroit, et un **bouton fast/think** bascule entre des réponses conversationnelles rapides et des workflows agentiques plus poussés.
- **Code** : développement dans le terminal, dans VS Code ou en session cloud à distance.

:::tip
Besoin d’aide pour choisir le mode adapté ? Comparez-les dans [Choisir Work ou Code](/vibe/choose-chat-work-code).
:::

:::info
**Chat et Work ne font plus qu’un.** Vibe séparait auparavant les conversations rapides (**Chat**) et le travail agentique en plusieurs étapes (**Work**) en deux onglets, ce qui vous obligeait à choisir une surface avant de commencer une tâche. Depuis le 22 septembre, ils sont fusionnés en une expérience unique — un seul endroit pour toutes vos conversations, où le **bouton fast/think** détermine la profondeur du traitement, et non l’onglet dans lequel vous vous trouvez. L’URL <AppLink href="https://chat.mistral.ai">chat.mistral.ai</AppLink> reste le point d’accès, et votre offre, votre historique et vos paramètres sont conservés.

Le déploiement est progressif : les comptes des offres Free, Pro et Teams en libre-service migrent en premier. Les organisations Enterprise suivent avec une fenêtre de migration de six mois — les administrateurs choisissent la date de migration dans le panneau d’administration ou déclenchent la fusion immédiatement. Si vous utilisiez les agents, tournez-vous vers les [Skills](/vibe/work/skills) — invoquez-les avec `@`. Des fenêtres d’accueil vous présentent les changements à la première ouverture de l’expérience unifiée.
:::

<SectionTab as="h2" sectionId="how-vibe-works">Comment fonctionne Vibe</SectionTab>

Quel que soit le mode, vous interagissez avec Vibe **de la même manière** : mêmes modèles Mistral, mêmes logiques, même contrôle. Un workflow Vibe typique se déroule ainsi :

1. **Vous exprimez votre besoin** en langage naturel.
2. **Vibe rassemble le contexte** à partir de votre demande, des fichiers joints, des outils connectés ou du web.
3. **Vibe planifie et exécute** : il découpe la tâche, lance les bons outils, affiche sa progression en temps réel.
4. **Vous révisez et réutilisez** : les résultats sont inspectables, modifiables et réutilisables en session.

**À chaque étape, vous gardez la main.** Vibe demande votre accord avant chaque action sensible, affiche tous les appels d’outils et vous laisse piloter ou interrompre quand vous le souhaitez.

:::info
Le **Chat temporaire** démarre une conversation qui n’est ni enregistrée dans votre historique, ni utilisée pour entraîner nos modèles. Nous consignons uniquement qu’un Chat temporaire a eu lieu, pas son contenu, et les données peuvent être conservées lorsque la loi l’exige.
:::
